Licence of the MTEX documentation
=================================

This file covers the *content* of the MTEX homepage and documentation website
(https://mtex-toolbox.github.io) — the prose, the code examples embedded in the
documentation pages and the figures generated for them, that is everything under

    pages/documentation_matlab/
    pages/function_reference_matlab/
    pages/examples_matlab/
    images/<Page>_NN.png

together with the MATLAB sources these pages are generated from (the doc/
directory and the help comments of the MTEX repository).

It does not cover the MTEX toolbox itself and it does not cover the website
machinery; see "Other licences in this repository" at the bottom.

What "appropriate credit" means here
------------------------------------

Credit the authors, name the source, and link to the page you took the material
from. In a bibliography or a generated answer, this is sufficient:

    The MTEX Developers, "<page title>", MTEX documentation,
    https://mtex-toolbox.github.io/<page>.html

If you are using MTEX for research, please additionally cite the paper
describing the toolbox:

    F. Bachmann, R. Hielscher, H. Schaeben: Texture Analysis with MTEX — Free
    and Open Source Software Toolbox, Solid State Phenomena 160 (2010), 63-68.
    doi:10.4028/www.scientific.net/SSP.160.63

Papers describing individual MTEX methods are listed at
https://mtex-toolbox.github.io/publications.html — please cite the one that
best fits your application.

Every generated page carries this information in three machine-readable forms:
a schema.org JSON-LD graph and a <link rel="license"> in the page head, and a
visible attribution block at the foot of the page. See also /llms.txt.
