{% comment %} The import wizard in short, for the language the visitor chose: its window, the command that starts it and what to do in it. Shown on the get-started page and in the dialog of the homepage. {% endcomment %}

Type this in the MATLAB command window:

import_wizard
  1. Double-click your file in the tree on the left. The wizard reads it and draws the map.
  2. Check the phase table: mineral names, symmetries and lattice parameters.
  3. Check the two coordinate systems against your specimen.
  4. Click Generate import script. The script loads the file without the wizard and becomes the first step of your analysis.

EBSD, pole figure and ODF files of all common vendors. MATLAB R2022b or newer.

Type this in the interactive window of VS Code or in any Python session:

from mtex import *
ebsd = importWizard()

or, from a terminal, mtex-wizard.

  1. Click your file in the browser on the left. The wizard reads it and draws the map.
  2. Check the phase table: mineral names, symmetries and lattice parameters.
  3. Check the two coordinate systems, map and Euler, against your specimen.
  4. Click write script. The script loads the file without the wizard and becomes the first step of your analysis.

EBSD files of all common vendors. Installed with pip install "mtex[all]".
