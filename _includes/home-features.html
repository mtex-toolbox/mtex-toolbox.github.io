What MTEX gives you

Read and write common data formats

EBSD from Oxford Instruments, EDAX and Bruker, 3D data from Xnovo and DREAM.3D, Neper tessellations and many pole figure formats, in one data model and back out to vendor files. Compare maps from different microscopes in one script.

  • Supported file formats
  • Export to vendor formats
  • Reference frames of each vendor

Beyond the acquisition software

MTEX also covers analyses that acquisition software leaves out, and it combines diffraction and EBSD data in one place.

  • ODFs from X-ray and neutron pole figures
  • Parent grains for any orientation relationship
  • Elastic and other tensor properties from texture
  • Variational denoising of orientation maps

Open, down to the algorithm

Every function is source code you can open. The core algorithms are published in peer-reviewed papers. Scripts record your analysis choices, rerun on new maps and help you document your methods.

AI assistants write MTEX scripts you can check

Describe your analysis in plain words and an assistant drafts the script. The documentation is mapped for AI tools in llms.txt. The result is ordinary code, so you read it, run it and keep it with your data.

I have an Oxford map A.ctf and an EDAX map B.ang of the same single-phase steel. Compare the grain size distributions.

compareGrainSize.m 
% two vendors, one grain definition
ebsdA = EBSD.load('A.ctf');
ebsdB = EBSD.load('B.ang');
grainsA = calcGrains(ebsdA,'angle',10*degree);
grainsB = calcGrains(ebsdB,'angle',10*degree);

% shared bins, normalized for different map sizes
rA = grainsA('indexed').equivalentRadius;
rB = grainsB('indexed').equivalentRadius;
edges = linspace(0,max([rA(:);rB(:)]),21);
histogram(rA,edges,'Normalization','pdf',...
  'DisplayStyle','stairs')
hold on
histogram(rB,edges,'Normalization','pdf',...
  'DisplayStyle','stairs')
hold off
xlabel('Equivalent radius (map length units)')
ylabel('Probability density')
legend('Oxford','EDAX')
import numpy as np
# two vendors, one grain definition
ebsdA = EBSD.load('A.ctf')
ebsdB = EBSD.load('B.ang')
grainsA = calcGrains(ebsdA,angle=10*degree)
grainsB = calcGrains(ebsdB,angle=10*degree)

# shared bins, normalized for different map sizes
rA = grainsA['indexed'].equivalentRadius
rB = grainsB['indexed'].equivalentRadius
edges = np.linspace(0,max(rA.max(),rB.max()),21)
histogram(rA,edges,density=True,histtype='step',label='Oxford')
hold(True)
histogram(rB,edges,density=True,histtype='step',label='EDAX')
hold(False)
xlabel('Equivalent radius (map length units)')
ylabel('Probability density')
legend()
