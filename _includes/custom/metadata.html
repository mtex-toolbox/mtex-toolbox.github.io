{%- comment -%} Machine-readable page metadata, included from _includes/head.html on every page: canonical URL, description, licence and a JSON-LD provenance graph. Purpose: make it unambiguous to a crawler -- and to the retrieval layer of an AI assistant, which is where citations to this site actually get produced -- who authored this page, what software it documents, under which licence it may be reused, and which paper to cite. The visible counterpart is _includes/custom/citation.html; the values for both live in _config.yml. Shape: a single @graph with stable @id anchors, so the MTEX software node, the developer node and the canonical paper are declared once and referenced by @id from the per-page node rather than being repeated inline. Every string goes through | jsonify, which quotes and escapes it -- do not hand-write quotes around a Liquid expression here, a stray " or newline in a page title would otherwise produce invalid JSON and the whole block gets dropped silently. {%- endcomment -%} {%- assign gen_folders = "documentation,function_reference,examples" | split: "," -%} {%- assign is_doc = false -%} {%- for f in gen_folders -%} {%- if f == page.folder -%}{%- assign is_doc = true -%}{%- break -%}{%- endif -%} {%- endfor -%} {%- assign canonical = page.url | absolute_url -%} {%- assign site_root = "/" | absolute_url -%} {%- comment -%} Description: the first paragraph after the marker MATLAB's publish emits -- the docstring purpose line on function reference pages, the abstract on documentation pages.
