transform image ij map positions (NWSE) into ebsd.pos (XYZ) this is nothing to do with the order of matrix indexing, but what the actual numbers are, so imgEast and imgSouth can be any size (inc column vectors)

Syntax

{% highlight matlab %} [xEbsdNew, yEbsdNew] = nwse2EbsdPos(ebsd,imgEast,imgSouth,varargin) {% endhighlight %}
