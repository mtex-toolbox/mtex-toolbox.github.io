{% raw %}
the ranges (phi1, Phi, phi2) of the Bunge Euler angles covering the fundamental region of
two frames, the specimen frame the default second

## Syntax

```python
maxPhi1, maxPhi, maxPhi2 = eulerRegion(cs)
eulerRegion(cs1, cs2)
```

## Signature

```python
eulerRegion(frA, frB=None)
```
