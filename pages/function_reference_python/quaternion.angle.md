A method of [quaternion](quaternion_index_py.html).

the rotational angle in [0, pi], or the angle between two, both from atan2 forms that
keep their digits near 0 and pi

## Syntax

```python
quaternion.angle(self, other=None)
```

```python
omega = angle(q)
omega = angle(q1, q2)
```
