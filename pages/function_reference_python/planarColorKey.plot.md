A method of [planarColorKey](planarColorKey_index_py.html).

draws the key as an image, hue along x and saturation along y; with the two properties v1, v2
the axes carry their ranges and labels

## Syntax

```python
planarColorKey.plot(self, v1=None, v2=None, nHue=256, nSat=128, **kw)
```

```python
pK.plot()
pK.plot(v1, v2)
```
