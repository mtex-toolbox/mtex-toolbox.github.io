{% raw %}
the plan for a node set: the NUFFT at arbitrary nodes, the FFT on a Clenshaw-Curtis grid,
the NUFFT on the nodes of a grid whose polar rule is not equispaced

## Syntax

```python
wignerPlan(nodes, L, real=True, folds=(1, 1))
```
