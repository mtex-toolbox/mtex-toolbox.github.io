a new mtexFigure laid out for n axes; it is always new, so MATLAB's second output, whether
it is, has no counterpart

## Syntax

```python
newMtexFigure(4, figSize='large')
```

## Signature

```python
newMtexFigure(n=1, **kwargs)
```
