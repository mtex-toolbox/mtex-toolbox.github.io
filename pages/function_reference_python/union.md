{% raw %}
combine point groups or compatible pole figure data sets.

## Syntax

<div class="mx-form" markdown="1">

```python
combined = union(a, b)
```

</div>

## Description

For an MTEX object, union(x, ...) calls x.union(...). Additional positional
and keyword arguments are passed to that method unchanged. Its documentation
specifies the accepted inputs, units, symmetry handling and optional outputs.
Consult the corresponding method for the behaviour of a particular object type.

For numeric arrays without an MTEX method, this calls numpy.union1d.

## Signature

<div class="mx-form" markdown="1">

```python
union(x, *args, **kwargs)
```

</div>

## Methods it calls

| [PoleFigure](PoleFigure.union_py.html) | the pole figures of several data sets in one |
| [referenceFrame](referenceFrame.union_py.html) | return a frame whose group is generated by this group and another group or operation |
| [symmetry](symmetry.union_py.html) | generate the smallest point group containing the operations of both inputs |
