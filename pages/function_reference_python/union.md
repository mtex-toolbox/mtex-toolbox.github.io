{% raw %}
union(x, ...) is x.union(...), the method of the object passed; NumPy's union1d for an array

## Syntax

```python
union(x, *args, **kwargs)
```

## Methods it calls

| | |
|---|---|
| [PoleFigure](PoleFigure.union_py.html) | the pole figures of several data sets in one |
| [referenceFrame](referenceFrame.union_py.html) | the same frame with the group generated by a rotation added, or with another frame's group joined |
| [symmetry](symmetry.union_py.html) | the group generated by both, symmetry/union |

## Used on

[CrystalSymmetries](CrystalSymmetries_py.html), [PoleFigureRefinement](PoleFigureRefinement_py.html)
