{% raw %}
the number of harmonic coefficients on SO(3) of the degrees below n, sum of (2k + 1)^2 for
k = 0 .. n - 1; deg2dim(L + 1) is the length of an array of bandwidth L

## Syntax

```python
deg2dim(n)
```
