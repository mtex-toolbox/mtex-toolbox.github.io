the real Wigner-d matrix d_l(beta) at one angle, or with bandwidth=L the list d_0 .. d_L

## Syntax

```python
wignerd(beta, degree=None, *, bandwidth=None)
```

```python
wignerd(beta, l)
wignerd(beta, bandwidth=L)
```
