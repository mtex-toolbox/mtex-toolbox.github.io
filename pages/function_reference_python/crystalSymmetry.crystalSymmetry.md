{% raw %}
the reference frame glued to the lattice basis of a phase, with the point group of the
crystal

## Syntax

Point group, cell, name:

```python
cs = crystalFrame('m-3m', [4.05, 4.05, 4.05], mineral='Aluminium', color='blue')
```

Angles and alignment:

```python
cs = crystalFrame('2/m', [8.6, 13, 7.2], [90, 116, 90], 'X||a', mineral='Orthoclase')
```

By the crystal system, or 'O', '432', ...

```python
cs = crystalFrame('cubic')
```

By the number of the Laue class:

```python
cs = crystalFrame(LaueId=9)
```

By the number of the space group:

```python
cs = crystalFrame(spaceId=153)
```

By the space group, the centring kept:

```python
cs = crystalFrame('I4/mmm', [3.3, 3.3, 5.8])
```

The axes turned by a rotation:

```python
cs = crystalFrame('432', rotAxes=rot)
```

By the cell alone, no group:

```python
cs = crystalFrame([1, 2, 3], [70, 80, 120], 'Z||a*')
```

By the axes themselves:

```python
cs = crystalFrame(axes, name='Forsterite')
```

The group generated by rotations:

```python
cs = crystalFrame(rot)
```

The trivial group, carrying that frame:

```python
cs = crystalFrame(otherFrame)
```

The basis is the crystal axes a, b, c in Euclidean coordinates, with their lengths; how the
Cartesian axes are aligned to them, X||a* and Z||c by default, belongs to the frame, not to
the point group. A frame is a handle compared by identity: the constructor answers with the
session's frame of the same lattice, group and name where there is one (intern=False
keeps it apart). The name, the mineral, is the frame's identity in a phase list.

Positional strings are the point group and alignments, 'X||a', 'Z||c*', 'EDAX'; everything
else is a keyword. The axis angles are in radians, or in degree when one exceeds 2 pi. A
space group symbol gives the point group and the centring of the lattice, P, A, B, C, I, F
or R, which centering also sets.

## Input

| | |
|---|---|
| `symbol` | the point group in international or Schoenflies notation, a crystal system, or a space group symbol |
| `abc` | the lengths of the crystal axes a, b, c |
| `abg` | the angles alpha, beta, gamma between the crystal axes |
| `axes` | vector3d, the three crystal axes |
| `rot` | rotation, the generators of the group |
| `otherFrame` | crystalFrame whose lattice the new frame takes, without its group |

## Output

| | |
|---|---|
| `cs` | crystalFrame |

## Keywords

| | default | |
|---|---|---|
| `mineral` | `None` | the name of the phase, the frame's identity |
| `name` | `None` | the same as mineral |
| `color` | `None` | the colour of the phase in a map |
| `alignment` | `()` | the alignment of the Cartesian axes to the crystal axes, 'X\|\|a', 'Y\|\|b*', 'EDAX', ..., as a string or a list of them |
| `rotAxes` | `None` | rotation turning the crystal axes against the Cartesian ones |
| `pointId` | `None` | the point group by its number, 1 to 32 |
| `LaueId` | `None` | the Laue class by its number, 1 to 11 |
| `laueId` | `None` | the same as LaueId |
| `spaceId` | `None` | the point group of the space group of this number, 1 to 230 |
| `how2plot` | `None` | the plottingConvention of the frame, by default the one of its crystal system |
| `intern` | `True` | unify with the session's frame of the same lattice, group and name |
| `density` | `None` | the mass density of the phase, kept in cs.opt['density'] |
| `axesNames` | `('a', 'b', 'c')` | the names of the three axes |
| `check` | `True` | check that the cell agrees with the lattice of the point group |
| `centering` | `None` | the centring of the lattice: 'P', 'A', 'B', 'C', 'I', 'F' or 'R' |
