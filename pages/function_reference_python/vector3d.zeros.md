A method of [vector3d](vector3d_index_py.html).

the zero vectors of a shape

## Syntax

```python
vector3d.zeros(*shape)
```

```python
v = vector3d.zeros()        # one zero vector
v = vector3d.zeros(m, n)    # an m x n array of them
```
