A method of [referenceFrame](referenceFrame_index_py.html).

return a frame whose group is generated by this group and another group or operation.

## Syntax

<div class="mx-form" markdown="1">

```python
combined = cs1.union(cs2)
combined = cs.union(rot)
```

</div>

## Description

The basis and frame type of the receiver are retained, while the symmetry group is
extended to include both operands and their products. The result is an interned sibling
frame; the input frames are unchanged. Use disjoint for the group intersection.

## See also

[referenceFrame.disjoint](referenceFrame.disjoint_py.html), [symmetry.union](symmetry.union_py.html)

## Signature

<div class="mx-form" markdown="1">

```python
referenceFrame.union(self, other)
```
