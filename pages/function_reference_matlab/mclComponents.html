Markovian clustering algorithm

Alternates expansion (squaring the transition matrix, i.e. letting the random walk take twice as many steps) and inflation (raising the transition probabilities to the power p and renormalising, i.e. favouring the likely steps) until the flow has drained out of the weakly connected parts of the graph. See S. van Dongen, Graph Clustering by Flow Simulation, PhD thesis, University of Utrecht, 2000, and S. van Dongen, Graph clustering via a discrete uncoupling process, SIAM J. Matrix Anal. Appl., 2008, 30(1):121-141.

Note that maxIter caps the number of cycles well before convergence in practice - for grain reconstruction it acts as the length scale on which clusters are decided, see doc/Grains/GrainReconstructionMCL.m.

author: gregor arbylon.net

Syntax

{% highlight matlab %} A = mclComponents(A,p,maxIter) {% endhighlight %}

Input

A adjacency matrix with weights between 0 and 1
p inflation power
maxIter maximum number of expansion/inflation cycles

Output

A adjacency matrix of the components
