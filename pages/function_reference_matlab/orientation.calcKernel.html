compute an optimal kernel function for ODF estimation

Description

'UCV' minimises an unbiased estimate of the integrated squared error, 'conservative' errs towards wider kernels, both bounded below by a noise floor, see selectHalfwidth. 'KLCV', 'LSCV' and 'BCV' are Kullback Leibler, least squares and biased cross validation over ten candidates, 'RuleOfThumb' reads the nearest neighbour distances and 'magicRule' only the number of orientations.

Syntax

{% highlight matlab %} psi = calcKernel(ori) psi = calcKernel(ori,'method','conservative') psi = calcKernel(ori,'groups',grainId) psi = calcKernel(ori,'method','ruleOfThumb') {% endhighlight %}

Input

ori orientation

Output

psi SO3DeLaValleePoussinKernel

Options

method |'KLCV'| (default), |'UCV'| (default with |'groups'|), |'conservative'|, |'LSCV'|, |'BCV'|, |'RuleOfThumb'|, |'magicRule'|
weights weights of the orientations
groups ids of mutually dependent orientations, e.g. the grainId of EBSD pixels (UCV and conservative only)
