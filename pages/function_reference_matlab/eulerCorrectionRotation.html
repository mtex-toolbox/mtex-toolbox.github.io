the Euler - map alignment behind an EDAX style "setting"

Description

EDAX style formats (.ang, .osc, .edaxh5) expose the alignment of the Euler angle reference frame with the map reference frame as a number 1 to 4, which the file does not state. This is the rotation each of them stands for, 0 being no correction at all.

Import applies it (see applyEulerCorrectionTable), export has to undo it again, so both take it from here.

Syntax

{% highlight matlab %} rot = eulerCorrectionRotation(2) {% endhighlight %}

Input

setting 0 to 4

Output

rot rotation
