The class stressTensor describes a (list) of stress tensors.

Syntax

{% highlight matlab %} M = [1 0 0; 0 0 0; 0 0 0]; sigma = stressTensor(M) {% endhighlight %}

Specify stress tensor by matrix.

{% highlight matlab %} sigma = stressTensor.uniaxial(v) {% endhighlight %}

Uniaxial stress in direction v.

Input

M 3x3 symmetric matrix
v vector3d

Output

sigma stressTensor
