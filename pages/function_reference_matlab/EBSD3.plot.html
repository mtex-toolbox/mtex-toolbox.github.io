spatial EBSD plot

Syntax

{% highlight matlab %} plot(ebsd) {% endhighlight %}

Colorize according to phase.

{% highlight matlab %} plot(ebsd,ebsd.mad) {% endhighlight %}

Colorize according to arbitrary value - here MAD.

{% highlight matlab %} plot(ebsd('phaseName'),ebsd('phaseName').orientation) {% endhighlight %}

Colorize according to orientation.

{% highlight matlab %} oM = ipfColorKey(ebsd('phaseName')) color = oM.orientation2color(ebsd('phaseName').orientations); plot(ebsd('phaseName'),color) {% endhighlight %}

Colorize according to custom color.

{% highlight matlab %} badMAD = ebsd.mad > 1; plot(ebsd(badMAD),'faceColor','black,'DisplayName','bad values') {% endhighlight %}

Specify the color directly and show in Legend.

{% highlight matlab %} plot(ebsd,ebsd.orientation,'region',[xmin, xmax, ymin, ymax]) {% endhighlight %}

Plot a subregion.

Input

ebsd EBSD
color length(ebsd) × 3 vector of RGB values

Options

micronbar 'on'/'off'
DisplayName add a legend entry
region [xmin, xmax, ymin, ymax] plotting region

Flags

points plot dots instead of unitcells
exact plot exact unitcells, even for large maps
