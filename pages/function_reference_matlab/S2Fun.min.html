global, local and pointwise minima of spherical functions

Syntax

{% highlight matlab %} [value,pos] = min(sF) {% endhighlight %}

The position where the minimum is atained.

{% highlight matlab %} [value,pos] = min(sF,'numLocal',5) {% endhighlight %}

The 5 largest local minima.

{% highlight matlab %} sF = min(sF, c) {% endhighlight %}

Minimum of a spherical functions and a constant.

{% highlight matlab %} sF = min(sF1, sF2) {% endhighlight %}

Minimum of two spherical functions.

{% highlight matlab %} sF = min(sF1, sF2, 'bandwidth', bw) {% endhighlight %}

Specify the new bandwidth.

{% highlight matlab %} sF = min(sFmulti,[],dim) {% endhighlight %}

Compute the minimum of a vector valued function along dim.

Input

sF, sF1, sF2 S2Fun
sFmulti a vector valued S2Fun
c double

Options

kmax number of iterations
numLocal number of peaks to return
startingNodes vector3d
tolerance minimum distance between two peaks
resolution minimum step size
maxStepSize maximum step size

Output

value double
pos vector3d
S2F S2Fun
