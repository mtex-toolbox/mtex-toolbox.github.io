divide a spherical vector field pointwise by a function or a number

Syntax

{% highlight matlab %} sVF = sVF ./ sF {% endhighlight %}

The field divided by the values of sF at the vertices.

{% highlight matlab %} sVF = sVF ./ a {% endhighlight %}

The field divided by the number a.

Input

sVF S2VectorFieldTri
sF S2FunTri on the same triangulation
a double

Output

sVF S2VectorFieldTri
