an abstract class representing functions on the 1-sphere

S1Fun is the common interface of all representations of a function defined on the circle, e.g. the distribution of an angle. Deriving classes only have to implement the method eval, everything else - arithmetics, plotting, integration - is inherited from here.

Class Properties

antipodal f(x) = f(x + pi)
bandwidth maximum harmonic degree
