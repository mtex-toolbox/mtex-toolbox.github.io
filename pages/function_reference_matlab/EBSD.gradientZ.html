orientation gradient in Z direction in specimen coordinates

Works on any EBSD, including a rotated or sheared grid - see private/gradientDir for how the lattice basis is inverted.

Syntax

{% highlight matlab %} gZ = ebsd.gradientZ {% endhighlight %}

Input

ebsd EBSD

Output

gZ length(ebsd) x 1 orientation gradient along Z
