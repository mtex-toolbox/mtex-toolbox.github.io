release an incremental hold

Description

Counterpart of holdOn. Decreases the hold counter of the axes ax and restores the original hold state once it drops back to zero. Usually this is called automatically by the guard returned from holdOn and there is no need to call it directly.

Syntax

{% highlight matlab %} holdRelease(ax) {% endhighlight %}

Input

ax axes handle(s)
