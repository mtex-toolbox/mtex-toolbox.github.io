--- title: 'calcPolygonsC' sidebar: function_reference_sidebar permalink: calcPolygonsC.html folder: function_reference toc: false --- calcPolygonsC edit page

trace the boundary loops of every grain into polygons

Syntax

{% highlight matlab %} [poly,inclusionId] = calcPolygonsC(I_FG,F,V) {% endhighlight %}

Grains in the plane.

{% highlight matlab %} [poly,inclusionId] = calcPolygonsC(I_FG,F,V,N) {% endhighlight %}

Grains in a plane of normal N.

Input

I_FG sparse incidence matrix of boundary segments and grains
F boundary segments as pairs of indices to V
V vertices, n x 2 double or vector3d
N vector3d, normal of the plane of the vertices

Output

poly cell list of indices to V
inclusionId number of trailing vertices in poly{k} belonging to inclusion (hole) loops, i.e. numel(poly{k}) minus the length of the main (largest area) loop. Known for free here since every grain's cycles are traced individually below; see EBSDAnalysis/grain2d/grain2d.m.
