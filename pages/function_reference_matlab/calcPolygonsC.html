Syntax

{% highlight matlab %} [poly,inclusionId] = calcPolygonsC(I_FG,F,V,N) {% endhighlight %}

Input

I_FG
F

Output

poly cell list of indices to V
inclusionId number of trailing vertices in poly{k} belonging to inclusion (hole) loops, i.e. numel(poly{k}) minus the length of the main (largest area) loop. Known for free here since every grain's cycles are traced individually below; see EBSDAnalysis/grain2d/grain2d.m.
