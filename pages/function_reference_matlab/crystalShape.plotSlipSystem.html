--- title: 'crystalShape.plotSlipSystem' sidebar: function_reference_sidebar permalink: crystalShape.plotSlipSystem.html folder: function_reference toc: false --- crystalShape.plotSlipSystem edit page

plot a slip system into a crystal shape, its plane as an inner face and its Burgers vector as an arrow

Syntax

{% highlight matlab %} h = plotSlipSystem(cS,sS,'faceColor','blue') {% endhighlight %}

Slip plane and slip direction of sS.

Input

cS crystalShape
sS slipSystem

Options

PatchProperty all matlab patch properties

Output

h handle to the graphics object

Example

{% highlight matlab %} cs = crystalSymmetry.load('Mg-Magnesium.cif'); cS = crystalShape.hex(cs) sS = [slipSystem.pyramidal2CA(cs), ... slipSystem.pyramidalA(cs)]; {% endhighlight %} {% highlight plaintext %} cS = crystalShape mineral: Mg (6/mmm, X||a*, Y||b, Z||c) vertices: 12 faces: 8 {% endhighlight %} {% highlight matlab %} plot(cS,'faceAlpha',0.2) hold on plot(cS,sS(2),'faceColor','blue') plot(cS,sS(1),'faceColor','red') hold off {% endhighlight %}
