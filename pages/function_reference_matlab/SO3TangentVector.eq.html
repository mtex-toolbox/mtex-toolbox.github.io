eq - Determine equality This MATLAB function returns a logical array or a table of logical values with elements set to logical 1 (true) where inputs A and B are equal; otherwise, the element is logical 0 (false).

Syntax

   A == B
   eq(A,B)

Input

A Operands
scalars | vectors | matrices | multidimensional arrays | tables |
timetables
B Operands
scalars | vectors | matrices | multidimensional arrays | tables |
timetables
