define rotentations by Euler angles

Syntax

{% highlight matlab %} rot = rotation.byEuler(phi1,Phi,phi2) {% endhighlight %}

Bunge convention.

{% highlight matlab %} rot = rotation.byEuler(alpha,beta,gamma,'ZYZ') {% endhighlight %}

Matthies convention.

{% highlight matlab %} rot = rotation.byEuler(phi1,Phi,phi2,'Kocks') {% endhighlight %}

Kocks convention.

Input

phi1, Phi, phi2 Euler angles in radiant

Flags

Bunge, ZXZ
ABG, Matthies, ZYZ
Roe
Kocks
Canova

Output

rot rotation
