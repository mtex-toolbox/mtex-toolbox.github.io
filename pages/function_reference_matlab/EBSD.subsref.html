indexing of EBSD data

Description

ebsd(x,y) is not the coordinate lookup - it is an error, since on a gridded map the same expression is the pixel in row x and column y. Use ebsd('xy',x,y), which means the same on a grid and on a list.

Syntax

{% highlight matlab %} ebsd('Fe') {% endhighlight %}

The data of phase Fe.

{% highlight matlab %} ebsd({'Fe','Mg'}) {% endhighlight %}

The data of the phases Fe and Mg.

{% highlight matlab %} ebsd(1:end) {% endhighlight %}

The measurements with these indices.

{% highlight matlab %} ebsd('id',id) {% endhighlight %}

The measurements with these ids.

{% highlight matlab %} ebsd('xy',x,y) {% endhighlight %}

The measurements closest to the coordinates.
