intragranular average misorientation angle per orientation

Syntax

{% highlight matlab %} plot(ebsd,ebsd.KAM ./ degree) {% endhighlight %}
{% highlight matlab %} kam = KAM(ebsd,'threshold',10*degree); plot(ebsd,kam./degree) {% endhighlight %}

Ignore misorientation angles > threshold.

{% highlight matlab %} [grains, ebsd] = calcGrains(ebsd) plot(ebsd, ebsd.KAM./degree) {% endhighlight %}

Ignore grain boundary misorientations.

{% highlight matlab %} kam = KAM(ebsd,'order',2); plot(ebsd,kam./degree) {% endhighlight %}

Consider also second order neighbors.

{% highlight matlab %} kam = KAM(ebsd,'radius',3*dxy); {% endhighlight %}

Consider all neighbors within a physical distance instead of order.

{% highlight matlab %} kam = KAM(ebsd,'order',3,'weights',@(d) exp(-(d/dxy).^2)); {% endhighlight %}

Weight neighbors by a kernel function of their physical distance.

Input

ebsd EBSD

Options

order consider neighbors up to graph-distance n (default 1)
radius consider neighbors up to physical distance r, instead of order
threshold ignore misorientation angles larger than threshold
max take not the mean but the maximum misorientation angle
weights function handle psi(distance) weighting each neighbor by its physical distance (default: uniform weight 1)
