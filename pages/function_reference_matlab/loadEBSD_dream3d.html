import 3d EBSD voxel data from a DREAM.3D file

Description

Files of DREAM3D-NX and of DREAM.3D 6 are read, whatever the data container and its attribute matrices are called. The voxel data are the first attribute matrix with EulerAngles, Quats or FeatureIds, in this order. A file without orientations gives rotations that are NaN, a file without Phases a single phase.

Syntax

{% highlight matlab %} ebsd = loadEBSD_dream3d(fname) ebsd = EBSD3.load(fname) {% endhighlight %}

Input

fname file name

Options

CS list of crystalSymmetry replacing the one read from the file

Output

ebsd EBSD3square, every further scalar cell array of the file is a property
