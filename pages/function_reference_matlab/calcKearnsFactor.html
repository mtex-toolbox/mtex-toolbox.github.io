Kearns texture factor of a pole figure or an ODF

Syntax

{% highlight matlab %} k = calcKearnsFactor(odf,N,h) {% endhighlight %}

From the pole figure of h computed from the ODF.

{% highlight matlab %} k = calcKearnsFactor(pdf,N) {% endhighlight %}

From a pole density function.

Input

odf orientation distribution function, SO3Fun
h crystal direction, Miller (default is [0001])
pdf pole density function, S2Fun
N normal direction vector3d, (default is Z)

Output

k Kearns texture factors
