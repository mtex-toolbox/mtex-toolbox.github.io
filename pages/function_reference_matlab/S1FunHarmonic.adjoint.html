Compute the adjoint SO(3)-Fourier/Wigner transform of given evaluations on specific nodes, by adjoint trivariate nfft/fft.

Syntax

{% highlight matlab %} S1F = S1FunHarmonic.adjoint(nodes,values) S1F = S1FunHarmonic.adjoint(nodes,values,'bandwidth',128,'weights',w) {% endhighlight %}

Input

nodes double
values double

Output

S1F S1FunHarmonic

Options

bandwidth maximal harmonic degree
weights quadrature weights
