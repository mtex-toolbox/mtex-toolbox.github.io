--- title: "EBSD.calcMisorientation" sidebar: function_reference_sidebar permalink: EBSD.calcMisorientation.html folder: function_reference toc: false --- EBSD.calcMisorientation edit page

calculate the uncorrelated misorientations between two ebsd phases

For two orientations \(g_i\) and \(g_j\) the misorientation is defined by \( m = g_i^{-1} \circ g_j \).

Syntax

{% highlight matlab %} mori = calcMisorientation(ebsd('phase1'),'sampleSize',1000) {% endhighlight %}

1000 uncorrelated misorientations of phase1.

{% highlight matlab %} mori = calcMisorientation(ebsd('phase1'),'minDistance',100) {% endhighlight %}

Uncorrelated misorientations with minimum distance 100.

{% highlight matlab %} mori = calcMisorientation(ebsd('phase1'),ebsd('phase2')) {% endhighlight %}

Uncorrelated misorientations between phase1 and phase2.

{% highlight matlab %} [ori1,ori2] = calcMisorientation(ebsd('phase1')) plot(axis(ori1,ori2),'contourf') {% endhighlight %}

Compute pairs of orientations to be used to compute axis. Distributions in specimen coordinates.

Input

ebsd EBSD

Output

m orientation
