a class representing an axis field on the sphere by harmonic series

Since an axis has no sign, not the axis itself but the six independent entries of the symmetric matrix v*v' are expanded into spherical harmonics. Evaluation recovers the axis as its leading eigenvector.

Syntax

{% highlight matlab %} aF = S2AxisFieldHarmonic(sF) aF = S2AxisFieldHarmonic(fun) {% endhighlight %}

Input

sF 6x1 S2FunHarmonic, the entries xx, xy, yy, xz, yz, zz
fun S2AxisField or @function_handle to be approximated

Output

aF S2AxisFieldHarmonic

Options

bandwidth maximum harmonic degree

Class Properties

sF the six components as S2FunHarmonic
