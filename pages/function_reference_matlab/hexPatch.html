--- title: hexPatch sidebar: function_reference_sidebar permalink: hexPatch.html folder: function_reference toc: false --- hexPatch edit page

Draw a hexagonal grid as a single patch object, one RGB color per tile.

All tiles share the same polygon shape (hex.unitCell) translated to their centers, so the whole map is one patch with per-face true-color data - far faster than one patch per tile. Tiles whose color contains a NaN are skipped, which lets you draw only the measured cells of an otherwise complete grid.

Syntax

{% highlight matlab %} h = hexPatch(hex, Xc, Yc, rgb) h = hexPatch(hex, Xc, Yc, rgb, 'parent', ax, ...) {% endhighlight %}

Input

hex geometry struct from hexGridEstimate (uses hex.unitCell)
Xc, Yc nFull-by-1 tile centers from hexGridComplete
rgb nFull-by-3 color per tile, values in [0,1]. Rows containing
NaN are not drawn. Build it from per point data with the index
from hexGridComplete:
rgb = nan(numel(Xc),3); rgb(idx,:) = pointRGB;

Output

h handle to the created patch object

Options

'parent' target axes (default: gca)
'EdgeColor' default 'none'
