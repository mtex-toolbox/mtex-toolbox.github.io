refine the boundary surfaces by midpoint subdivision

Description

Every subdivision splits each edge at its midpoint and each face into four, which halves the spacing of the vertices. No vertex moves, so the volumes, the areas and the grains a face separates are inherited exactly; a face keeps its voxels and its misorientation.

Syntax

{% highlight matlab %} grains = refineBoundary(grains) grains = refineBoundary(grains,2) {% endhighlight %}

Input

grains grain3d with triangular faces
n number of subdivisions (default 1)

Output

grains grain3d
