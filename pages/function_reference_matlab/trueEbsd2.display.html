standard output

A @trueEbsd job is a sequence of maps plus the hops between them, so the display is one row per map: what it is called, how big it is, which distortion separates it from the next one, how far and which way that hop moved it, and what was left over afterwards. The name is the one undistort writes the aligned image under, so it is also what to reach for afterwards - ebsd.fsdT1 rather than job.undistortedList(4).img. The residual is the diagnostic that says whether the registration worked - around a pixel or less is a success.

Syntax

{% highlight matlab %} display(job,varargin) {% endhighlight %}

Every MTEX class overloads it.
