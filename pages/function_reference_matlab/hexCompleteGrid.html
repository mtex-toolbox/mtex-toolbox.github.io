HEXCOMPLETEGRID Complete an incomplete hexagonal grid of tile centers.

{% highlight matlab %} G = HEXCOMPLETEGRID(x, y, unitCell) G = HEXCOMPLETEGRID(..., Name, Value) {% endhighlight %}

Syntax

{% highlight matlab %} G = hexCompleteGrid(x, y, unitCell, varargin) {% endhighlight %}

Input

x,y Original tile center coordinates. Missing tiles are allowed.
unitCell Approximate lattice/unit cell description. Supported forms:
2 by-2 numeric matrix:
[a1x a1y; a2x a2y]
Row vectors a1 and a2 are the two integer lattice steps.
scalar numeric:
nearest neighbor center spacing d. Uses basis
d*[1 0; 1/2 sqrt(3)/2].
struct with fields:
.basis 2 by-2 row-vector basis
OR .a1 and .a2 two 1 by-2 basis vectors
OR .spacing nearest neighbor center spacing
OR .radius hexagon center to-corner radius
Optional struct fields:
.angle rotation angle in radians for scalar spacing/radius
.angleDeg rotation angle in degrees
.hexRadius plotting radius, center to corner
.hexAngle plotting angle in radians for first vertex
.hexAngleDeg plotting angle in degrees for first vertex
Name Value options
'Origin' 1 by-2 origin. Default: first finite input point.
'RefineBasis' true/false. Least squares refine origin and basis. Default true.
'Iterations' Number of refinement iterations. Default 3.
'Tolerance' Warning threshold in lattice coordinate units. Default 0.35.
'Padding' Extra integer q/r layers around the completed grid. Default 0.
'Domain' 'qrbox', 'xybox', or 'convexhull'. Default 'qrbox'.
'KeepDuplicate' 'closest' or 'first' when several input points map to the
same grid position. Default 'closest'.

Output

G.x, G.y Complete grid center coordinates.
G.qr Nfull by-2 integer lattice coordinates [q r].
G.fullToOriginal Nfull by-1 index into original x/y, NaN for missing tiles.
G.originalToFull Noriginal by-1 index into complete grid, NaN for invalid input.
G.isObserved True for complete grid positions with original data.
G.basis, G.origin Refined basis/origin, with xy = origin + [q r]*basis.
G.hexRadius Default patch radius inferred from the lattice.
G.hexAngle Default first vertex angle for hex plotting.
