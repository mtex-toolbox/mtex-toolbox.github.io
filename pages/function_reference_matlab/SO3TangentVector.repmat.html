repmat - Repeat copies of array This MATLAB function returns an array containing n copies of A in the row and column dimensions.

Syntax

   B = repmat(A,n)
   B = repmat(A,r1,...,rN)
   B = repmat(A,r)

Input

A Input array
scalar | vector | matrix | multidimensional array
n Number of times to repeat input array in row and column dimensions
integer value
r1,...,rN Repetition factors for each dimension (as separate arguments)
integer values
r Vector of repetition factors for each dimension (as a row vector)
integer values
