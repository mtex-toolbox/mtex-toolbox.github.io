checks which grains are within given polygon

Syntax

{% highlight matlab %} ind = inpolygon(grains,[xmin,ymin,dx,dy]) {% endhighlight %}

Select indices by rectangle.

{% highlight matlab %} ind = inpolygon(grains,[x1 y1; x2 y2; x3 y3; x4 y4]) {% endhighlight %}

Select indices by poylgon.

{% highlight matlab %} grains = grains(ind) {% endhighlight %}

Select grains data by indices.

Input

grains grain2d
xmin, xmax lower left corner of a rectangle
dx, dy extent of a rectangle
x, y vertices of a polygon

Output

ind logical
