--- title: "noverk" sidebar: function_reference_sidebar permalink: noverk.html folder: function_reference toc: false --- noverk edit page

same as nchoosek, but works for vector-valued inputs

Syntax

a = noverk(n, k);

Input

n array of integers
k array of integers with: either n(i) >= k(i) (same size), or min(n) >= max(k) (different size)

Output

a = nchoosek(n, k) (pointwise)
