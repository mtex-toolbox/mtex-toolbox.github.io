WRAPTEXT Wrap text to a maximum line length (Unicode-aware, indent-aware).

{% highlight matlab %} out = wraptext(txt,width) returns text where: - Each original input line (split on newline) is wrapped separately. - No wrapped line exceeds 'width' visible characters. - Words are not split. - Runs of leading whitespace in each original line are preserved and re-applied to every wrapped line from that line. - ... fragments are treated as unbreakable words. {% endhighlight %} {% highlight matlab %} txt ... string or char width ... positive integer {% endhighlight %} {% highlight matlab %} Returns a char vector with '\n' separators. {% endhighlight %}

Syntax

{% highlight matlab %} out = wraptext2(txt,width) {% endhighlight %}
