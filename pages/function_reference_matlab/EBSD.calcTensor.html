--- title: "EBSD.calcTensor" sidebar: function_reference_sidebar permalink: EBSD.calcTensor.html folder: function_reference toc: false --- EBSD.calcTensor edit page

compute the average tensor for an EBSD data set

Syntax

{% highlight matlab %} [TVoigt, TReuss, THill] = calcTensor(ebsd('phase2'),T_phase2) {% endhighlight %}

Applies a tensor on a given phase.

{% highlight matlab %} [TVoigt, TReuss, THill] = calcTensor(ebsd,T_phase1,T_phase2,...) {% endhighlight %}

Applies each tensor given in order of input to each phase.

{% highlight matlab %} THill = calcTensor(ebsd,T_phase1,T_phase2,'Hill') {% endhighlight %}

Returns the specified tensor.

{% highlight matlab %} TGeom = calcTensor(ebsd,T_phase1,T_phase2,'geometric') {% endhighlight %}

Geometric mean instead of arithmetic one.

Input

ebsd EBSD
T_phaseN tensor for the N-th phase

Options

Voigt Voigt mean
Reuss Reuss mean
Hill Hill mean
geometric geometric mean

Output

T tensor
