implements grains(1:3)

Syntax

{% highlight matlab %} grains(1:10) {% endhighlight %}

The 10 first grains.

{% highlight matlab %} grains('Fe') {% endhighlight %}

Only Fe grains.

{% highlight matlab %} grains('id',5) {% endhighlight %}

Give the grain with id 5.

{% highlight matlab %} grains(5) {% endhighlight %}

Give the 5th grain in the list.

{% highlight matlab %} grains( ~grains('fe') ) {% endhighlight %}

All grains but Fe.

{% highlight matlab %} grains(cond) {% endhighlight %}

Input

grains grain2d
cond logical array with same size as grains
