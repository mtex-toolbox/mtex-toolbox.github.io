obsolete de la Vallee Poussin kernel, replaced by SO3DeLaValleePoussinKernel

Description

This class is obsolete since MTEX 5.9. Use the class SO3DeLaValleePoussinKernel instead. The class is preserved so that the kernels of saved unimodal @ODFs can be loaded.

Syntax

{% highlight matlab %} psi = deLaValleePoussinKernel(varargin) {% endhighlight %}

Warns and returns SO3DeLaValleePoussinKernel(varargin{:}).
