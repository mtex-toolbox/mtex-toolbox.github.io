a class representing a vector field on the sphere by values at nodes

The field is given by a vector3d at every vertex of a spherical triangulation and interpolated linearly in between.

Syntax

{% highlight matlab %} vF = S2VectorFieldTri(nodes,values) vF = S2VectorFieldTri(fun) {% endhighlight %}

Input

nodes vector3d or S2Triangulation
values vector3d, the field value at each node
fun @function_handle, sampled on an equispaced grid

Output

vF S2VectorFieldTri

Class Properties

tri S2Triangulation
vertices vector3d, the nodes of the triangulation
values vector3d, the field value at each node
antipodal vF(v) = vF(-v)

Example

{% highlight matlab %} v = equispacedS2Grid('resolution',10*degree); vF = S2VectorFieldTri(v,cross(v,vector3d.Z)) {% endhighlight %} {% highlight plaintext %} vF = S2VectorFieldTri vertices: 1 x 412 {% endhighlight %}
