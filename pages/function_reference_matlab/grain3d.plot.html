plot 3-dimensional grains, or more precise their faces

Only outer faces, the inner grains have the color gray [0.5 0.5 0.5].

Syntax

{% highlight matlab %} plot(grains) {% endhighlight %}

Colorize by phase.

{% highlight matlab %} plot(grains,property) {% endhighlight %}

Colorize by property.

{% highlight matlab %} plot(grains,property,'LineStyle','none') {% endhighlight %}

Adapt LineStyle.

Input

grains grain3d
property n × 1 numeric or orientation
