--- title: "spatialTransformId" sidebar: function_reference_sidebar permalink: spatialTransformId.html folder: function_reference toc: false --- spatialTransformId edit page

the transform that leaves every position where it is

Composing with it is a no-op on either side, so a hop where nothing separates the two frames needs no special case at the call sites.

Syntax

{% highlight matlab %} T = spatialTransformId {% endhighlight %}

Output

T spatialTransformId
