number of boundary segments

Description

The number of segments the grain boundary consists of. Note that this is a plain count of segments - the summed up geometric length of all segments is computed by segLength.

Syntax

{% highlight matlab %} n = length(gB) {% endhighlight %}

Input

gB grainBoundary

Output

n number of boundary segments
