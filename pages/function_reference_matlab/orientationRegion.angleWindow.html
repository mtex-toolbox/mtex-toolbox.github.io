--- title: 'orientationRegion.angleWindow' sidebar: function_reference_sidebar permalink: orientationRegion.angleWindow.html folder: function_reference toc: false --- orientationRegion.angleWindow edit page

the rotation angles about h that lie in the region, cut to a window

Syntax

{% highlight matlab %} [a,b] = angleWindow(oR,h) [a,b] = angleWindow(oR,h,'minAngle',20*degree,'maxAngle',40*degree) {% endhighlight %}

Input

oR orientationRegion
h vector3d, rotational axes

Output

a, b the angles about each axis run from a to b, b >= a
