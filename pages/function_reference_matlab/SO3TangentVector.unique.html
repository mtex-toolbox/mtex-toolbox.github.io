unique - Unique values This MATLAB function returns the same data as in A, but with no repetitions.

Syntax

   C = unique(A)
   C = unique(A,setOrder)
   C = unique(A,occurrence)
   C = unique(A,___,'rows')
   C = unique(A,'rows',___)
   [C,ia,ic] = unique(___)

Input

A Input array
array
setOrder Order flag
'sorted' (default) | 'stable'
occurrence Occurrence flag
'first' (default) | 'last'

Output

C Unique data of A
array
ia Index to A
column vector
ic Index to C
column vector
