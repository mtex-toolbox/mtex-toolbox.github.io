--- title: hexGridEstimate sidebar: function_reference_sidebar permalink: hexGridEstimate.html folder: function_reference toc: false --- hexGridEstimate edit page

Estimate the geometry of a (possibly incomplete) row-offset hexagonal grid.

A row-offset hex grid (the convention used by HKL/Oxford .ctf and many other EBSD systems) has points arranged in horizontal rows spaced dy apart; within a row points are spaced dx apart; and every other row is shifted horizontally by dx/2.

The step sizes and the offset pattern are measured from the data itself, because point spacings are exact even when many grid positions are missing. The unit cell is used only as the tile shape for plotting (and as a fallback for the steps if there are too few points to measure them). Steps can also be overridden explicitly (see options).

Syntax

{% highlight matlab %} hex = hexGridEstimate(x, y) hex = hexGridEstimate(x, y, unitCell) hex = hexGridEstimate(x, y, unitCell, 'dx', dx, 'dy', dy) {% endhighlight %}

Input

x, y column vectors of measured point centers
unitCell K-by-2 polygon vertices of one tile, relative to its center
(e.g. ebsd.unitCell). Optional; if omitted a regular hexagon
matching the measured steps is synthesized.

Output

hex struct describing the complete grid:
.dx .dy step sizes
.x0 .y0 origin (center of the row 0 / col 0 tile)
.nRows .nCols size of the complete bounding grid
.offsetOdd true if odd rows are shifted by +dx/2
.unitCell K by-2 tile polygon used for plotting

Options

'dx' override the in-row (horizontal) step
'dy' override the row (vertical) step
'offsetOdd' override offset detection (logical: are odd rows shifted?)
