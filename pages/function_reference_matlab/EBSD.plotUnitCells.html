low level plotting routine for EBSD maps - dispatches to a backend

Backend (option 'backend', 'imagesc'|'surf'|'patch'): * automatic (default): a square grid is sent to imagesc, which draws it directly if the grid is axis-aligned and rigid and otherwise hands over to surf; a hexagonal grid (or a 'unitCell'/'points' request) goes to patch. * an explicit 'backend' overrides the routing.

Syntax

{% highlight matlab %} h = plotUnitCells(ebsd,d,varargin) {% endhighlight %}
