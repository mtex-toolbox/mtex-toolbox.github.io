rotational axis of an misorientation or two orientations

Syntax

{% highlight matlab %} csCube = crystalSymmetry('cubic') csHex = crystalSymmetry('hexagonal') {% endhighlight %}

Define a cubic and hexagonal symmetries.

{% highlight matlab %} o1 = orientation.byEuler(0,0,0,csCube) o2 = orientation.byEuler(10*degree,20*degree,30*degree,csHex) {% endhighlight %}

Define two orientations.

{% highlight matlab %} a = axis(o1,o2) {% endhighlight %}

The misorientation axis with respect to the specimen coordinate. System is computed by.

{% highlight matlab %} a = axis(inv(o1)*o2,csCube) {% endhighlight %}

The misorientation axis with respect to csCube is computed by.

{% highlight matlab %} a = axis(inv(o1)*o2,csHex) {% endhighlight %}

The misorientation axis with respect to csHex is computed by.

{% highlight matlab %} a = axis(inv(o1)*o2,'noSymmetry') {% endhighlight %}

Compute the misorientation axis ignoring symmetry.

Input

mori,o1,o2 orientation

Options

noSymmetry ignore symmetry
max return the axis corresponding to the largest rotational angle

Output

a vector3d
m Miller
