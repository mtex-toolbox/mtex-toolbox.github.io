length of a unit in meter

Syntax

{% highlight matlab %} factor = getUnitScale('um') {% endhighlight %}

1e-6.

Input

unit unit of length, one of ym, zm, am, fm, pm, au (Angstrom, 1e-10), nm, um, mm, cm, m, km, Mm, Gm, Tm, Pm, Em, Zm, Ym

Output

factor length of the unit in meter
