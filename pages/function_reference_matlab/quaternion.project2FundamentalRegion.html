projects quaternions to a fundamental region

Syntax

{% highlight matlab %} project2FundamentalRegion(q,CS) {% endhighlight %}

To FR.

{% highlight matlab %} project2FundamentalRegion(q,CS,q_ref) {% endhighlight %}

To FR around reference rotation.

{% highlight matlab %} project2FundamentalRegion(q,CS1,CS2,q_ref) {% endhighlight %}

Misorientation to FR around id.

Input

q quaternion
CS1, CS2 crystal symmetry
q_ref reference quaternion single or size(q) == size(q_ref)

Output

q quaternion
omega rotational angle to reference quaternion
