--- title: 'trueEbsd' sidebar: function_reference_sidebar permalink: trueEbsd_index.html folder: function_reference toc: false --- trueEbsd edit page

Align a sequence of images and EBSD maps of the same specimen area using a chain of spatial transformations. Put the most distorted map first and the reference map last.

Create a job with trueEbsd, match pixel sizes with pixelSizeMatch, fit the transformations with calcDistortion, and resample the aligned maps with undistort.

See TrueEBSD for a worked registration workflow.
