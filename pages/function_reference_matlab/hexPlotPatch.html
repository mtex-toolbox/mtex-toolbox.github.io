HEXPLOTPATCH Fast patch plot for a completed hex mesh.

{% highlight matlab %} h = HEXPLOTPATCH(mesh, c) h = HEXPLOTPATCH(mesh, c, Name, Value) {% endhighlight %}

mesh is returned by hexBuildPatchMesh. c may be full-grid or original-grid scalar/RGB data; see hexColorData.

Name-Value options 'Parent' Target axes. Default gca. 'EdgeColor' Patch edge color. Default 'none'. 'MissingColor' RGB color for missing tiles when c is RGB. Default gray. 'ColorSource' 'auto', 'full', or 'original'. Default 'auto'. 'HideMissing' For scalar colors, make missing tiles transparent. Default false. 'AxisEqual' Call axis(ax,'equal'). Default true. 'AxisTight' Call axis(ax,'tight'). Default true.

Syntax

{% highlight matlab %} h = hexPlotPatch(mesh, c, varargin) {% endhighlight %}
