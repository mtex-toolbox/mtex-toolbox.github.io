class representing a strain tensor

The strain tensor is the symmetric rank 2 tensor describing a finite deformation. Depending on whether it is referred to the undeformed or the deformed configuration it is of type Lagrange, the default, or of type Euler. The constructor warns if the matrix is not symmetric.

Syntax

{% highlight matlab %} eps = strainTensor(M) eps = strainTensor(M,cs) eps = strainTensor(M,'type','Euler') {% endhighlight %}

Input

M 3x3 matrix
cs crystal symmetry

Output

eps strainTensor

Options

type 'Lagrange' or 'Euler'

Class Properties

M the tensor coefficients
rank always 2
type 'Lagrange' or 'Euler', read only
CS symmetry the coefficients refer to

Example

{% highlight matlab %} eps = strainTensor(diag([1 0 -1])) {% endhighlight %} {% highlight plaintext %} eps = strainTensor (y↓→x) type: Lagrange rank: 2 (3 x 3) 1 0 0 0 0 0 0 0 -1 {% endhighlight %}
