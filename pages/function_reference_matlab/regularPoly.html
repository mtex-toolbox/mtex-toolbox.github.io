--- title: 'regularPoly' sidebar: function_reference_sidebar permalink: regularPoly.html folder: function_reference toc: false --- regularPoly edit page

a regular polygon with s vertices, as the vertices of a unit cell

Syntax

{% highlight matlab %} unitCell = regularPoly(4,[dx dy],0) % the rectangle dx × dy unitCell = regularPoly(6,d,0) % the hexagon of width d {% endhighlight %}

Input

s number of vertices
d width, or [dx dy]
rot rotation angle

Output

unitCell s × 2 vertices

calcUnitCell EBSD.updateUnitCell
