hue-saturation-value colour map

The colours vary the hue of the hue-saturation-value colour model: they begin with red, pass through yellow, green, cyan, blue, magenta, and return to red. The map is particularly useful for displaying periodic functions.

Syntax

{% highlight matlab %} map = hsvColorMap(m) {% endhighlight %}

An m x 3 colour map.

{% highlight matlab %} map = hsvColorMap {% endhighlight %}

As many colours as the colour map of the current figure.

{% highlight matlab %} mtexColorMap(hsvColorMap) {% endhighlight %}

Set the colour map of the current plot.

Input

m number of colours

Output

map m x 3 matrix of RGB values
