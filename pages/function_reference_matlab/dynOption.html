--- title: "dynOption" sidebar: function_reference_sidebar permalink: dynOption.html folder: function_reference toc: false --- dynOption edit page

class to add dynamic options to a static class

Syntax

{% highlight matlab %} dOpt = dynOption('name',value) x = x.setOption('name',value) v = x.getOption('name') tf = x.isOption('name') {% endhighlight %}

Options

individual entries a unit, a grid layout, a comment - and are therefore not indexed along with it. That is the difference to dynProp.

Class Properties

opt struct holding the options
