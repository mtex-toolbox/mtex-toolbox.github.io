--- title: hexGridComplete sidebar: function_reference_sidebar permalink: hexGridComplete.html folder: function_reference toc: false --- hexGridComplete edit page

Build the complete hexagonal grid and map the measured points onto it.

Given the geometry from hexGridEstimate, this returns the centers of every tile of the complete (gap-free) bounding grid in a fixed linear order, and an index array linking each measured point to its tile in that grid.

Linear order is row-major: tile (r,c), with r = 0..nRows-1 and c = 0..nCols-1, has linear index r*nCols + c + 1. Odd rows are shifted by +dx/2 when hex.offsetOdd is true.

Syntax

{% highlight matlab %} [Xc, Yc, idx] = hexGridComplete(hex, x, y) [Xc, Yc, idx, isData] = hexGridComplete(hex, x, y) {% endhighlight %}

Input

hex geometry struct from hexGridEstimate
x, y measured point centers (same vectors passed to hexGridEstimate)

Output

Xc, Yc nFull-by-1 centers of every tile (nFull = nRows*nCols)
idx nData-by-1 linear index into the full grid for each measured
point, i.e. Xc(idx) ~= x and Yc(idx) ~= y. Use it to scatter
per point data onto the full grid:
full = nan(nFull, ...); full(idx,:) = data;
isData nFull-by-1 logical, true for tiles that carry a measured point
