pointwise power of a symmetrised spherical function

Syntax

{% highlight matlab %} sF = sF1.^a {% endhighlight %}

The power a of sF1, symmetric as sF1.

{% highlight matlab %} sF = sF1.^sF2 {% endhighlight %}

The symmetry is the one both functions share.

Input

sF1, sF2 S2FunHarmonicSym
a double

Output

sF S2FunHarmonicSym
