calculates the gradient of a spherical harmonic

Syntax

{% highlight matlab %} sVF = grad(sF) {% endhighlight %}

Returns the gradient as a spherical vector field.

{% highlight matlab %} g = grad(sF, v) {% endhighlight %}

Return the gradient in point v as vector3d.

Input

sF S2FunHarmonic
v vector3d

Output

sVF @sphericalVectorFieldHarmonic
g vector3d
