--- title: "buildImportWizardScript" sidebar: function_reference_sidebar permalink: buildImportWizardScript.html folder: function_reference toc: false --- buildImportWizardScript edit page

build the reproducible import script emitted by import_wizard

Syntax

{% highlight matlab %} str = buildImportWizardScript(ebsd,filePath,mapConvention,eulerConvention) str = buildImportWizardScript(...,dataSet,plotMask,phaseNames) {% endhighlight %}

Input

ebsd configured EBSD data
filePath source file
mapConvention selected map plottingConvention
eulerConvention selected Euler plottingConvention
dataSet selected HDF5 data set number
plotMask phases enabled in the wizard
phaseNames mineral names displayed in the phase table
