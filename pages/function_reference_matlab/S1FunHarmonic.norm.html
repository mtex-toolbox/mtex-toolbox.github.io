--- title: "S1FunHarmonic.norm" sidebar: function_reference_sidebar permalink: S1FunHarmonic.norm.html folder: function_reference toc: false --- S1FunHarmonic.norm edit page

Calculate the L2-norm of a S1FunHarmonic (Fourier series), by using Parsevalls equality for the integral

\[ n = \sqrt{\frac1{2\pi}\int_{\mathcal S_1} f(x)^2 dx}\],

with \(vol(S_1) = \int_{S_1} 1 dx = 2\pi\).

Syntax

{% highlight matlab %} n = norm(sF) {% endhighlight %}

Input

sF S1FunHarmonic

Output

n double
