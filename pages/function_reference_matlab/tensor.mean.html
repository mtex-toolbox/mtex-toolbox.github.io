mean of a list of tensors

Syntax

{% highlight matlab %} T = mean(T) {% endhighlight %}

Mean along the first non singleton dimension.

{% highlight matlab %} T = mean(T,dim) {% endhighlight %}

Mean along dimension dim.

{% highlight matlab %} TReuss = mean(T,'Reuss') {% endhighlight %}

Reuss average.

{% highlight matlab %} THill = mean(T,'Hill') {% endhighlight %}

Hill average.

{% highlight matlab %} TGeometric = mean(T,'geometric') {% endhighlight %}

Geometric mean.

{% highlight matlab %} [TVoigt, TReus, THill] = mean(T) {% endhighlight %}

Voigt, Reuss and Hill averages.

{% highlight matlab %} [TVoigt, TReus, THill] = mean(ori*T,'weights',weights) {% endhighlight %}

Mean with respect to orientations.

{% highlight matlab %} [TVoigt, TReus, THill] = mean(T,odf) {% endhighlight %}

Mean with respect to ODF.

{% highlight matlab %} [TVoigt, TReus, THill] = mean(ori,'weights',weights) {% endhighlight %}

Weighted mean.

Input

T tensor
dim dimension with respect to which the mean is taken
ori orientation
odf SO3Fun
weights double
