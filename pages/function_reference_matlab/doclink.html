--- title: "doclink" sidebar: function_reference_sidebar permalink: doclink.html folder: function_reference toc: false --- doclink edit page

build a command window hyperlink to a documentation page

The link runs mtexShowDoc rather than naming the html file directly: it keeps the link short enough to survive text wrapping, and it is the one place that decides whether the page comes from the local installation or from the web.

Syntax

{% highlight matlab %} linkText = doclink('EBSDReferenceFrame','here') linkText = doclink(ebsd) {% endhighlight %}

Input

fname documentation page, or an object whose class page is meant
lname text of the link, defaults to the page name
