plot a section through a spherical function

Syntax

{% highlight matlab %} N = vector3d.Z; {% endhighlight %}

Normal direction.

{% highlight matlab %} plotSection(sF,N) {% endhighlight %}

Plot in equator plane.

{% highlight matlab %} theta = pi/3; {% endhighlight %}

Polar angle.

{% highlight matlab %} plotSection(sF,N,theta) {% endhighlight %}

Plot small circle at 30 degree from the north pole.

{% highlight matlab %} rho = linspace(0,pi); {% endhighlight %}

Azimuth angle.

{% highlight matlab %} plotSection(sF,N,theta,rho) {% endhighlight %}

Plot half small circle at 30 degree.

Input

sF S2Fun
N normal direction of the intersection plane
theta polar angle of the intersection plane
rho azimuth angle of the points to be plotted

Output

h handle to the axes
