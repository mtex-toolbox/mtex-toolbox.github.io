import crystal symmetry from phl or cif files

if cif file not found and input name is a valid COD entry, this function tries to download the file from <http://www.crystallography.net/cif/ http://www.crystallography.net/cif/>

Syntax

{% highlight matlab %} cs = crystalSymmetry.load('5000035.cif') {% endhighlight %}

Load from cif file.

{% highlight matlab %} cs = crystalSymmetry.load('copper.phl') {% endhighlight %}

Load from phl file.

{% highlight matlab %} cs = crystalSymmetry.load(5000035) {% endhighlight %}

Lookup online.
