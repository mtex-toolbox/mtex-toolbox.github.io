class that provides an interface to the crystal simulation software neper (see https://neper.info)

Syntax

{% highlight matlab %} neper.init {% endhighlight %}
{% highlight matlab %} neper.filePath='C:\\Users\user\Work\Mtex\NeperExamples'; {% endhighlight %}

Select working folder, default: |tempdir|.

{% highlight matlab %} neper.fileName3d='my100Grains'; %default: 'allgrains' {% endhighlight %}

Specifying filenames.

{% highlight matlab %} neper.geometry = "cube(4,4,1)"; {% endhighlight %}

Specifying size of tessellation domain.

{% highlight matlab %} neper.id = 512; {% endhighlight %}

Defining tessellation id.

{% highlight matlab %} neper.varNeperopts = '-regularization 1' {% endhighlight %}

Eventually set a list of additional options to be found here. To be found here: https://neper.info/doc/neper_t.html.

{% highlight matlab %} cs = crystalSymmetry('mmm'); odf = unimodalODF(orientation.rand(cs)) numGrains = 100; myNeper.simulateGrains(numGrains,odf) {% endhighlight %}
{% highlight matlab %} N = vector3d(1,1,1); {% endhighlight %}

Normal vector (a,b,c) of a plane.

{% highlight matlab %} d = 1; {% endhighlight %}

D of a plane equation(a,b,c,d).

{% highlight matlab %} grains = neper.getSlice(N,d) {% endhighlight %}
{% highlight matlab %} N = vector3d(0,0,1); {% endhighlight %}

Normal vector of a plane.

{% highlight matlab %} A = vector3d(0,0,0.5); {% endhighlight %}

Point from the plane.

{% highlight matlab %} grains2 = neper.getSlice(N,A) {% endhighlight %}
{% highlight matlab %} plot(grains,grains.meanOrientation) hold plot(grains2,grains2.meanOrientation) {% endhighlight %}

Class Properties

id integer, "used [...] to compute the (initial) seed positions"
geometry "cube(x,y,z)" or "cylinder(h,d,numFaces)" or "sphere(d,numFaces)"
morpho cell morphology, see neper.info/doc/neper_t.html#morphology-options -default: graingrowth
iterMax max Iterations for morpho optimization process
fileName2d name for 2d outputs (fileendings .tess/.ori), default: '2dslice'
fileName3d name for 3d outputs (fileendings .tess/.ori/.stpoly), default: 'allgrains'
filePath filepath working directory, default: tempdir/neper
