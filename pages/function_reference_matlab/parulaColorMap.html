blue-green-orange-yellow colour map

Description

The colours begin with dark purplish-blue and blue, range through green and orange, and end with bright yellow.

Syntax

{% highlight matlab %} map = parulaColorMap(n) {% endhighlight %}

Colour map with n colours.

{% highlight matlab %} map = parulaColorMap {% endhighlight %}

As many colours as the current figure's colour map.

Input

n number of colours

Output

map n x 3 RGB colour map
