--- title: 'linprogCentre' sidebar: function_reference_sidebar permalink: linprogCentre.html folder: function_reference toc: false --- linprogCentre edit page

many small linear programs min c'x, A x = y, x >= 0 at once

Description

A primal dual path following interior point method on all problems simultaneously. Following the central path it ends in the analytic centre of the optimal solutions, which is symmetric whenever the problem is, where a simplex method returns an arbitrary vertex.

Syntax

{% highlight matlab %} x = linprogCentre(c,A,y) {% endhighlight %}

Input

c n x 1 or n x N costs
A m x n or m x n x N constraint matrices
y m x N right hand sides

Output

x n x N solutions, NaN where a problem did not converge

Options

tolerance relative accuracy (default 1e-9)
maxIter maximum number of iterations (default 100)
