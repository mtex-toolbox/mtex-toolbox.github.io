random stiffness tensor

Description

The entries of a stiffness tensor cannot be drawn independently: it has to be symmetric and positive definite, which a tensor of independent random entries is not, and which this class checks on construction. The Voigt matrix is therefore drawn as a random Gram matrix \(A A^T\), shifted away from singularity, so that both properties hold by construction.

Note that there are no zeros, ones or nan counterparts, since none of those is a stiffness tensor.

Syntax

{% highlight matlab %} C = stiffnessTensor.rand C = stiffnessTensor.rand(100) C = stiffnessTensor.rand(cs) {% endhighlight %}

Input

n,m size of the array of tensors
cs crystalSymmetry

Output

C stiffnessTensor
