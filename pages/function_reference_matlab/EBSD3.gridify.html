put a list of voxels back onto its lattice

A selection from a volume, ebsd('Quartz') or ebsd(condition), is a list of voxels that still carries the unit cell of the grid it came from. This rebuilds that grid: every voxel goes to its lattice cell and the cells nobody occupies are padded as not indexed.

Syntax

{% highlight matlab %} [ebsdGrid,newId] = gridify(ebsd) {% endhighlight %}

Input

ebsd EBSD3

Output

ebsdGrid EBSD3square, with |ebsdGrid.pos(newId) == ebsd.pos|
newId lattice index of every voxel of the list
