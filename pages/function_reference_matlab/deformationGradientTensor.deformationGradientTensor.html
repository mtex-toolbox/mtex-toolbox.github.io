class representing a deformation gradient tensor

The deformation gradient F contains the full information about the local rotation and deformation of the material. It also shows, for example, how a small line segment in the undeformed body, dX, is rotated and stretched into a line segment in the deformed body, dx, since dx = F dX. As F is volume preserving this implies that det F = 1.

Syntax

{% highlight matlab %} F = deformationGradientTensor(M) F = deformationGradientTensor.uniaxial(d,rate) F = deformationGradientTensor.simpleShear(d,n,e) F = deformationGradientTensor.pureShear(exp,compr,lambda) {% endhighlight %}

Input

M 3x3 matrix
d, n vector3d
rate, e amount of deformation
exp, compr extension and compression direction, vector3d
lambda stretch

Output

F deformationGradientTensor

Class Properties

M the tensor coefficients
rank always 2
CS symmetry the coefficients refer to

Example

{% highlight matlab %} F = deformationGradientTensor.simpleShear(vector3d.X,vector3d.Z,0.2) {% endhighlight %} {% highlight plaintext %} F = deformationGradientTensor (y↓→x) rank: 2 (3 x 3) 1 0 0.2027 0 1 0 0 0 1 {% endhighlight %}
