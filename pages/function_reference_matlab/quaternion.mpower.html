power of a quaternion

Syntax

{% highlight matlab %} q = q^n {% endhighlight %}

The n-th power.

{% highlight matlab %} q = q^(-1) {% endhighlight %}

The inverse.

{% highlight matlab %} q = q^[0,1,2,3] {% endhighlight %}

The powers 0, 1, 2 and 3 of a single quaternion.

Input

q quaternion
n double

Output

q quaternion
