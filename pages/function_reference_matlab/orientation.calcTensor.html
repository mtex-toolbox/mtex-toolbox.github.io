compute the average tensor for a vector of orientations

Syntax

{% highlight matlab %} [TVoigt, TReuss, THill] = calcTensor(ori,T,'weights',w) {% endhighlight %}

Returns the Voigt--, Reuss-- and Hill-- average <tensor.tensor.html tensor> of T.

{% highlight matlab %} THill = calcTensor(ori,T,'Hill') {% endhighlight %}

Returns the specified <tensor.tensor.html tensor>, i.e. 'Hill' in this case.

{% highlight matlab %} TGeom = calcTensor(ori,T,'geometric') {% endhighlight %}

Uses geometric mean instead of arithmetric one.

Input

ori orientation
T tensor
w weights for each orientation

Options

Voigt Voigt mean
Reuss Reuss mean
Hill Hill mean
geometric geometric mean

Output

TVoigt, TReuss, THill tensor
