discrepancy between weighted spherical point sets or a spherical density

Description

Point weights are nonnegative and normalized independently to mass one. A point set paired with a function is scaled to the function's integral, and keeps mass one if that integral vanishes. Antipodal points split mass equally between both signs. See S2Fun/discrepancy for all options and normalization conventions. The metrics are

* D_2 - the standard root cap L2 discrepancy, evaluated without truncating
point measures and counting a difference in total mass
* L2 - the root bandlimited norm
* D_cap - a finite cap-search approximation; info.isExact is false
* kernel - the historical squared truncated optimization objective, which
takes two functions of equal integral only

Syntax

{% highlight matlab %} d = discrepancy(v,w,'metric','D_2') {% endhighlight %}

Between the point sets v and w.

{% highlight matlab %} [d,info] = discrepancy(v,w,'metric','D_cap','numCenters',4097) {% endhighlight %}

Cap discrepancy over 4097 centres.

{% highlight matlab %} d = discrepancy(v,w,'metric','L2','bandwidth',32) {% endhighlight %}

Bandlimited norm up to degree 32.

{% highlight matlab %} d = discrepancy(v,w,'weights',c,'weights2',d,'metric','D_2') {% endhighlight %}

Weighted point sets.

{% highlight matlab %} d = discrepancy(v,f,'weights',c,'metric','D_2') {% endhighlight %}

Between a point set and a density f.

{% highlight matlab %} d = discrepancy(v,w,'squared') {% endhighlight %}

The squared discrepancy.

Input

v vector3d
w vector3d
f S2Fun

Options

metric 'D_2' (default), 'L2', 'D_cap' or 'kernel'
weights weights of v
weights2 weights of w
bandwidth harmonic degree of L2 and kernel
numCenters number of cap centres of D_cap

Flags

squared return the squared discrepancy

Output

d double
info struct, info.isExact says whether d is exact
