HEXCOLORDATA Expand original-grid or full-grid colors to patch face colors.

{% highlight matlab %} cdata = HEXCOLORDATA(mesh, c) [cdata, isMissing, colorSource] = HEXCOLORDATA(...) {% endhighlight %}

c may be: Nfull-by-1 scalar color per completed tile Nfull-by-3 RGB color per completed tile Norig-by-1 scalar color per original input tile Norig-by-3 RGB color per original input tile 1-by-3 one RGB color for all tiles

Name-Value options 'ColorSource' 'auto', 'full', or 'original'. Default 'auto'. 'MissingColor' RGB color for missing tiles when c is RGB. Default gray.

Syntax

{% highlight matlab %} [cdata, isMissing, colorSource] = hexColorData(mesh, c, varargin) {% endhighlight %}
