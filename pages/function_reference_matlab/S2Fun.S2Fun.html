an abstract class representing functions on the sphere

A spherical function carries the referenceFrame it is expressed in - empty means frame-free, resolved against the session default at render time. Symmetry is deliberately not part of this class: only S2FunHarmonicSym represents a symmetrised function and holds a symmetry, whose frame it exposes here.
