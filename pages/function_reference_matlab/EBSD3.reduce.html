reduce ebsd data by a factor

Syntax

{% highlight matlab %} ebsd = reduce(ebsd) {% endhighlight %}

Take every second voxel along each axis.

{% highlight matlab %} ebsd = reduce(ebsd,3) {% endhighlight %}

Take every third voxel along each axis.

Input

ebsd EBSD3
factor resample ebsd at rate factor (integer)

Output

ebsd EBSD3
