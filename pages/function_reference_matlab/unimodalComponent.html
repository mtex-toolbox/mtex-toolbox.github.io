obsolete ODF component, kept to load ODFs saved before MTEX 5.9

This class is obsolete since MTEX 5.9. Use the class SO3FunRBF instead. The class is preserved, so that saved @ODFs can be loaded.

Syntax

{% highlight matlab %} load('odf.mat') {% endhighlight %}

An ODF saved before MTEX 5.9 loads as <SO3FunRBF.SO3FunRBF.html SO3FunRBF>.
