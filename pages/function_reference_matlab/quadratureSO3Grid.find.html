--- title: "quadratureSO3Grid.find" sidebar: function_reference_sidebar permalink: quadratureSO3Grid.find.html folder: function_reference toc: false --- quadratureSO3Grid.find edit page

return the index of the nearest node of a Clenshaw Curtis quadrature grid for each input rotation

Since the grid is a regular tensor grid in the Euler angles the lookup is plain (vectorized) index arithmetic - no search is involved.

The first and third Euler angle are folded into the grid section by their periodicity. For grids with cyclic symmetries this amounts to identifying symmetrically equivalent rotations, i.e. it is only meaningful when the data to be accumulated on the grid is (to be) symmetrised anyway.

Syntax

{% highlight matlab %} id = find(SO3G,ori) {% endhighlight %}

Input

SO3G quadratureSO3Grid
ori rotation, orientation

Output

id index of the nearest node into the (unique) grid, size(ori)
