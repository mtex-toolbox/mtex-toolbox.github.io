the layout engine behind mtexFigure

Description

Three steps, so that the arithmetic can be computed - and tested - without a figure:

* <mtexLayout.measure.html measure> reads the geometry off the graphics objects
* <mtexLayout.solveLayout.html solveLayout> is pure arithmetic, no handles in and none out
* <mtexLayout.apply.html apply> writes back only what actually moved

resolve drives the three until nothing moves. solveLayout is static: give it a spec struct and it returns every position with no figure existing anywhere, which is what tests/core/check_mtexLayout exercises.

Syntax

{% highlight matlab %} lay = mtexFig.layout {% endhighlight %}

The layout engine of an <mtexFigure.mtexFigure.html mtexFigure>.

{% highlight matlab %} plan = mtexLayout.solveLayout(spec) {% endhighlight %}

The arithmetic alone, without a figure.
