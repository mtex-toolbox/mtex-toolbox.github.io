symmetrise a tensor according to its crystal symmetry

Syntax

{% highlight matlab %} T = symmetrise(T,'isotropic') {% endhighlight %}

The isotropic part of the tensor.

{% highlight matlab %} T = symmetrise(T,cs) {% endhighlight %}

Symmetrise according to a crystal symmetry.

{% highlight matlab %} T = symmetrise(T,d) {% endhighlight %}

Symmetrise transversally allong direction d.

Input

T tensor
cs symmetry
d vector3d

Output

T tensor
