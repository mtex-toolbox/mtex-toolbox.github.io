--- title: 'planarColorKey' sidebar: function_reference_sidebar permalink: planarColorKey.html folder: function_reference toc: false --- planarColorKey edit page

encode two scalar properties as hue × saturation colors

Description

The first property selects the hue, sampled from a colour map, the second the saturation, from no colour (white or black) to the full colour:

* property 1 - hue, sampled from a user-supplied or the default colour map
* property 2 - saturation, linearly from white or black to the full colour

Syntax

{% highlight matlab %} cK = planarColorKey {% endhighlight %}

Key over the default colour map.

{% highlight matlab %} cK = planarColorKey(winter,'shading','black') {% endhighlight %}

Key over winter, fading to black.

{% highlight matlab %} rgb = cK.property2color(v1, v2) {% endhighlight %}

Colours of the values v1, v2.

{% highlight matlab %} plot(cK) {% endhighlight %}

Standalone legend (key image only, no labels).

{% highlight matlab %} plot(cK, v1, v2) {% endhighlight %}

Legend with axes and labels according to the data range.

Input

winter n x 3 colour map of the hue, or the name of one
v1 double, the property mapped to hue
v2 double, the property mapped to saturation, same size as v1

Options

shading 'white' (default) or 'black', what zero saturation maps to
satRange saturation range for v2, default [0 1]
quantileCap quantile for the maximum of v2, default 0.975
range1 data range of v1, default [min(v1), max(v1)]
range2 data range of v2, default [min(v2), quantile(v2,0.975)]
label1 x-axis label in plot(), default 'Property 1'
label2 y-axis label in plot(), default 'Property 2'

Output

cK planarColorKey
rgb colours of size [size(v1), 3]

Class Properties

colorMap n x 3 hue look-up table
shading 'white' (default) or 'black', what zero saturation maps to
satRange saturation range for v2
periode period of periodic data (pi or 2*pi), wrapping v1, default NaN
quantileCap quantile for the maximum of v2
range1 data range of v1
range2 data range of v2
label1 x-axis label in plot()
label2 y-axis label in plot()

Example

Example 1: long axis mapping, with saturation given by aspect ratio get the data

{% highlight matlab %} mtexdata martensite silent grains = ebsd('indexed').calcGrains('minPixel',5); asr = grains('indexed').aspectRatio; lax = grains('indexed').longAxis; {% endhighlight %}

set up colormap

{% highlight matlab %} pK = planarColorKey(colorcet('C2')); % since long axis direction is periodic and antipodal (=pi) pK.periode = pi; pK.label1 = 'phi'; pK.label2 = 'a/b'; % and plot it plot(pK,mod(lax.rho,pi)/degree,asr) {% endhighlight %}

use the key to colorize the map

{% highlight matlab %} plot(grains('indexed'),pK.property2color(mod(lax.rho,pi)/degree,asr)) {% endhighlight %}

example 2: highlight grains which are large AND have a large aspect ratio

{% highlight matlab %} v1 = grains('indexed').aspectRatio; v2 = grains('indexed').area; {% endhighlight %}

set a colormap

{% highlight matlab %} pK = planarColorKey(inferno); {% endhighlight %}

shade to black

{% highlight matlab %} pK.shading = 'black'; {% endhighlight %}

set the range1 for v1

{% highlight matlab %} pK.range1 = [1 4]; {% endhighlight %}

set the autoselection of v2 a little lower

{% highlight matlab %} pK.quantileCap = 0.9; {% endhighlight %}

set labels

{% highlight matlab %} pK.label1 = 'asr'; pK.label2 = 'area'; close all; plot(pK,v1,v2) {% endhighlight %} {% highlight matlab %} plot(grains('indexed'),pK.property2color(v1,v2)) {% endhighlight %}
