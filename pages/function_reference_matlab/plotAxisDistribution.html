plot axis distribution

Syntax

{% highlight matlab %} plotAxisDistribution(cs) {% endhighlight %}

Random axis distribution.

{% highlight matlab %} plotAxisDistribution(cs1,cs2) {% endhighlight %}

Random misorientation axis distribution.

{% highlight matlab %} plotAxisDistribution(mori) {% endhighlight %}

Axes in crystal coordinates.

{% highlight matlab %} plotAxisDistribution(mori,cs1) {% endhighlight %}

Axes in crystal coordinates.

{% highlight matlab %} plotAxisDistribution(ori1,ori2) {% endhighlight %}

Axes in specimen coordinates.

{% highlight matlab %} plotAxisDistribution(odf) {% endhighlight %}

Input

odf SO3Fun
mori @misorientation
ori1,ori2 orientation
cs1, cs2 crystalSymmetry

Options

RESOLUTION resolution of the plots

Flags

antipodal include antipodal symmetry
complete plot entire (hemi)--sphere
noLabel do not annotate
