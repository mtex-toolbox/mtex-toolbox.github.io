copy the hold state of one axes onto others

Description

Propagates the hold state of fromAx to all axes in toAx. In contrast to holdOn this sets the baseline hold state, i.e. it is not undone when the calling function returns and it does not take part in the hold counter. Use it when a plot spans multiple axes and all of them should behave like the current one.

Syntax

{% highlight matlab %} copyHoldState(mtexFig.gca,mtexFig.children) {% endhighlight %}

Input

fromAx source axes handle
toAx target axes handle(s)
