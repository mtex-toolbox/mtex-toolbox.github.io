--- title: "plotSphericalGrid" sidebar: function_reference_sidebar permalink: plotSphericalGrid.html folder: function_reference toc: false --- plotSphericalGrid edit page

draw the meridians and small circles of a spherical grid in 3d

The three dimensional counterpart of the polar grid sphericalPlot draws on a projected plot. It is used by plotEmptySphere for the backdrop of a three dimensional scatter plot, and by vector3d/plot3d to lay a grid over a pole density function.

Syntax

{% highlight matlab %} plotSphericalGrid(ax) plotSphericalGrid(ax,'grid_res',10*degree) plotSphericalGrid(ax,'radius',1.002) {% endhighlight %}

Input

ax axes handle

Output

h handles of the two line objects drawn

Options

grid_res angular spacing of the grid lines, default 15 degree
radius radius of the sphere the grid is drawn on, default 1
center center of that sphere, default the origin, vector3d
gridColor line color, default light gray

See also
