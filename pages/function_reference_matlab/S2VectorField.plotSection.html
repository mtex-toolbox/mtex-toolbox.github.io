plot a vector field along a great or small circle section

Syntax

{% highlight matlab %} plotSection(sVF,vector3d.Z) {% endhighlight %}

Along the great circle normal to z.

{% highlight matlab %} plotSection(sVF,vector3d.Z,pi/3) {% endhighlight %}

Along the small circle at angle pi/3 to z.

Input

sVF S2VectorField
sec vector3d, normal of the section
