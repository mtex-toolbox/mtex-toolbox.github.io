abstract class for denoising EBSD data

A filter replaces the orientation of every pixel of a gridded EBSD map by one computed from its neighbours. Deriving classes only implement smooth; which neighbours exist is told to them through isHex.

Syntax

{% highlight matlab %} ebsd = smooth(ebsd,F) ebsd = smooth(ebsd,F,'fill',grains) {% endhighlight %}

Input

F EBSDFilter

Class Properties

isHex is the map on a hexagonal grid
