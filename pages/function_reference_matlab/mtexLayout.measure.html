--- title: 'mtexLayout.measure' sidebar: function_reference_sidebar permalink: mtexLayout.measure.html folder: function_reference toc: false --- mtexLayout.measure edit page

read the geometry off the figure, once

Description

The only step that touches graphics properties. Everything it reads is cached behind a token built from the things the answer depends on, so a resize that changes nothing - the common case while dragging a window - costs one token comparison and no property access at all.

Syntax

{% highlight matlab %} spec = lay.measure(mtexFig) {% endhighlight %}

Output

spec what solveLayout needs, all in pixels
