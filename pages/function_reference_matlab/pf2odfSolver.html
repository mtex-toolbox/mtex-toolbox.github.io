an abstract class representing solvers for the pole figure inversion

Reconstructing an ODF from PoleFigure data is an ill posed inverse problem. This is the interface calcODF drives; the only implementation is MLSSolver, the modified least squares solver.

Syntax

{% highlight matlab %} odf = calcODF(pf) solver = MLSSolver(pf); odf = solver.calcODF {% endhighlight %}

Class Properties

pf the PoleFigure data
CS, SS crystal and specimen symmetry of pf

Derived Classes

MLSSolver modified least squares, the MTEX default
