compute the Fourier coefficients of a function on the circle by quadrature

Syntax

{% highlight matlab %} S1F = S1FunHarmonic.quadrature(nodes,values,'weights',w) {% endhighlight %}

From function values at nodes.

{% highlight matlab %} S1F = S1FunHarmonic.quadrature(f) {% endhighlight %}

From a function handle or an <S1Fun.S1Fun.html S1Fun>.

{% highlight matlab %} S1F = S1FunHarmonic.quadrature(f, 'bandwidth', bandwidth) {% endhighlight %}

Up to a given bandwidth.

Input

values double (first dimension has to be the evaluations)
nodes double
f function handle (first dimension has to be the evaluations)

Options

bandwidth minimal degree of the complex exponentials
S1Grid quadrature grid
weights quadrature weights

Output

S1F S1FunHarmonic
