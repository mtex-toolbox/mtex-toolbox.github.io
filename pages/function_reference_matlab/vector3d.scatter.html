plot directions as markers in a spherical projection

Syntax

{% highlight matlab %} scatter(v) {% endhighlight %}

Plot the directions v.

{% highlight matlab %} scatter(v,data) {% endhighlight %}

Colorize directions according to data.

{% highlight matlab %} scatter(v,'label',text) {% endhighlight %}

Plot text below markers.

{% highlight matlab %} scatter(v,'label',text,'textaboveMarker') {% endhighlight %}

Plot text above markers.

{% highlight matlab %} scatter(v,'numbered') {% endhighlight %}

Plot directions with numbers.

Input

v vector3d
data double
rgb a list of rgb color values

Options

Marker 's','o','diamond','p'
MarkerFaceColor 'r','g','w','k','b'
MarkerEdgeColor 'r','g','w','k','b'
MarkerColor shortcut for the above two
MarkerSize size of the markers in pixel
MarkerAlpha transparency setting
MarkerEdgeAlpha transparency setting
MarkerFaceAlpha transparency setting
DynamicMarkerSize scale marker size when plot is resized
Grid whether to display a grid
grid_res resolution of the grid to be displayed

Output

h handle to the graphics objects
ax handle to the axes
