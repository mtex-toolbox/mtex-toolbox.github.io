difference between the largest and the smallest value

Description

For a vector, y is the difference between the maximum and the minimum value, for a matrix the range of each column. NaNs are ignored.

Syntax

{% highlight matlab %} y = range(x) {% endhighlight %}

Along the first non-singleton dimension.

{% highlight matlab %} y = range(x,dim) {% endhighlight %}

Along the dimension dim.

Input

x double
dim dimension

Output

y double, max(x) - min(x)
