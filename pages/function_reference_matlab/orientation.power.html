power of a misorientation

Description

Except for n = -1, the inverse, the power is only defined for misorientations between the same phase; it is taken of the representative in the fundamental region.

Syntax

{% highlight matlab %} mori = mori.^n {% endhighlight %}

The n-th power.

{% highlight matlab %} mori = mori.^(-1) {% endhighlight %}

The inverse.

{% highlight matlab %} mori = mori.^2 {% endhighlight %}

The square.

{% highlight matlab %} mori = mori.^[0,1,2,3] {% endhighlight %}

Several powers at once.

Input

mori misorientation
n double

Output

mori misorientation
