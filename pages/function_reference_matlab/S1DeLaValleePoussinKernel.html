The \(n\)-th de la Vallee Poussin kernel is defined by

\[ V_{2n}(x) = \frac{1}{n} \, \sum\limits_{j=n}^{2n-1} D_j(x) = 2F_{2n-1}(x) - F_{n-1}(x),\]

where \(D_j\) denotes the \(j\)-th Dirichlet kernel and \(F_n\) the \(n\)-th Fejer kernel.

The de la Vallee Poussin kernel is always positive and there is no truncation error in Fourier space.

Syntax

{% highlight matlab %} psi = S1DeLaValleePoussinKernel(n) {% endhighlight %}

Input

n parameter (2*n is the bandwidth)
