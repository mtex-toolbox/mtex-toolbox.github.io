projects quaternions to a fundamental region

Syntax

{% highlight matlab %} [phi1,Phi,phi2] = project2EulerFR(q,CS) {% endhighlight %}

Bunge fundamental region.

{% highlight matlab %} [alpha,beta,gamma] = project2EulerFR(q,CS,'Matthies') {% endhighlight %}

Matthies fundamental region.

{% highlight matlab %} [phi1,Phi,phi2] = project2EulerFR(q,CS1,CS2) {% endhighlight %}

Misorientations.

Input

q quaternion
CS1, CS2 crystal symmetry

Output

phi1,Phi,phi2 Euler angles
