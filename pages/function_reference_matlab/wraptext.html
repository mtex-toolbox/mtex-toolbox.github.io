wrap text to a maximum line length

Description

Each line of txt is wrapped on its own, so that no wrapped line exceeds width visible characters; the line breaks of txt are kept. Words are not split. A hyperlink ......</a> is treated as one word, as long as the text it shows, and is never broken.

Syntax

{% highlight matlab %} out = wraptext(txt,width) {% endhighlight %}

Wrap to width characters.

{% highlight matlab %} out = wraptext(txt) {% endhighlight %}

Wrap to the width of the command window.

{% highlight matlab %} wraptext(txt,width) {% endhighlight %}

Display the wrapped text.

Input

txt char or string
width positive integer

Output

out char vector with newline characters as line separators
