plot a grain size histogram

Syntax

{% highlight matlab %} hist(grains) {% endhighlight %}
{% highlight matlab %} hist(grains,n) {% endhighlight %}

Specify the number of bins.

{% highlight matlab %} hist(grains,grains.equivalentRadius) {% endhighlight %}

Use an arbitrary property for the histogram.

{% highlight matlab %} binId = hist(grains) {% endhighlight %}

Returns the bin for each grain.

Input

grains grain2d
n number of bins, default is 15
