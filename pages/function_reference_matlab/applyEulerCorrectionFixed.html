apply a single fixed default Euler / map reference frame correction

Shared by Oxford-style formats (.crc, .ctf) that always default to the same correction rotation (a 180 degree rotation about the z-axis) unless the user overrides it.

Syntax

{% highlight matlab %} ebsd = applyEulerCorrectionFixed(ebsd,ext,defaultCorrection,varargin{:}) {% endhighlight %}

Input

ebsd EBSD
ext file extension used in the warning text, e.g. '.ctf'
defaultCorrection rotation applied unless overridden

Options

EulerCorrection explicit correction rotation, overrides defaultCorrection
