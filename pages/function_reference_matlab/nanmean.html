mean value ignoring NaNs

Syntax

{% highlight matlab %} y = nanmean(x) {% endhighlight %}

Along the first non-singleton dimension.

{% highlight matlab %} y = nanmean(x,dim) {% endhighlight %}

Along dimension dim.

Input

x numeric array
dim dimension to average along

Output

y mean of the entries of x that are not NaN, NaN where all of them are
