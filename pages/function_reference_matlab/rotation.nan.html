rotations with all components set to NaN

Description

Placeholder rotations, e.g. to preallocate an array that is filled later on. Any operation involving a NaN rotation returns NaN.

Syntax

{% highlight matlab %} rot = rotation.nan rot = rotation.nan(5) rot = rotation.nan(10,3) {% endhighlight %}

Input

n,m size of the array of rotations

Output

rot rotation
