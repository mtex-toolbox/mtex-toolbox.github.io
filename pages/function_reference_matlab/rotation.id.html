the identical rotation

Description

The rotation that leaves every vector unchanged, i.e., the neutral element of the rotation group.

Syntax

{% highlight matlab %} rot = rotation.id rot = rotation.id(5) rot = rotation.id(10,3) {% endhighlight %}

Input

n,m size of the array of rotations

Output

rot rotation
