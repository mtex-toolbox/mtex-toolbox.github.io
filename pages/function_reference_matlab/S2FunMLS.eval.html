evaluate S2F by moving least squares

The optional fourth output contains accumulated neighborhood warnings. When it is requested, the warnings are returned but not printed. This is used by nested evaluations in eval_range.

Syntax

{% highlight matlab %} [vals, conds, info, warnings] = eval(S2F, v, varargin) {% endhighlight %}
