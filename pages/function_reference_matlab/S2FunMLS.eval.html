evaluate S2F on v via moving least squares (MLS) approximation also returns the condition of the (regularized) local least squares problems

Syntax

{% highlight matlab %} vals = S2F.eval(v) vals = eval(S2F,v) {% endhighlight %}

Input

S2F S2FunMLS
v vector3d the evaluation directions

Output

vals values of the MLS approximation S2F on v
conds condition of the solved local least squares problems
info struct with additional regularization data
