regular grid in Euler orientation space

Syntax

{% highlight matlab %} SO3G = regularSO3Grid(cs) {% endhighlight %}
{% highlight matlab %} SO3G = regularSO3Grid(cs,ss,'resolution',2.5*degree) {% endhighlight %}

Specify the resolution.

{% highlight matlab %} SO3G = regularSO3Grid(cs,ss,'resolution',5*degree,'ZYZ') {% endhighlight %}

Use ZYZ convention.

{% highlight matlab %} SO3G = regularSO3Grid(cs,ss,'phi2','sections',10) {% endhighlight %}

10 phi2 sections.

{% highlight matlab %} SO3G = regularSO3Grid('ClenshawCurtis','bandwidth',64) {% endhighlight %}

Input

cs crystalSymmetry
ss specimenSymmetry

Options

resolution Euler angle resolution
sections number of sections

Flags

phi1 | Phi | phi2 sections along which variable

Output

SO3G orientation
