class representing the different Bravais lattices

An enumeration, so a lattice can be compared against its name - cs.lattice == 'hexagonal' - and carries the conventions that follow from it, above all the default axis angles and whether the three or four digit Miller notation applies.

Syntax

{% highlight matlab %} l = latticeType.hexagonal l = cs.lattice {% endhighlight %}

Class Properties

triclinic, monoclinic, orthorhombic, trigonal, tetragonal, hexagonal,
cubic, none, icosahedral the enumeration members
