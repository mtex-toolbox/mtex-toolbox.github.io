--- title: "mtexCifPath" sidebar: function_reference_sidebar permalink: mtexCifPath.html folder: function_reference toc: false --- mtexCifPath edit page

returns the default path to crystallographic information files (CIF)

Syntax

{% highlight matlab %} mtexCifPath {% endhighlight %}
{% highlight matlab %} getMTEXpref('CIFPath') {% endhighlight %}

Long form of mtexCifPath.

{% highlight matlab %} setMTEXpref('CIFPath',path) {% endhighlight %}

Change the path to CIF files.
