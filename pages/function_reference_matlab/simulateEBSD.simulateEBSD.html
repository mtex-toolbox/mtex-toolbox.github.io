Class guiding through the simple simulation of an EBSD object

Description

It allows to simulate a single/multigradient EBSD map with a free choice of the starting orientation, size, misorientation axis, direction of misorientaiton increase, type and range of noise Multiple gradients can be superposed and you can use an existing map and add noise or deform it.

Syntax

{% highlight matlab %} ebsdSIM = simulateEBSD {% endhighlight %}

Initialize the object.

{% highlight matlab %} ebsdSIM.xdim = 50 ebsdSIM.ydim = 50 {% endhighlight %}

Set the dimension (optional).

{% highlight matlab %} ebsdSIM.ori0 = orientation.byEuler([0, pi, 30]*degree,ebsdSIM.CS) {% endhighlight %}

Change the initial orientation (optional).

{% highlight matlab %} ebsdSIM.makeMap plot(ebsdSIM.EBSDsim) {% endhighlight %}

Make a planar map.

{% highlight matlab %} ebsdSIM.axS = vector3d(1,1,0) {% endhighlight %}

1) create a simple gradient. 1a) set the misorientation axis.

{% highlight matlab %} ebsdSIM.gradDir = vector3d(1,0,0); {% endhighlight %}

1b) set the direction towards which the misorientation increases.

{% highlight matlab %} ebsdSIM.addFeature_simpleGradient {% endhighlight %}

1c) create the gradient.

{% highlight matlab %} ebsdSIM.noiseFun = 'logn' {% endhighlight %}

2) add noise. 2a) specify noise type: 'uniform' or 'logn'.

{% highlight matlab %} ebsdSIM.noiseMax = 0.1*degree; {% endhighlight %}

2b) specify maximum noise.

{% highlight matlab %} ebsdSIM.addnoise {% endhighlight %}

2c) create noise.

{% highlight matlab %} ebsdSIM.axS = vector3d(1,1,1) {% endhighlight %}

3) add a circular "subgrain". 3a) set the misorientation axis.

{% highlight matlab %} ebsdSIM.addFeature_circularSubgrain {% endhighlight %}

3b) add "subgrain".

{% highlight matlab %} ebsd = ebsdSIM.EBSDsim; plot(ebsd,angle(ebsd.orientations,ebsd.orientations(1))/degree) nextAxis ebsd = ebsd.gridify plot(ebsd,ebsd.gradientX.norm) nextAxis plot(ebsd,ebsd.gradientY.norm) nextAxis sax = axis(ebsd(1).orientations,ebsd.orientations) ck= HSVDirectionKey(specimenSymmetry('1')) plot(ebsd,ck.direction2color(sax)) nextAxis plot(ck) {% endhighlight %}
