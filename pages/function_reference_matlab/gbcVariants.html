gbcVariants grain boundary criterion from variant ids

Two neighbouring measurements belong to the same grain iff they carry the same variant id. Used for variant-based (parent/child) grain computation.

Syntax

{% highlight matlab %} criterion = gbcVariants('variants',ids); out = criterion.eval(ebsd,i,j); {% endhighlight %}

Output

out = 1 same variant id (same grain) out = 0 grain boundary
ids is a per pixel array (one row per measurement); several columns are allowed and all must match.
