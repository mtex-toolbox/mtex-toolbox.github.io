function to fit Bingham parameters

Description

confidence ellipse for the mean direction based on Tanaka / asymptotic covariance of the maximum eigenvector (1999) https://doi.org/10.1186/BF03351601

Syntax

{% highlight matlab %} BS2 = S2FunBingham.fit(v) [BS2, ab, rot] = S2FunBingham.fit(v,'p',0.95) {% endhighlight %}

Input

v vector3d

Output

BS2 S2FunBingham
ab semi axes length of the confidence ellipse (in radian)
rot orientation of the confidence ellipse, to be used with |ellipse|

Options

p confidence level p of the ellipse computed (default at 0.95)

Example

simulate some directions

{% highlight matlab %} odf = unimodalODF(quaternion.id,'halfwidth',10*degree); N = 100; v = odf.discreteSample(N) .* ... rotation.byAxisAngle(vector3d.X,rand(N,1)*2*pi) * vector3d.Y; {% endhighlight %}

fit a Bingham distribution

{% highlight matlab %} [S2F, ab, rot] = S2FunBingham.fit(v) {% endhighlight %} {% highlight plaintext %} S2F = S2FunBingham (y↓→x) ab = 0.0507 2.1552 rot = rotation Bunge Euler angles in degree phi1 Phi phi2 165.975 11.1085 195.629 {% endhighlight %}

visualization

{% highlight matlab %} plot(S2F) mtexColorMap LaboTeX hold on plot(v,'Markercolor','k','MarkerSize',3) ellipse(rot,ab(1),ab(2)) hold off {% endhighlight %}
