function to fit Bingham parameters

Description

confidence ellipse for the mean direction based on Tanaka / asymptotic covariance of the maximum eigenvector (1999) https://doi.org/10.1186/BF03351601

Syntax

{% highlight matlab %} BS2 = S2FunBingham.fit(v) [BS2, ab, rot] = S2FunBingham.fit(v,'p',0.95) {% endhighlight %}

Input

v vector3d

Output

BS2 S2FunBingham
ab semi axes length of the confidence ellipse (in radian)
rot orientation of the confidence ellipse, to be used with |ellipse|

Options

p confidence level p of the ellipse computed (default at 0.95)

Example

simulate some directions

{% highlight matlab %} v = discreteSample(S2FunBingham([-10 -4 0]),50); {% endhighlight %}

fit a Bingham distribution

{% highlight matlab %} [S2F, ab, rot] = S2FunBingham.fit(v) {% endhighlight %} {% highlight plaintext %} S2F = S2FunBingham (y↓→x) ab = 0.1062 0.2124 rot = rotation Bunge Euler angles in degree phi1 Phi phi2 Inv. 8.45587 170.693 15.2773 1 {% endhighlight %}

visualization

{% highlight matlab %} plot(S2F) mtexColorMap LaboTeX hold on plot(v,'Markercolor','k','MarkerSize',3) ellipse(rot,ab(1),ab(2),'linewidth',2) hold off {% endhighlight %}
