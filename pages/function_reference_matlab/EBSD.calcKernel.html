compute an optimal kernel function for ODF estimation from EBSD data

Neighbouring pixels of one grain are not independent observations of the texture. The halfwidth is therefore selected from the energies of parts of the map that share no grain, which needs the grainId of every pixel.

Syntax

{% highlight matlab %} [grains,ebsd.grainId] = calcGrains(ebsd); psi = calcKernel(ebsd('Forsterite')) psi = calcKernel(ebsd('Forsterite'),'method','conservative') {% endhighlight %}

Input

ebsd EBSD of one phase with grainId

Output

psi SO3DeLaValleePoussinKernel

Options

method |'UCV'| (default) or |'conservative'|, see selectHalfwidth
