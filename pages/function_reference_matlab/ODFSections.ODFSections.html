an abstract class representing sections through orientation space

Orientation space is three dimensional, so plotting an ODF means slicing it. A deriving class fixes how the slices are cut and how an orientation is projected into a slice; everything the plotting needs - the grid, the projection, the axes labels - is asked through this interface.

Syntax

{% highlight matlab %} oS = axisAngleSections(cs,cs) {% endhighlight %}

Construct sections using a derived class.

Class Properties

CS1, CS2 the two symmetry
CS, SS crystal and specimen symmetry
tol tolerance an orientation may deviate from a section
plotGrid the grid the section is evaluated on
gridSize number of points per section

Example

colour axis-angle sections by misorientation and plot individual orientations

{% highlight matlab %} cs = crystalSymmetry('222') oS = axisAngleSections(cs,cs); {% endhighlight %} {% highlight plaintext %} cs = crystalSymmetry (⊙c→a) symmetry: 222 elements: 4 a, b, c : 1, 1, 1 {% endhighlight %}

colour the sections by a misorientation colour key

{% highlight matlab %} ori = oS.makeGrid('resolution',2.5*degree); oM = PatalaColorKey(cs,cs) rgb = oM.orientation2color(ori); plot(oS,rgb,'surf') {% endhighlight %} {% highlight plaintext %} oM = PatalaColorKey (222 → 222) antipodal: true {% endhighlight %}

plot orientations into the sections

{% highlight matlab %} ori = orientation.rand(100,cs,cs) plot(oS,ori) {% endhighlight %} {% highlight plaintext %} ori = misorientation (222 → 222) size: 100 × 1 {% endhighlight %}
