standard output

A mapImage is almost always held as a sequence, so this is a table of the sequence rather than a dump of one object: how big each image is, how big its pixels are, which frame it is expressed in and which layout its array is stored in. Two entries are comparable pixel by pixel only where the layouts agree, so that column is the quick check that alignment worked.
