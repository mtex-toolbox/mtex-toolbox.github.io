converts directions to rgb values as HKL Channel 5 does

Syntax

{% highlight matlab %} dM = HKLDirectionKey(cs) rgb = dM.direction2color(h) {% endhighlight %}

Input

cs crystalSymmetry
h Miller

Output

dM HKLDirectionKey
rgb list of RGB triplets

Class Properties

sym the Laue group of cs
sR the fundamental sector
