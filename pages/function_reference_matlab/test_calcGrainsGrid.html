smoke test for the grid pipeline WITHOUT requiring MTEX

Builds a tiny fake gridded object exposing just the fields the grid code touches (pos, unitCell, phaseId, isIndexed, rotations), runs spatialDecompositionGrid + doGridSegmentation, and checks invariants. Requires jcvoronoi2_mex on the path (mex jcvoronoi2_mex.cpp).
