the reference frame a sample is expressed in

Named instances make moving between specimen frames an explicit operation: the measurement frame of the instrument (X, Y, Z), the rolling frame (RD, TD, ND), the geological frame. The named factories return the one session instance from the register (referenceFrame.byName); calling the constructor directly always makes a fresh, unregistered frame. The axes names are identity and display only for now - nothing else consumes them yet.

Syntax

{% highlight matlab %} sF = specimenFrame.specimen {% endhighlight %}

The generic frame X, Y, Z.

{% highlight matlab %} sF = specimenFrame.measurement {% endhighlight %}

The instrument frame X1, Y1, Z1.

{% highlight matlab %} sF = specimenFrame.rolling sF = specimenFrame.geological {% endhighlight %}
{% highlight matlab %} sF = specimenFrame.default {% endhighlight %}

Supplies the default convention.

{% highlight matlab %} specimenFrame.rolling.makeDefault {% endhighlight %}

The session plots RD north.

{% highlight matlab %} sF = specimenFrame('rolling','axesNames',{'RD','TD','ND'},how2plot) {% endhighlight %}

A fresh frame, name first, optionally with axes names and convention.

Input

how2plot plottingConvention

Class Properties

axesNames names of the three axes, default {'X','Y','Z'}
