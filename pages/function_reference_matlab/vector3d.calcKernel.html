--- title: 'vector3d.calcKernel' sidebar: function_reference_sidebar permalink: vector3d.calcKernel.html folder: function_reference toc: false --- vector3d.calcKernel edit page

compute an optimal kernel function for the density estimation of directions

Syntax

{% highlight matlab %} psi = calcKernel(v) psi = calcKernel(v,'method','conservative') sF = calcDensity(v,'kernel',calcKernel(v)) {% endhighlight %}

Input

v vector3d, Miller

Output

psi S2DeLaValleePoussinKernel

Options

method |'UCV'| (default) or |'conservative'|, see selectHalfwidth
weights weights of the directions
