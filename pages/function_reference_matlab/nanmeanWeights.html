--- title: 'nanmeanWeights' sidebar: function_reference_sidebar permalink: nanmeanWeights.html folder: function_reference toc: false --- nanmeanWeights edit page

weighted mean value ignoring NaNs

Syntax

{% highlight matlab %} y = nanmeanWeights(x,weights) {% endhighlight %}

Along the first non-singleton dimension.

{% highlight matlab %} y = nanmeanWeights(x,weights,dim) {% endhighlight %}

Along dimension dim.

Input

x numeric array
weights numeric array of the size of x
dim dimension to average along

Output

y weighted mean of the entries of x that are not NaN, NaN where all of them are
