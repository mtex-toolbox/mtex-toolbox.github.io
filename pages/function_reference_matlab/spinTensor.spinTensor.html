--- title: 'spinTensor.spinTensor' sidebar: function_reference_sidebar permalink: spinTensor.spinTensor.html folder: function_reference toc: false --- spinTensor.spinTensor edit page

skew symmetric rank two tensor describing an infinitesimal rotation

Syntax

{% highlight matlab %} Omega = spinTensor(v) {% endhighlight %}

The skew symmetric matrix of the vector v.

{% highlight matlab %} Omega = spinTensor(S) {% endhighlight %}

The skew symmetric part of a rank two tensor.

{% highlight matlab %} Omega = spinTensor(rot) {% endhighlight %}

The matrix logarithm of a rotation.

{% highlight matlab %} Omega = spinTensor(mori) {% endhighlight %}

The matrix logarithm of a misorientation.

Input

S skew symmetric matrix
v vector3d
rot rotation
mori misorientation
