the web browser of MATLAB's web function

Description

MTEX's copy of MATLAB's docopt: on Unix it returns firefox as the browser, on a Mac and on Windows an empty command, which leaves the choice to MATLAB.

Syntax

{% highlight matlab %} [doccmd,options,docpath] = docopt {% endhighlight %}

Output

doccmd command that starts the web browser
options options of the browser command, empty
docpath path of the documentation, empty
