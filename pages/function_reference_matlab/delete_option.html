clear options in option list

All occurrences of the options are removed, together with the nparams entries following each option name.

Syntax

{% highlight matlab %} option_list = delete_option(option_list,{option1,option2,option3,...}) option_list = delete_option(option_list,option,nparams) {% endhighlight %}

Input

option_list cell array
options option name(s), string or cell array of names
nparams number of values to delete along with the option name,
default 0, either a scalar or one entry per option

Output

option_list cell array
