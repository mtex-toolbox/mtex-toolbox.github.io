segment the grid decomposition into grains

Build the site-adjacency graph (sites sharing a Voronoi face), decide per shared face whether it is a grain boundary, and label grains by connected components. gbc(ebsd,i,j) is TRUE where cells i,j belong to the same grain. It is evaluated only on residual indexed pairs (faces between two indexed sites that are NOT grid neighbours); grid-neighbour indexed pairs reuse the dry-run result passed in out.gridSame; notIndexed pairs merge by phase; dummy faces are always boundaries.

Syntax

{% highlight matlab %} [grainId,isBoundaryFace] = doGridSegmentation(out,ebsd,gbc) {% endhighlight %}

Input

out struct from spatialDecompositionGrid (needs extra fields below)
ebsd the same gridified ebsd
gbc gbc(ebsd,i,j) -> TRUE where same grain
out must additionally carry, from the dry run:
out.gridPairs 2 x m linear ebsd ids of indexed grid-neighbour pairs
out.gridSame m x 1 logical, gbc result for those pairs (reused here)

Output

grainId nSites x 1 grain label per site
isBoundaryFace nF x 1 logical, faces that are grain boundaries
