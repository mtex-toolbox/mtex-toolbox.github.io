computes the weighted Burgers vector

Syntax

{% highlight matlab %} W = weightedBurgersVec(ebsd) {% endhighlight %}

Weighted Burgers vector in specimen coordinates.

{% highlight matlab %} W = inv(ebsd.orientations) .* weightedBurgersVec(ebsd) {% endhighlight %}

Weighted Burgers vector in crystal coordinates.

{% highlight matlab %} W = weightedBurgersVec(ebsd,'integral') {% endhighlight %}

Weighted Burgers vector using the integral methods.

Input

ebsd EBSD

Options

integral use integral method
windowSize size of the integral window (default = 1)

Output

W vector3d weighted Burgers vector in specimen coordinates

References

  • The weighted Burgers vector: a new quantity for constraining dislocation densities and types using electron backscatter diffraction on 2D sections through crystalline materials, J. Microscopy, 2009.
