overload the / operator, i.e. one can now write S1Fun / 2 in order to scale an S1Fun.

x = sF / s solves the system of linear equations x*s = sF for a S1Fun x.

Syntax

{% highlight matlab %} sF = sF / 2 {% endhighlight %}

Input

sF S1Fun
s constant, vector

Output
