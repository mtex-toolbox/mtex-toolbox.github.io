nicely reorder grain boundaries

Deprecated. Boundary segments are stored in walk order by default, so there is nothing to reorder. Use grainBoundary/order to re-establish that invariant after modifying F directly.

Syntax

{% highlight matlab %} gB = reorder(gB,varargin) {% endhighlight %}
