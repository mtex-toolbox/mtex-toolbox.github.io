--- title: 'SO3Grid.SO3Grid' sidebar: function_reference_sidebar permalink: SO3Grid.SO3Grid.html folder: function_reference toc: false --- SO3Grid.SO3Grid edit page

represent orientations in a gridded structure to allow quick access

Syntax

{% highlight matlab %} S3G = regularSO3Grid(CS) {% endhighlight %}
{% highlight matlab %} S3G = regularSO3Grid(CS,SS,'resolution',2.5*degree) {% endhighlight %}

Specify the resolution.

{% highlight matlab %} S3G = regularSO3Grid(CS,SS,'resolution',5*degree,'ZYZ') {% endhighlight %}

Use ZYZ convention.

{% highlight matlab %} S3G = regularSO3Grid(CS,SS,'phi2','sections',10) {% endhighlight %}

10 phi2 sections.

{% highlight matlab %} S3G = regularSO3Grid S3G = equispacedSO3Grid(CS,SS,'points',n) S3G = equispacedSO3Grid(CS,'resolution',res) {% endhighlight %}
{% highlight matlab %} S3G = equispacedSO3Grid(CS,'maxAngle',20*degree) {% endhighlight %}

Fill only a ball with radius of 20 degree.

Input

CS crystalSymmetry
SS specimenSymmetry
n approximate number of points
res resolution in radiant

Options

maxAngle radius of the ball to be filles
center center of the ball
sections number of sections

Flags

phi1 | Phi | phi2 sections along which variable

Output

S3G SO3Grid
