gbcAngle Misorientation-angle grain boundary criterion

Syntax

{% highlight matlab %} criterion = gbcAngle; criterion = gbcAngle(10*degree); criterion = gbcAngle('threshold',10*degree); {% endhighlight %} {% highlight matlab %} out = criterion.evaluate(ebsd,i,j); {% endhighlight %}

Output

out = 1 no boundary < -> angle < low
out = 0.5 low angle boundary <--> low <= angle < high
out = 0 high angle boundary angle = high
