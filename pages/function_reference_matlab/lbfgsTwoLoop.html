the two loop recursion of L-BFGS

Applies the inverse Hessian approximation built from the secant pairs in S and Y to the gradient g without ever forming a matrix - only inner products of the stored vectors are needed. An empty memory gives the negative gradient, i.e. the step of steepest descent.

Syntax

{% highlight matlab %} d = lbfgsTwoLoop(g,S,Y) {% endhighlight %}

Input

g gradient, as a column
S, Y the steps taken and the changes of the gradient, one pair per column

Output

d descent direction
