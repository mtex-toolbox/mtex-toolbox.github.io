a hexagonal grid has only one matrix layout

Description

A hexagonal grid encodes the alternating offset of its lines in the matrix layout, so unlike an EBSDsquare it cannot be reindexed into another one.

Syntax

{% highlight matlab %} ebsd = transformReferenceFrame(ebsd,gridLayout.columnMajor) {% endhighlight %}

Input

ebsd EBSDhex
gL gridLayout, has to be the column major layout

Output

ebsd EBSDhex, unchanged
