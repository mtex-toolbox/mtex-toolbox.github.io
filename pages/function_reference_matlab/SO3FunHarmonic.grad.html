gradient of an SO3Fun

Syntax

{% highlight matlab %} G = SO3F.grad {% endhighlight %}

Compute the gradient.

{% highlight matlab %} g = SO3F.grad(rot) {% endhighlight %}

Evaluate the gradient in rot.

{% highlight matlab %} ori_new = exp(5*degree*normalize(g),rot) {% endhighlight %}

Go 5 degree in direction of the gradient.

{% highlight matlab %} g = SO3F.grad(rot,SO3TangentSpace.rightVector) {% endhighlight %}

The right tangent vector.

Input

SO3F SO3FunHarmonic
rot rotation / orientation

Output

G SO3VectorFieldHarmonic
g vector3d
