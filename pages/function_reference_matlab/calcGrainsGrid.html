calcGrains integration sketch for the grid-based reconstruction

This is NOT a drop-in replacement yet — it shows how the grid path replaces the current two-Voronoi-pass structure in EBSD/calcGrains.m for gridded square/hex data. The scattered-data path (qhull / spatialDecomposition) is left in place and chosen when the data is not gridified.

Flow (see DESIGN.md): gridify -> spatialDecompositionGrid (dry-run CC + minPixel + alpha partition + Voronoi) -> doGridSegmentation (residual gbc + CC grains) -> assemble grain2d -> write grainId back to ebsd.

Syntax

{% highlight matlab %} [grains,ebsd] = calcGrainsGrid(ebsd,varargin) {% endhighlight %}
