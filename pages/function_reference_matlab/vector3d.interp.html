spherical interpolation - including some smoothing

Syntax

{% highlight matlab %} sF = interp(v,y) {% endhighlight %}
{% highlight matlab %} sF = interp(v,y,'linear') {% endhighlight %}

Linear interpolation (default).

{% highlight matlab %} sF = interp(v,y,'nearest') {% endhighlight %}

Nearest neighbor interpolation.

{% highlight matlab %} sF = interp(v,y,'spline') {% endhighlight %}

Spline interpolation (default).

{% highlight matlab %} sF = interp(v,y,'inverseDistance') {% endhighlight %}

Inverse distance interpolation.

{% highlight matlab %} sF = interp(v,y,'harmonic') {% endhighlight %}

Approximation with spherical harmonics.

{% highlight matlab %} yi = interp(v,y,vi) {% endhighlight %}
{% highlight matlab %} yi = interp(v,y,vi,'spline') {% endhighlight %}

Spline interpolation (default).

{% highlight matlab %} yi = interp(v,y,vi,'linear') {% endhighlight %}

Linear interpolation.

{% highlight matlab %} yi = interp(v,y,vi,'nearest') {% endhighlight %}

Nearest neighbor interpolation.

{% highlight matlab %} yi = interp(v,y,vi,'inverseDistance') {% endhighlight %}

Inverse distance interpolation.

{% highlight matlab %} yi = interp(v,y,vi,'harmonic') {% endhighlight %}

Approximation with spherical harmonics.

Input

v data points vector3d
y data values (double, vector3d)
vi interpolation points vector3d

Output

sF S2Fun
yi interpolation values
