--- title: "SO3Fun.plot" sidebar: function_reference_sidebar permalink: SO3Fun.plot.html folder: function_reference toc: false --- SO3Fun.plot edit page

plots odf or append to a previous plot using 'add2all'

Syntax

{% highlight matlab %} plot(odf) {% endhighlight %}

Plot in phi2 sections.

{% highlight matlab %} plot(odf,'phi2',45*degree) {% endhighlight %}

Plot in specific phi2 sections.

{% highlight matlab %} plot(odf,'axisAngle') plot(odf,'rodrigues') {% endhighlight %}

Plot in 3d space.

{% highlight matlab %} f = fibre.alpha(odf.CS) plot(odf,f) {% endhighlight %}

Plot along a fibre.

{% highlight matlab %} oS = sigmaSections(odf.CS) plot(odf,oS) {% endhighlight %}

Plot the odf as sigma sections.
