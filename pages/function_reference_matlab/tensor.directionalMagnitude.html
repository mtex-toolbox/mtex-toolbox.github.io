magnitude of a tensor in direction v

Description

The tensor is contracted with the direction in every index,

\[ q = T_{i_1 i_2 \ldots i_d} v_{i_1} v_{i_2} \cdots v_{i_d}. \]

Syntax

{% highlight matlab %} q = directionalMagnitude(T,v) {% endhighlight %}

Magnitude in the directions v.

{% highlight matlab %} S2F = directionalMagnitude(T) {% endhighlight %}

Magnitude as a function on the sphere.

Input

T tensor
v direction (vector3d / Miller)

Output

q magnitude of a tensor in direction v
