--- title: "EBSDsquare.EBSDsquare" sidebar: function_reference_sidebar permalink: EBSDsquare.EBSDsquare.html folder: function_reference toc: false --- EBSDsquare.EBSDsquare edit page

EBSD data on a rectangular grid. In contrast to arbitrary EBSD data the values are stored in a matrix.

pos(i,j) is affine in (i,j) here - the grid may be rotated or sheared, but the step between adjacent entries is the same everywhere, which is what separates this from EBSDhex.

In practice this class is not constructed directly but by gridify.

Syntax

{% highlight matlab %} ebsd = gridify(ebsd) ebsd = EBSDsquare(pos,rot,phaseId,phaseMap,CSList) {% endhighlight %}

Input

pos vector3d, one per grid point
rot rotation, in matrix layout
phaseId phase as index to CSList
phaseMap convert between phase = phaseMap(phaseId)
CSList cell list of crystalSymmetry

Output

ebsd EBSDsquare

Class Properties

gradient1 orientation gradient along the first grid dimension
gradient2 orientation gradient along the second grid dimension
d1, d2 vector3d, directions of the two grid dimensions
layout gridLayout, d1 and d2 in the order the map is stored
