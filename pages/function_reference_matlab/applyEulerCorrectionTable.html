apply a 4-setting Euler / map reference frame correction

Shared by EDAX-style formats (.ang, .osc, .edaxh5) that expose the Euler - map alignment as a "setting" 1 to 4. Since the setting is not stored in the file, setting 2 is assumed and a note is printed - unless the user states the alignment or the import wizard did it already.

Syntax

{% highlight matlab %} ebsd = applyEulerCorrectionTable(ebsd,ext,varargin{:}) {% endhighlight %}

Input

ebsd EBSD
ext file extension used in the note, e.g. '.ang'

Options

setting 0 (no correction) to 4, default is 2
EulerCorrection explicit correction rotation, overrides setting
wizard suppress the note about the assumed setting
