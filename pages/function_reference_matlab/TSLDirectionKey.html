--- title: "TSLDirectionKey" sidebar: function_reference_sidebar permalink: TSLDirectionKey.html folder: function_reference toc: false --- TSLDirectionKey edit page

converts directions to rgb values as TSL / OIM does

In the TSL coloring every fundamental sector is white in its center, not at a vertex, which is the visible difference to the MTEX default.

Syntax

{% highlight matlab %} dM = TSLDirectionKey(cs) rgb = dM.direction2color(h) {% endhighlight %}

Input

cs crystalSymmetry
h Miller

Output

dM TSLDirectionKey
rgb list of RGB triplets

Class Properties

sym the Laue group of cs
sR the fundamental sector
