--- title: 'loadEBSD_h5' sidebar: function_reference_sidebar permalink: loadEBSD_h5.html folder: function_reference toc: false --- loadEBSD_h5 edit page

read EBSD data from the HDF5 files of the vendors

Description

The reader works as follows:

* the file is matched against the configurations in interfaces/hdf5_config,
by the manufacturer stated in the file or by the option 'type'
* the configuration names the groups holding the EBSD data; an error is
thrown if there is no such data
* the data are extracted as the configuration says and converted into an
<EBSD.EBSD.html EBSD> map

Every per pixel data set the config does not read itself becomes a property of the map. For an Oxford file that includes the EDS element maps stored next to the EBSD data set, e.g. plot(ebsd, ebsd.Fe_WindowIntegral_Ka1) - the element comes first and the subgroup they are sorted into is part of the property name, since a quantified map holds a "Fe Ka1" both as a window integral and as a peak area. The EDS header - beam voltage, detector geometry, channel width - comes along as ebsd.opt.eds.header.

Syntax

{% highlight matlab %} ebsd = EBSD.load(fname) {% endhighlight %}

The map of an HDF5 file.

{% highlight matlab %} ebsd = EBSD.load(fname,'dataSet',2) {% endhighlight %}

The second data set of the file.

{% highlight matlab %} ebsd = EBSD.load(fname,'dataSet','OIM Map 2') {% endhighlight %}

The data set of this name.

{% highlight matlab %} ebsd = EBSD.load(fname,'headerOnly') {% endhighlight %}

The phases and the data sets only.

Input

fname file name

Options

dataSet which data set to import from a file that holds several of them, either as the number shown in the list printed on import, or as (part of) its name, e.g. EBSD.load(fname,'dataSet',2) or EBSD.load(fname,'dataSet','OIM Map 2'). Oxford files may hold a map twice, as recorded by the detector under "EBSD" and as cleaned up by the vendor software under "Data Processing" - both are offered as data sets and the cleaned up one is imported unless the other one is asked for, EBSD.load(fname,'dataSet','EBSD')
type the configuration to use, by one of its manufacturer keys, e.g. 'Oxford_EBSD', instead of detecting it
debug report the steps of the import

Flags

headerOnly return only phase/header metadata, skip reading the (potentially large) per-pixel position/rotation/phase data and any other top-level category (e.g. electron images). Also lists the data sets the file contains.

Output

ebsd EBSD
