global, local and pointwise maxima of spherical functions

Syntax

{% highlight matlab %} [v,pos] = max(sF) {% endhighlight %}

The position where the maximum is atained.

{% highlight matlab %} [v,pos] = max(sF,'numLocal',5) {% endhighlight %}

The 5 largest local maxima.

{% highlight matlab %} sF = max(sF, c) {% endhighlight %}

Maximum of a spherical functions and a constant.

{% highlight matlab %} sF = max(sF1, sF2) {% endhighlight %}

Maximum of two spherical functions.

{% highlight matlab %} sF = max(sF1, sF2, 'bandwidth', bw) {% endhighlight %}

Specify the new bandwidth.

{% highlight matlab %} sF = max(sFmulti,[],dim) {% endhighlight %}

Compute the maximum of a vector valued function along dim.

Input

sF, sF1, sF2 S2Fun
sFmulti a vector valued S2Fun
c double

Options

kmax number of iterations
numLocal number of peaks to return
startingNodes vector3d
tolerance minimum distance between two peaks
resolution minimum step size
maxStepSize maximm step size

Output

v double
pos vector3d
