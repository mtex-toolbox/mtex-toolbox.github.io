--- title: 'axesRatio' sidebar: function_reference_sidebar permalink: axesRatio.html folder: function_reference toc: false --- axesRatio edit page

height to width ratio an axis should be shaped with

The shape comes from the camera, not from the data: an axis is as wide and as high as the shadow its plot box casts along the viewing direction.

Syntax

{% highlight matlab %} ratio = axesRatio(ax) {% endhighlight %}

Input

ax axes handle

Output

ratio height / width
