--- title: "mtexShowDoc" sidebar: function_reference_sidebar permalink: mtexShowDoc.html folder: function_reference toc: false --- mtexShowDoc edit page

open a page of the MTEX documentation, installed copy or online

Description

The HTML documentation is generated by makeDoc and ships with a release, but doc/html is not part of the repository, and even a local build does not contain every page. A link into it then points at a file that is not there and clicking it does nothing at all - no page, no message. So a page that is not installed is looked up online instead, which keeps the links in the command window working for everyone running MTEX from a clone.

Syntax

{% highlight matlab %} mtexShowDoc('EBSDReferenceFrame') url = mtexShowDoc('EBSDReferenceFrame') % resolve only, do not open {% endhighlight %}

Input

page name of the documentation page, with or without the .html suffix

Output

url where the page was looked up; asking for it opens nothing
