--- title: 'parseXML' sidebar: function_reference_sidebar permalink: parseXML.html folder: function_reference toc: false --- parseXML edit page

convert an XML file to a MATLAB structure

Every node becomes a struct with the fields Name, Attributes, Data and Children; the attributes are a struct array with the fields Name and Value.

Syntax

{% highlight matlab %} s = parseXML(filename) {% endhighlight %}

The tree of the XML file as nested structs.

Input

filename name of the XML file

Output

s struct array with the fields Name, Attributes, Data and Children
