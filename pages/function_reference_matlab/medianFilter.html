--- title: "medianFilter" sidebar: function_reference_sidebar permalink: medianFilter.html folder: function_reference toc: false --- medianFilter edit page

replaces every orientation by the median of its neighbourhood

Unlike meanFilter this one removes single wild pixels without pulling the boundary along, but it is not yet fully supported on hexagonal grids.

Syntax

{% highlight matlab %} F = medianFilter F = medianFilter('neighbours',2) ebsd = smooth(ebsd,F) {% endhighlight %}

Options

neighbours radius of the window in pixel, 1 by default

Class Properties

numNeighbours radius of the window in pixel
isHex is the map on a hexagonal grid
