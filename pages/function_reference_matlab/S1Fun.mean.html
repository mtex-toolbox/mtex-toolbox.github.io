mean value of a S1Fun or along a dimension of a vector-valued S1Fun

\[ v = \frac{1}{2\pi} \int_{0}^{2\pi} f( o ) do \]

Description

If sF is a 3x3 S1Fun then mean(sF) returns a 3x3 matrix with the mean values of each function mean(sF, 1) returns a 1x3 S1Fun which contains the pointwise mean values along the first dimension

Syntax

{% highlight matlab %} value = mean(sF) value = mean(sF,'resolution',0.1*degree) sF = mean(sF, d) {% endhighlight %}

Input

sF S1Fun
d dimension to take the mean value over

Options

resolution spacing of the quadrature nodes, default 0.3 degree

Output

value double
sF S1Fun

Example

a scalar valued function

{% highlight matlab %} sF = S1FunHandle(@(o) sin(o).^2) mean(sF) {% endhighlight %} {% highlight plaintext %} sF = S1FunHandle eval: @(o)sin(o).^2 ans = 0.5000 {% endhighlight %}

a vector valued function

{% highlight matlab %} sF = S1FunHandle(@(o) [sin(o).^2, cos(2*o).^2, 1+0*o]) mean(sF) mean(sF,1) {% endhighlight %} {% highlight plaintext %} sF = S1FunHandle size: 3 × 1 eval: @(o)[sin(o).^2,cos(2*o).^2,1+0*o] ans = 0.5000 0.5000 1.0000 ans = S1FunHandle eval: @(o)mean(sF.eval(o),varargin{1}+1) {% endhighlight %}
