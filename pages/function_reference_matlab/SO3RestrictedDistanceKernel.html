--- title: "SO3RestrictedDistanceKernel" sidebar: function_reference_sidebar permalink: SO3RestrictedDistanceKernel.html folder: function_reference toc: false --- SO3RestrictedDistanceKernel edit page

The rotational restricted distance kernel is defined by

\[ K(t) = -\sqrt{8}\sin(\acos(t))\]

for \(t\in[0,1]\). This kernel is negative and describes the distance between two given orientations, by K.eval(angle(R,Q)). It is used in the compactify method to ensure that the points repel each other and do not overlap.

Syntax

{% highlight matlab %} psi = SO3RestrictedDistanceKernel(bw) {% endhighlight %}

Input

bw bandwidth

Output

psi SO3Kernel
