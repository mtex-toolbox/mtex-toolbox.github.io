an abstract class representing kernel functions on the circle

A kernel on the circle is a nonnegative even function concentrated at 0, stored as an S1FunHarmonic. Deriving classes give its Fourier coefficients a closed form; the halfwidth and the arithmetics come from here.

Syntax

{% highlight matlab %} psi = S1Kernel(fhat) {% endhighlight %}

Input

fhat Fourier coefficients, from degree -N to N

Output

psi S1Kernel

Class Properties

fhat Fourier coefficients
bandwidth maximum harmonic degree
