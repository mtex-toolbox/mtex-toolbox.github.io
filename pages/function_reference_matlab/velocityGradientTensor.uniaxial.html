--- title: "velocityGradientTensor.uniaxial" sidebar: function_reference_sidebar permalink: velocityGradientTensor.uniaxial.html folder: function_reference toc: false --- velocityGradientTensor.uniaxial edit page

defines uniaxial tension/compression tensors

Syntax

{% highlight matlab %} L = r .* velocityGradientTensor.uniaxial(d,q) {% endhighlight %}

Axi symmetric uniaxial tension.

{% highlight matlab %} L = -velocityGradientTensor.uniaxial(d,q) {% endhighlight %}

Uniaxial compression.

Input

d tension direction vector3d
q [0 .. 1] non axial symmetric portion (0.5 is symmetric and default)
r strain rate

Output

L velocityGradientTensor
