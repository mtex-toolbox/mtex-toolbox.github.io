--- title: "crystalFrame.alignment" sidebar: function_reference_sidebar permalink: crystalFrame.alignment.html folder: function_reference toc: false --- crystalFrame.alignment edit page

the alignment of the Cartesian axes as strings, e.g. {'X||a','Z||c*'}

Where a direct and a reciprocal axis coincide - c and c* in a hexagonal lattice, every pair in an orthogonal one - the direct axis is reported, so the result does not depend on rounding noise in the basis. For a frame with mutually orthogonal axes nothing is worth reporting and the result is empty - the same rule crystalSymmetry/alignment always used.

Syntax

{% highlight matlab %} str = alignment(cF) {% endhighlight %}
