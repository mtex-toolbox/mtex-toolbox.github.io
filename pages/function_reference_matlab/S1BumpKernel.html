The Bump kernel is a function depending on the halfwidth \(r\in (0,pi)\). The function value is 0, if the angle is greater then the halfwidth \(r\). Otherwise it is 1.

Syntax

{% highlight matlab %} psi = S1BumpKernel(10*degree) psi = S1BumpKernel('halfwidth',10*degree) {% endhighlight %}

Options

halfwidth angle at which the kernel function has reduced to half its peak value
bandwidth harmonic degree
