a class representing a vector field on the sphere by a function handle

Syntax

{% highlight matlab %} vF = S2VectorFieldHandle(fun) {% endhighlight %}

Input

fun @function_handle taking a vector3d and returning a vector3d

Output

vF S2VectorFieldHandle

Class Properties

fun @function_handle
antipodal vF(v) = vF(-v)

Example

{% highlight matlab %} vF = S2VectorFieldHandle(@(v) cross(v,vector3d.Z)) {% endhighlight %} {% highlight plaintext %} vF = S2VectorFieldHandle {% endhighlight %}
