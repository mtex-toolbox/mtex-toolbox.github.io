low discrepancy grid of orientations from a super Fibonacci spiral

The nodes are the super Fibonacci spiral of M. Alexa, Super-Fibonacci Spirals: Fast, Low-Discrepancy Sampling of SO(3), CVPR 2022, restricted to the fundamental region of the given symmetries. In contrast to a lattice the number of nodes is a free parameter. To cover a ball around a single orientation use localOrientationGrid.

Syntax

{% highlight matlab %} S3G = fibonacciSO3Grid(CS) S3G = fibonacciSO3Grid(CS,SS,'points',10000) S3G = fibonacciSO3Grid(CS,SS,'resolution',2.5*degree) {% endhighlight %}

Input

CS crystalSymmetry
SS specimenSymmetry

Output

S3G fibonacciSO3Grid

Options

points approximate number of nodes
resolution node spacing in radiant
