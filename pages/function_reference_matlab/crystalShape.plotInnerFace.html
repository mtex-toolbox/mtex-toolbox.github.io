--- title: 'crystalShape.plotInnerFace' sidebar: function_reference_sidebar permalink: crystalShape.plotInnerFace.html folder: function_reference toc: false --- crystalShape.plotInnerFace edit page

plot the section of a crystal shape with a lattice plane

Syntax

{% highlight matlab %} N = Miller(1,0,1,'hkl',cs) plotInnerFace(cS,N,'faceColor','blue','faceAlpha',0.5,'edgeColor','k') {% endhighlight %}

The plane (101) through the centre of the shape, in blue.

Input

cS crystalShape
N Miller lattice plane

Options

PatchProperty all matlab patch properties

Output

h handle to the graphics object

Example

{% highlight matlab %} cS = crystalShape.olivine; N = Miller(1,0,1,'hkl',cS.CS); {% endhighlight %} {% highlight matlab %} plot(cS,'faceAlpha',0.2,'colored') hold on plotInnerFace(cS,N,'faceColor','blue','DisplayName','(101)') plotInnerFace(cS,Miller(0,1,1,cS.CS),'faceColor','red','DisplayName','(011)') hold off {% endhighlight %}
