--- title: 'mtexLayout.apply' sidebar: function_reference_sidebar permalink: mtexLayout.apply.html folder: function_reference toc: false --- mtexLayout.apply edit page

write the plan back, but only what actually moved

Description

Every Position write on an axes fires listeners - scaleBar keeps one on Position and rebuilds itself from it - and a write during a resize can bring the resize callback straight back round. Skipping the writes that would not change anything is what keeps both quiet.

Syntax

{% highlight matlab %} moved = lay.apply(mtexFig,plan) {% endhighlight %}

Output

moved whether anything was written
