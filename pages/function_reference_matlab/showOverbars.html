check whether the command window font centres the overbars

Negative Miller indices and point groups are printed with a combining overline, e.g. 1̅. Only some fonts place this bar centred above the digit. The fonts known to do so are listed in the MTEX preference overbarFonts.

Description

With the option 'cycle' every installed monospaced font is made the command window font in turn, and the sample is printed. Variants such as Light or Bold are skipped, as overbarFonts matches by prefix. Press Enter to go on, y to mark the font as centred, k to keep it as the command window font or q to quit. Unless a font is kept, the initial font is restored at the end.

Syntax

{% highlight matlab %} % print a sample in the current command window font showOverbars {% endhighlight %} {% highlight matlab %} % cycle through all installed monospaced fonts good = showOverbars('cycle') {% endhighlight %} {% highlight matlab %} % hint at showOverbars if the font is not in overbarFonts showOverbars('check') {% endhighlight %}

Output

good fonts marked as centred, added to the preference overbarFonts
