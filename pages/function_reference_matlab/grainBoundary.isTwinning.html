--- title: 'grainBoundary.isTwinning' sidebar: function_reference_sidebar permalink: grainBoundary.isTwinning.html folder: function_reference toc: false --- grainBoundary.isTwinning edit page

find the boundary segments with a given twinning misorientation

Syntax

{% highlight matlab %} ind = isTwinning(gB,mori) {% endhighlight %}

Within 5 degree of mori.

{% highlight matlab %} ind = isTwinning(gB,CSL(3,cs),2*degree) {% endhighlight %}

Within 2 degree of the Sigma 3 misorientation.

Input

gB grainBoundary
mori twinning misorientation
threshold maximum deviation angle, default 5*degree

Output

ind logical, true for the segments whose misorientation lies within threshold of mori

CSL grainBoundary.misorientation
