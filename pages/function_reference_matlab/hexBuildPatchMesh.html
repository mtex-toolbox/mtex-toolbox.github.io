HEXBUILDPATCHMESH Build Faces/Vertices arrays for a complete hex grid.

{% highlight matlab %} mesh = HEXBUILDPATCHMESH(G) mesh = HEXBUILDPATCHMESH(G, 'HexRadius', r, 'HexAngle', a) {% endhighlight %}

Syntax

{% highlight matlab %} mesh = hexBuildPatchMesh(G, varargin) {% endhighlight %}

Input

G Grid struct returned by hexCompleteGrid.
Name Value options
'HexRadius' Hexagon center to-corner radius. Default: G.hexRadius.
'HexAngle' First vertex angle in radians. Default: G.hexAngle.
'HexAngleDeg' Same as HexAngle, but in degrees. Overrides HexAngle.
'StoreSingle' Store Vertices as single precision. Default false.

Output

mesh.faces, mesh.vertices are ready for PATCH.
mesh.fullToOriginal and mesh.originalToFull preserve the index mapping.
