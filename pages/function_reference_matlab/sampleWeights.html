--- title: 'sampleWeights' sidebar: function_reference_sidebar permalink: sampleWeights.html folder: function_reference toc: false --- sampleWeights edit page

the weights of M sampling points, as a probability distribution

Syntax

{% highlight matlab %} c = sampleWeights(M) c = sampleWeights(M,'weights',c) {% endhighlight %}

Input

M number of points

Output

c M × 1, non negative, summing up to 1 - equal when none are given
