orientation gradient in X direction in specimen coordinates

Works on any EBSD, including a rotated or sheared grid - see private/gradientDir for how the lattice basis is inverted.

Syntax

{% highlight matlab %} gX = ebsd.gradientX {% endhighlight %}

Input

ebsd EBSD

Output

gX length(ebsd) × 1 orientation gradient along X
