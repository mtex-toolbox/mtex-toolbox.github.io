global, local and pointwise minima of functions on SO(3)

Syntax

{% highlight matlab %} [v,pos] = min(SO3F) {% endhighlight %}

Global minimum.

{% highlight matlab %} [v,pos] = max(SO3F,'numLocal',5) % the 5 smallest local minima {% endhighlight %}

Local minima.

{% highlight matlab %} SO3F = min(SO3F, c) % pointwise minimum of a SOFun and the constant c SO3F = min(SO3F1, SO3F2) % pointwise minimum of two SOFun SO3F = min(SO3F1, SO3F2, 'bandwidth', bw) % specify the new bandwidth {% endhighlight %}

Pointwise minima.

{% highlight matlab %} [v,pos] = min(SO3Fmulti) {% endhighlight %}

Global minimum of each component of a vector valued function.

{% highlight matlab %} SO3F = min(SO3Fmulti,[],dim) {% endhighlight %}

Pointwise minima of a vector valued function along dim.

Input

SO3F, SO3F1, SO3F2 SO3Fun
SO3Fmulti a vector valued SO3Fun
c double

Options

kmax number of iterations
numLocal number of local minima to return
startingNodes rotation / orientation
tolerance minimum distance between two peaks
resolution minimum step size
maxStepSize maximm step size

Output

v double
pos rotation / orientation
