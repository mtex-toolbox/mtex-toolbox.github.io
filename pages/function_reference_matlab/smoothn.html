robust spline smoothing of 1-D to N-D data

Description

A fast, automatic and robust discretized spline smoothing of uniformly sampled data of arbitrary dimension. Non finite values (NaN or Inf) are treated as missing. Without a smoothing parameter, it is determined by minimizing the generalized cross-validation score. Vector fields or multicomponent data are given as a cell array of their components. The author's original help, kept in the source, lists the details and eight examples.

Syntax

{% highlight matlab %} z = smoothn(y) {% endhighlight %}

Automatic smoothing.

{% highlight matlab %} z = smoothn(y,s) {% endhighlight %}

Smoothing parameter s, the larger the smoother.

{% highlight matlab %} z = smoothn(y,W,s) {% endhighlight %}

With nonnegative weights W of the size of y.

{% highlight matlab %} z = smoothn({Vx,Vy}) {% endhighlight %}

Smooth a vector field.

{% highlight matlab %} z = smoothn(y,'robust') {% endhighlight %}

Minimize the influence of outliers.

{% highlight matlab %} opt = struct('TolZ',1e-3,'MaxIter',100,'Spacing',[1 2]); [z,s,exitflag] = smoothn(y,opt) {% endhighlight %}

Termination of the iteration and spacing of the grid.

Input

y N-D double, or cell array of the components of a vector field
s smoothing parameter, a positive scalar, [] for automatic
W weights, 0 for a missing value
opt struct of options, the last argument

Options

TolZ termination tolerance on z, in ]0,1[ (default 1e-2)
MaxIter maximum number of iterations (default 100)
Initial initial value of the iteration (default y)
Weight weight function of the robust smoothing, 'bisquare' (default), 'talworth' or 'cauchy'
Spacing spacing [d1 d2 ...] of the grid in each dimension
Order order 0, 1 or 2 of the smoothing (default 2)

Flags

robust robust smoothing

Output

z smoothed data
s the smoothing parameter used
exitflag true if the iteration converged
