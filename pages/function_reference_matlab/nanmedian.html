median ignoring NaNs

Syntax

{% highlight matlab %} y = nanmedian(x) {% endhighlight %}

The median along the first non-singleton dimension.

{% highlight matlab %} y = nanmedian(x,dim) {% endhighlight %}

The median along the dimension dim.

Input

x array
dim dimension

Output

y the median of the entries that are not NaN, NaN where all are
