q.^n

For a unit quaternion q the power q.^n is the rotation about the same axis by n times the rotation angle; n may be any real number and an array.

Syntax

{% highlight matlab %} q = q.^n {% endhighlight %}

The power n.

{% highlight matlab %} q = q.^(-1) {% endhighlight %}

The inverse.

{% highlight matlab %} q = q.^2 {% endhighlight %}

Twice the rotation.

{% highlight matlab %} q = q.^[0,1,2,3] {% endhighlight %}

Several powers at once.

Input

q quaternion
n double

Output

q quaternion
