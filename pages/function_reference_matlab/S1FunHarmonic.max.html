global, local and pointwise maxima of periodic functions

Syntax

{% highlight matlab %} [v,pos] = max(fun) % the position where the maximum is atained {% endhighlight %} {% highlight matlab %} [v,pos] = max(fun,'numLocal',5) % the 5 largest local maxima {% endhighlight %} {% highlight matlab %} fun = max(fun, c) % maximum of a spherical functions and a constant fun = max(fun1, fun2) % maximum of two spherical functions fun = max(fun1, fun2, 'bandwidth', bw) % specify the new bandwidth {% endhighlight %} {% highlight matlab %} % compute the maximum of a vector valued function along dim fun = max(funmulti,[],dim) {% endhighlight %}

Input

fun, fun1, fun2 S1Fun
funmulti a vector valued S1Fun
c double

Output

v double
pos double

Options

kmax number of iterations
numLocal number of peaks to return
startingNodes vector3d
tolerance minimum distance between two peaks
resolution minimum step size
maxStepSize maximm step size
