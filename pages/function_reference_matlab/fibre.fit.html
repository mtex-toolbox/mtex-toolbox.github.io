determines the fibre that fits best a list of orientations

Syntax

{% highlight matlab %} f = fibre.fit(ori) {% endhighlight %}

Fit fibre to a list of orientations.

{% highlight matlab %} f = fibre.fit(ori,'local') {% endhighlight %}
{% highlight matlab %} f = fibre.fit(odf) {% endhighlight %}

Fit fibre to a list of orientations.

Input

ori1, ori2, ori orientation
odf SO3Fun

Options

local fast approach for locally concentrated orientations

Output

f fibre
lambda eigenvalues of the orientation tensor
delta mean angle between the orientations and the fitted fibre
