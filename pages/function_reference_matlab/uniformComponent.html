obsolete ODF component, converted into an SO3FunRBF when it is loaded

This class is obsolete since MTEX 5.9. It is kept only so that @ODFs saved by older versions can be loaded; use SO3FunRBF instead.

Syntax

{% highlight matlab %} load('odf.mat','odf') {% endhighlight %}

An ODF saved before MTEX 5.9 is converted while it is loaded.
