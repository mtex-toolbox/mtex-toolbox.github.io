disjoint list of vectors

Syntax

{% highlight matlab %} u = unique(v) {% endhighlight %}

Find disjoint elements of the vector v.

{% highlight matlab %} u = unique(v,'tolerance',0.01) {% endhighlight %}

Use tolerance 0.01.

{% highlight matlab %} [u,iv,iu] = unique(v,varargin)] {% endhighlight %}

Input

v vector3d
tol double (default 1e-7)

Flags

stable prevent sorting
antipodal tread vectors as axes
noAntipodal ignore antipodal symmetry

Output

u vector3d
ir index such that u = r(ir)
iv index such that r = u(iv)
