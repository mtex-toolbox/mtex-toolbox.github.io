--- title: "SO3VectorFieldHarmonic.transformInternTangentSpace" sidebar: function_reference_sidebar permalink: SO3VectorFieldHarmonic.transformInternTangentSpace.html folder: function_reference toc: false --- SO3VectorFieldHarmonic.transformInternTangentSpace edit page

Change the tangent space representation of an harmonic SO3VectorField between left and right. Therefore the bandwidth changes by {+1,0,-1}. We can compute it directly on the harmonic coefficients, since this change of the tangent space basis reads as linear combinations and products with Wigner_D functions of degree 1.

Syntax

{% highlight matlab %} SO3VF = transformInternTangentSpace(SO3VF,varargin) {% endhighlight %}
