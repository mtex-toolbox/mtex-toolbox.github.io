The Riez potential is defined as

q1-q2^2 = q1-q2,q1-q2 = q1^2 + q2^2 - 2<q1,q1> = 2 - 2 cos w/2

We can define the Riesz kernel \(\psi_{s}\) depending on a parameter \(s\) by

\[ \psi_{s}(q_1,q_2) = \frac{1}{\lVert q_1 - q_2 \rVert^s}\].

Syntax

{% highlight matlab %} psi = SO3RieszKernel(s) {% endhighlight %}

Input

s exponent
