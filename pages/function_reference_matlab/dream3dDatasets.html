--- title: 'dream3dDatasets' sidebar: function_reference_sidebar permalink: dream3dDatasets.html folder: function_reference toc: false --- dream3dDatasets edit page

the paths of all data sets of a DREAM.3D file

Description

Neither the names of the data containers nor those of their attribute matrices are fixed, so the importers locate their data by the name of the data set.

Syntax

{% highlight matlab %} ds = dream3dDatasets(fname) {% endhighlight %}

Input

fname file name

Output

ds column of strings
