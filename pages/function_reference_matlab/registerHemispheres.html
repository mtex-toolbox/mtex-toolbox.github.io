mark several axes as the halves of one and the same spherical plot

Description

A spherical region that covers the upper as well as the lower hemisphere is drawn into two axes - but it remains a single plot. Registering the halves with each other is what lets everything that is added later - a circle, a marker, a label - reach both of them, each showing the part of it that falls into its hemisphere.

Syntax

{% highlight matlab %} registerHemispheres([axUpper,axLower]) {% endhighlight %}

Input

ax the axes the halves are drawn into
