Get started

Install MTEX and run your first analysis

MTEX runs in MATLAB and in Python, with the same analysis workflow in both. Install it, load one of the example data sets, import your own file, and follow a tutorial for your kind of data.

MTEX for MATLAB 7.2.0 · Oct 2026

  1. Download and unzip mtex-7.2.0.zip
  2. In MATLAB, change to that folder and run startup_mtex
  3. Try mtexdata titanium, then plot(ebsd)
  4. Import your own file with import_wizard

MATLAB R2022b or newer, no further toolboxes needed. GND and Taylor computations use the Optimization Toolbox.

MTEX for Python 1.0.0 · Python 3.12+

  1. pip install "mtex[all]"
  2. from mtex import *
  3. Try ebsd = mtexdata('titanium'), then plot(ebsd)
  4. Import your own file with ebsd = importWizard()

Linux, macOS and Windows. The Python version needs no MATLAB licence.
