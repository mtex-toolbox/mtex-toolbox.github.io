MTEX manages multiple axes through mtexFigure. It keeps their sizes and spacing consistent. It also coordinates figure-wide tools such as colour ranges and colorbars.

Commands such as plotPDF over several lattice planes, or plot of an ODF in sections, create this kind of figure automatically. To build one by hand, newMtexFigure creates the figure and its layout. The two entries of 'layout' are the number of rows and columns.

{% highlight matlab %} mtexFig = newMtexFigure('layout',[2,3],'figSize','normal'); plottingConvention.default('y↑→x'); plot(vector3d(1,1,1),'upper','MarkerSize',8) {% endhighlight %}
{% include inline_image.html file="Multiplot_01.png" %}

The first direction occupies the upper-left position of the fixed grid.

Fill the axes in sequence

nextAxis without an argument selects the next free axis. The fixed layout fills from left to right and then from top to bottom.

{% highlight matlab %} nextAxis plot(vector3d(-1,1,1),'upper','MarkerSize',8) {% endhighlight %}
{% include inline_image.html file="Multiplot_02.png" %}

The second direction appears beside the first one in the upper row.

Select an axis by row and column

Two arguments select a particular row and column. This makes it possible to fill the layout in any order and to leave positions empty.

{% highlight matlab %} nextAxis(2,3) plot(vector3d.rand(200),'upper') {% endhighlight %}
{% include inline_image.html file="Multiplot_03.png" %}

The cloud appears in the lower-right position. The unused upper-right and lower-middle positions remain empty.

Return to an occupied axis

Calling nextAxis for an occupied position selects that axis again, but selecting is not the same as overlaying. With the hold state off, the next plot command starts a fresh layout and discards the whole gallery rather than repainting one cell. Use hold on to draw into the selected axis and keep the arrangement.

{% highlight matlab %} nextAxis(2,3) hold on plot(vector3d(1,-1,1),'upper','MarkerSize',8) hold off {% endhighlight %}
{% include inline_image.html file="Multiplot_04.png" %}

The single direction now sits on top of the random cloud, and the 2-by-3 arrangement is unchanged. Keep 'upper' when revisiting an upper-hemisphere axis. A full-sphere plot needs separate upper- and lower-hemisphere axes. It therefore changes the arrangement rather than converting this one axis in place.

Mix different kinds of plot

The axes need not contain the same kind of object. Here the lower-left axis shows the symmetry elements of a cubic crystal beside spherical plots of directions. It needs hold on for the same reason as above.

{% highlight matlab %} nextAxis(2,1) hold on plot(crystalSymmetry('432')) hold off {% endhighlight %}
{% include inline_image.html file="Multiplot_05.png" %}

Across the staged figures, every occupied axis keeps the same size while the unused grid positions remain blank. The last addition also shows that a symmetry plot can use the same layout as spherical direction plots. See Spherical Projections for the hemisphere and projection choices used by the spherical axes.

Figure-wide controls

An mtexFigure makes shared controls possible, but it does not make independent data ranges equal automatically. When coloured panels show comparable quantities, set one range after drawing all panels and then add the colorbar:

{% highlight matlab %} setColorRange('equal') mtexColorbar {% endhighlight %}

Color Mapping explains when a common range is required. Annotations covers colorbars and other figure-wide additions. The figure manager also preserves consistent axis sizes after a resize. It provides the cropping used by saveFigure.

Use Combined Plots when the goal is to overlay data. For unrelated MATLAB axes, use subplot or a tiled chart layout instead of an mtexFigure.

Further reading
