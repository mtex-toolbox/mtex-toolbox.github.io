--- title: "Fundamental Regions" sidebar: documentation_sidebar permalink: OrientationFundamentalRegion.html folder: documentation toc: false --- Fundamental Regions edit page

Symmetry makes an orientation a set of equivalent rotations, see Symmetry. A fundamental region is the part of rotation space that contains exactly one member of every such set. It is what makes a plot of orientations unambiguous, and it is the domain on which ODFs, axis distributions and angle distributions are computed.

{% highlight matlab %} plottingConvention.default('y↑→x'); {% endhighlight %}

The Space of All Rotations

Without symmetry, rotation space is a ball of radius \(180^\circ\): the direction of a point is the rotation axis, its distance from the centre the rotation angle.

{% highlight matlab %} % triclinic crystal symmetry cs = crystalSymmetry('triclinic') {% endhighlight %} {% highlight plaintext %} cs = crystalSymmetry (⊙c→b) symmetry : 1̅ elements : 2 a, b, c : 1, 1, 1 alpha, beta, gamma: 90°, 90°, 90° reference frame : {% endhighlight %} {% highlight matlab %} % the corresponding orientation space oR_all = fundamentalRegion(cs); plot(oR_all) {% endhighlight %}
{% include inline_image.html file="OrientationFundamentalRegion_01.png" %}

Rotations placed into it: one by \(180^\circ\) about the z axis, and two families about the x and y axes.

{% highlight matlab %} % rotation about the z-axis about 180 degree rotZ = orientation.byAxisAngle(vector3d.Z,180*degree,cs); hold on plot(rotZ,'MarkerColor','b','MarkerSize',10) hold off {% endhighlight %}
{% include inline_image.html file="OrientationFundamentalRegion_02.png" %}
{% highlight matlab %} % rotations about the x- and y-axis about 30,60,90 ... degree rotX = orientation.byAxisAngle(vector3d.X,(-180:30:180)*degree,cs); rotY = orientation.byAxisAngle(vector3d.Y,(-180:30:180)*degree,cs); hold on plot(rotX,'MarkerColor','r','MarkerSize',10) plot(rotY,'MarkerColor','g','MarkerSize',10) hold off {% endhighlight %}
{% include inline_image.html file="OrientationFundamentalRegion_03.png" %}

Each family lies on a straight line through the centre, because all its rotations share an axis and differ only in angle. The \(\pm180^\circ\) ends of a line are the same rotation, so the surface of the ball is glued to itself - which is why rotation space is not simply a ball.

Sections of constant rotational angle are the flat way of looking at the same thing.

{% highlight matlab %} plotSection(rotZ,'MarkerColor','b','axisAngle',(30:30:180)*degree) hold on plot(rotX,'MarkerColor','g','add2all') plot(rotY,'MarkerColor','r','add2all') hold off {% endhighlight %}
{% include inline_image.html file="OrientationFundamentalRegion_04.png" %}

What Crystal Symmetry Does

Each proper symmetry operation folds the ball onto itself, so a group with \(n\) proper elements cuts it into \(n\) equal pieces. Orthorhombic symmetry has four, and the region MTEX picks is the central one.

{% highlight matlab %} cs = crystalSymmetry('222') {% endhighlight %} {% highlight plaintext %} cs = crystalSymmetry (⊙c→a) symmetry: 222 elements: 4 a, b, c : 1, 1, 1 {% endhighlight %} {% highlight matlab %} oR = fundamentalRegion(cs); close all plot(oR_all) axis off hold on plot(oR,'color','r') hold off {% endhighlight %}
{% include inline_image.html file="OrientationFundamentalRegion_05.png" %}

Real Data Lands Inside It

Measured orientations are drawn in the fundamental region without being asked to.

{% highlight matlab %} mtexdata forsterite {% endhighlight %} {% highlight plaintext %} ebsd = EBSDsquare (y↑→x, row↑→col) Phase Orientations Mineral Color Symmetry Crystal reference frame 0 58485 (24%) notIndexed none 1 152345 (62%) Forsterite LightSkyBlue mmm 2 26058 (11%) Enstatite DarkSeaGreen mmm 3 9064 (3.7%) Diopside Goldenrod 12/m1 X||a*, Y||b, Z||c Properties: bands, bc, bs, error, mad, oldId Scan unit : um X × Y × Z : [0 → 36550] × [0 → 16750] × [0 → 0] Normal vector: (0,0,1) Square grid :336 × 732 {% endhighlight %} {% highlight matlab %} plot(ebsd('Fo').orientations,'axisAngle') {% endhighlight %} {% highlight plaintext %} plot 2000 random orientations out of 152345 given orientations {% endhighlight %}
{% include inline_image.html file="OrientationFundamentalRegion_06.png" %}

Nothing sticks out of the region, because every orientation was replaced by its equivalent inside. Doing that explicitly, rather than only for the plot, is project2FundamentalRegion.

{% highlight matlab %} ori = ebsd('Fo').orientations.project2FundamentalRegion {% endhighlight %} {% highlight plaintext %} ori = orientation (Forsterite → y↑→x) size: 152345 × 1 {% endhighlight %}

Recentring the Region

The region need not sit at the origin. Centred on the mean orientation of a grain, it is the natural frame for looking at the spread within that grain - orientations that would otherwise be split across the boundary of the region stay together.

{% highlight matlab %} % segment data into grains [grains,ebsd] = calcGrains(ebsd); % take the orientations of the largest one [~,id] = max(grains.area); largeGrain = grains(id) {% endhighlight %} {% highlight plaintext %} largeGrain = grain2d (y↑→x) Phase Grains Pixels Mineral Symmetry Color 1 1 2683 Forsterite mmm LightSkyBlue boundary segments: 714 (32005 µm) inner boundary segments: 0 (0 µm) triple points: 44 Id Phase Pixels meanRotation GOS 1650 1 2683 (171°,55°,261°) 0.0441053 {% endhighlight %} {% highlight matlab %} ori = ebsd(largeGrain).orientations; % recenter the fundamental zone to the mean orientation center = largeGrain.meanOrientation; ori = ori.project2FundamentalRegion(center) {% endhighlight %} {% highlight plaintext %} ori = orientation (Forsterite → y↑→x) size: 3089 × 1 {% endhighlight %} {% highlight matlab %} plot(ori,'axisAngle') hold on plot(center,'MarkerFaceColor','r','MarkerSize',20) hold off {% endhighlight %} {% highlight plaintext %} plot 2000 random orientations out of 3089 given orientations {% endhighlight %}
{% include inline_image.html file="OrientationFundamentalRegion_07.png" %}

The cloud is a small blob around the red marker - no orientation in this grain is more than about \(6^\circ\) from the mean - rather than a set of points spread over the whole region.

Fundamental Regions of Misorientations

A misorientation carries two symmetries, one from each crystal, so its region is cut by both and is correspondingly smaller.

{% highlight matlab %} oR = fundamentalRegion(ebsd('Fo').CS,ebsd('En').CS); plot(oR) {% endhighlight %}
{% include inline_image.html file="OrientationFundamentalRegion_08.png" %}

Boundary misorientations between the two phases, drawn in it:

{% highlight matlab %} plot(grains.boundary('Fo','En').misorientation) {% endhighlight %} {% highlight plaintext %} plot 2000 random orientations out of 11751 given orientations {% endhighlight %}
{% include inline_image.html file="OrientationFundamentalRegion_09.png" %}

Antipodal Symmetry Between Grains of One Phase

Between two grains of the same phase there is no way to say which grain is first, so a misorientation and its inverse are indistinguishable. In axis-angle terms the inverse has the same angle and the opposite axis, which is the 'antipodal' flag of Axes and Antipodal Symmetry applied to orientation space.

{% highlight matlab %} oR = fundamentalRegion(ebsd('Fo').CS,ebsd('Fo').CS,'antipodal'); plot(oR) {% endhighlight %}
{% include inline_image.html file="OrientationFundamentalRegion_10.png" %}

Half the size of the region without the flag. MTEX sets the flag on same-phase boundary misorientations by itself.

{% highlight matlab %} mori = grains.boundary('Fo','Fo').misorientation {% endhighlight %} {% highlight plaintext %} mori = misorientation (Forsterite → Forsterite) size: 15872 × 1 antipodal: true {% endhighlight %} {% highlight matlab %} plot(mori) {% endhighlight %} {% highlight plaintext %} plot 2000 random orientations out of 15872 given orientations {% endhighlight %}
{% include inline_image.html file="OrientationFundamentalRegion_11.png" %}

Removing it draws the same data in the larger region, with each misorientation and its inverse now counted as different.

{% highlight matlab %} mori.antipodal = false; plot(mori) {% endhighlight %} {% highlight plaintext %} plot 2000 random orientations out of 15872 given orientations {% endhighlight %}
{% include inline_image.html file="OrientationFundamentalRegion_12.png" %}

Axis Angle Sections

As for the full ball, sections of constant rotational angle flatten the region.
