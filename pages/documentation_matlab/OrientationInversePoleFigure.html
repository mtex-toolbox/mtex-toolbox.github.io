An inverse pole figure answers the question a pole figure asks in reverse: given a direction in the specimen, which crystal direction points along it? It is the natural view when the specimen direction is the meaningful one - the normal of a rolled sheet, the axis a load was applied along, the sample surface normal of an EBSD map.

{% highlight matlab %} plottingConvention.default('y↑→x'); cs = crystalSymmetry('321'); ori = orientation.rand(cs) {% endhighlight %} {% highlight plaintext %} ori = orientation (321 → y↑→x) Bunge Euler angles in degree phi1 Phi phi2 156.958 161.468 197.878 {% endhighlight %}

Building One by Hand

Fix a specimen direction.

{% highlight matlab %} r = vector3d.Z; {% endhighlight %}

The inverse orientation takes it into crystal coordinates.

{% highlight matlab %} h = inv(ori) * r {% endhighlight %} {% highlight plaintext %} h = Miller (321) h k i l 0.0667 -0.3025 0.2357 -0.9481 {% endhighlight %}

Plotted with its symmetric equivalents, in the part of the sphere that holds one representative of each - the fundamental sector.

{% highlight matlab %} plot(h.symmetrise,'fundamentalRegion') {% endhighlight %}
{% include inline_image.html file="OrientationInversePoleFigure_01.png" %}

A single point, because all six equivalents fall onto the same place once the sector is reduced. That is the whole purpose of the sector: it removes the ambiguity that symmetry introduces.

The Shortcut

plotIPDF takes a list of specimen directions and does the above for each of them.

{% highlight matlab %} plotIPDF(ori,[vector3d.X,vector3d.Y,vector3d.Z]) {% endhighlight %}
{% include inline_image.html file="OrientationInversePoleFigure_02.png" %}

Three sectors, one per specimen axis, and each shows where that axis lies within the crystal.

Contour Plots

As for pole figures, 'contourf' turns the markers into filled contours, which is how a whole population of orientations is read.

{% highlight matlab %} plotIPDF(ori,[vector3d.X,vector3d.Y,vector3d.Z],'contourf') mtexColorbar {% endhighlight %}
{% include inline_image.html file="OrientationInversePoleFigure_03.png" %}

By default only the fundamental sector is drawn. The complete sphere shows what the reduction hid - the symmetric copies.

{% highlight matlab %} plotIPDF(ori,[vector3d.X,vector3d.Y,vector3d.Z],'contourf','complete','upper') mtexColorbar {% endhighlight %}
{% include inline_image.html file="OrientationInversePoleFigure_04.png" %}

Inverse pole figures are also where the colours of an EBSD map come from: an IPF map gives every pixel the colour of the position its orientation occupies in this sector.
