A pole figure answers one question: given a crystal direction, where in the specimen does it point? It is the standard two dimensional view of orientation data, and it is built from the coordinate transform of Theory in three steps.

{% highlight matlab %} plottingConvention.default('y↑→x'); cs = crystalSymmetry('321') {% endhighlight %} {% highlight plaintext %} cs = crystalSymmetry (⊙c→a) symmetry : 321 elements : 6 a, b, c : 1, 1, 1 reference frame: X||a*, Y||b, Z||c {% endhighlight %} {% highlight matlab %} ori = orientation.rand(cs) {% endhighlight %} {% highlight plaintext %} ori = orientation (321 → y↑→x) Bunge Euler angles in degree phi1 Phi phi2 156.958 161.468 197.878 {% endhighlight %}

Building One by Hand

Fix a crystal direction.

{% highlight matlab %} % the fixed crystal direction (100) h = Miller({1,0,0},cs); {% endhighlight %}

Apply the orientation to every direction symmetrically equivalent to it, which gives the specimen directions the crystal sends them to.

{% highlight matlab %} r = ori * h.symmetrise {% endhighlight %} {% highlight plaintext %} r = vector3d (y↑→x) size: 1 × 6 x y z 0.88 -0.739 -0.113 1.08 0.34 0.246 -1.08 -0.34 -0.246 -0.88 0.739 0.113 0.196 1.08 0.359 -0.196 -1.08 -0.359 {% endhighlight %}

Plot the result in a spherical projection.

{% highlight matlab %} plot(r) {% endhighlight %}
{% include inline_image.html file="OrientationPoleFigure_01.png" %}

Six points, because the trigonal group 321 has six symmetry elements and each contributes one crystallographically equivalent direction, see Symmetry. They are distinct specimen directions belonging to the same crystal-direction family.

The Shortcut

plotPDF does all of that, for several crystal directions at once.

{% highlight matlab %} plotPDF(ori,Miller({1,0,-1,0},{0,0,0,1},{1,1,-2,1},ori.CS)) {% endhighlight %}
{% include inline_image.html file="OrientationPoleFigure_02.png" %}

Some of the three pole figures show one hemisphere, others show both. The rule is symmetry: where h and -h are symmetrically equivalent, the two hemispheres carry the same information and MTEX draws only the upper one. In 321 that holds for \((10\bar10)\) and for \((0001)\), since the twofold axes in the basal plane turn c into -c. It does not hold for \((11\bar21)\), so that pole figure needs both hemispheres. Imposing the reduced view regardless is what the 'antipodal' flag does, see Axes and Antipodal Symmetry.

Contour Plots

The option 'contourf' replaces the markers by filled contours.

{% highlight matlab %} plotPDF(ori,Miller({1,0,-1,0},{0,0,0,1},{1,1,-2,1},ori.CS),'contourf') mtexColorbar {% endhighlight %}
{% include inline_image.html file="OrientationPoleFigure_03.png" %}

For a single orientation this only smears six points, but it is how pole figures of a whole population are read - measured ones, or ones computed from an ODF, where the contours are a density and the colorbar counts multiples of a random distribution. See Pole Figures of an ODF and Pole Figure Analysis.
