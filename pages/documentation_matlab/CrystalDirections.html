--- title: "Miller Indices" sidebar: documentation_sidebar permalink: CrystalDirections.html folder: documentation toc: false --- Miller Indices edit page

A direction in the specimen is written in the specimen axes X, Y, Z. A direction in the crystal is written in the crystal axes \(\vec a\), \(\vec b\), \(\vec c\), and its coordinates are the Miller indices. Both are directions in the same three dimensional space - what differs is the frame the numbers refer to, and for a crystal that frame is in general neither orthogonal nor normalised.

The Crystal Reference Frame

Miller indices mean nothing without the lattice they are counted in, so the starting point is always a crystalSymmetry.

{% highlight matlab %} cs = crystalSymmetry('triclinic',[5.29,9.18,9.42],[90.4,98.9,90.1]*degree,... 'X||a*','Z||c','mineral','Talc'); {% endhighlight %}

It carries the lengths and the angles of the unit cell, and hence the three lattice axes as directions in the Cartesian crystal frame.

{% highlight matlab %} a = cs.aAxis {% endhighlight %} {% highlight plaintext %} a = Miller (Talc) u v w 1 0 0 {% endhighlight %} {% highlight matlab %} b = cs.bAxis {% endhighlight %} {% highlight plaintext %} b = Miller (Talc) u v w 0 1 0 {% endhighlight %} {% highlight matlab %} c = cs.cAxis {% endhighlight %} {% highlight plaintext %} c = Miller (Talc) u v w 0 0 1 {% endhighlight %}

Talc is triclinic, so these three are not at right angles - \(\vec a\) and \(\vec c\) enclose \(81^\circ\) here. Everything that follows is a consequence of that.

{% highlight matlab %} angle(a,c) ./ degree {% endhighlight %} {% highlight plaintext %} ans = 81.1000 {% endhighlight %}

Lattice Directions

A lattice direction \(\vec m = u \cdot \vec a + v \cdot \vec b + w \cdot \vec c\) is the direction from one lattice point to another, written \([uvw]\). In MTEX it is a variable of type Miller.

{% highlight matlab %} m = Miller(1,0,1,cs,'uvw') {% endhighlight %} {% highlight plaintext %} m = Miller (Talc) u v w 1 0 1 {% endhighlight %}

Plotting it draws it as a point on the sphere, alongside the three crystal axes.

{% highlight matlab %} plot(m,'labeled','grid') annotate([a,b,c],'label',{'a','b','c'},'backgroundcolor','w','textAboveMarker') {% endhighlight %}
{% include inline_image.html file="CrystalDirections_01.png" %}

For triclinic and monoclinic symmetry MTEX draws the b-axis towards the east and c* out of the plane. That is a plotting convention, and a convention belongs to a reference frame - here to the frame of the crystal.

{% highlight matlab %} % change the plotting convention of the crystal frame cs.frame.how2plot.east = cs.aAxis; plot(m,'labeled','grid') annotate([a,b,c],'label',{'a','b','c'},'backgroundcolor','w','textAboveMarker') {% endhighlight %}
{% include inline_image.html file="CrystalDirections_02.png" %}

The same direction, the same crystal, a different view: a now points east.

Lattice Planes

A lattice plane is named by its normal, \(\vec n = h \cdot \vec a^* + k \cdot \vec b^* + \ell \cdot \vec c^*\), written \((hkl)\). The starred axes are the reciprocal lattice, defined so that \(\vec a^*\) is perpendicular to both \(\vec b\) and \(\vec c\), and so on. Their construction from the lattice metric is explained in Lattice Metric and Plane Geometry.

The indices also describe where a plane cuts the direct axes. A member with plane equation \(\vec x\cdot\vec n=q\) has fractional intercepts \(q/h\), \(q/k\) and \(q/\ell\) along \(\vec a\), \(\vec b\) and \(\vec c\). A zero index means an infinite intercept, so the plane is parallel to that axis.

In the schematic, the \((213)\) plane is drawn with \(q=6\). It therefore meets the axes at \(3\vec a\), \(6\vec b\) and \(2\vec c\), and its normal is \(2\vec a^*+\vec b^*+3\vec c^*\).

{% include inline_image.html file="latticePlaneNormal.png" %}

If only the plane orientation matters, multiplying all indices by a common factor leaves the normal direction unchanged. It does not leave the full lattice-plane family unchanged: \((200)\) has twice the reciprocal-vector length and half the spacing of \((100)\). This distinction matters for diffraction and for dspacing.

{% highlight matlab %} n = Miller(1,0,1,cs,'hkl') {% endhighlight %} {% highlight plaintext %} n = Miller (Talc) h k l 1 0 1 {% endhighlight %}

A plane is drawn as its normal by default, or as the great circle where it cuts the sphere, with the option 'plane'.

{% highlight matlab %} hold on % the normal direction plot(n,'upper','labeled') % the trace of the corresponding lattice plane plot(n,'plane','linecolor','r','linewidth',2,'add2all') hold off {% endhighlight %}
{% include inline_image.html file="CrystalDirections_03.png" %}

Why \([101]\) and \((101)\) Are Not the Same Direction

The two directions defined above carry the same three numbers, and the plot shows them at different places. The angle between them is

{% highlight matlab %} angle(m,n) ./ degree {% endhighlight %} {% highlight plaintext %} ans = 31.6762 {% endhighlight %}

\(32^\circ\) apart. Direct and reciprocal axes are parallel in every orthogonal lattice, including orthorhombic, tetragonal and cubic lattices. In a non-orthogonal lattice they generally are not, so a plane normal need not be parallel to the lattice direction with the same indices. This is why Miller always records which of the two it represents.

Trigonal and Hexagonal Convention

Trigonal and hexagonal lattices are usually written with four indices, \([UVTW]\) and \((HKIL)\), because symmetrically equivalent directions are then easy to spot - they are permutations of the first three. The fourth index is redundant, as \(U + V + T = 0\) and \(H + K + I = 0\).

{% highlight matlab %} % import trigonal Quartz lattice structure cs = loadCIF('quartz'); % a four digit lattice direction m = Miller(2,1,-3,1,cs,'UVTW') {% endhighlight %} {% highlight plaintext %} m = Miller (Quartz) U V T W 2 1 -3 1 {% endhighlight %} {% highlight matlab %} % a four digit plane normal n = Miller(1,1,-2,3,cs,'hkil') {% endhighlight %} {% highlight plaintext %} n = Miller (Quartz) h k i l 1 1 -2 3 {% endhighlight %} {% highlight matlab %} plot(m,'upper','labeled','backgroundColor','white','grid','on') hold on plot(n,'upper','labeled') hold off {% endhighlight %}
{% include inline_image.html file="CrystalDirections_04.png" %}

Which notation the indices are displayed in is set by dispStyle, and changing it changes nothing about the direction itself.

{% highlight matlab %} m.dispStyle = 'uvw'; round(m) {% endhighlight %} {% highlight plaintext %} ans = Miller (Quartz) u v w 5 4 1 {% endhighlight %} {% highlight matlab %} n.dispStyle = 'UVTW'; round(n) {% endhighlight %} {% highlight plaintext %} ans = Miller (Quartz) U V T W 3 3 -6 11 {% endhighlight %}

Internally every Miller is stored in Cartesian coordinates, exactly as a <vector3d.vector3d.html vector3d> is. The indices are a way of reading it, and round is needed above because converting between the notations leaves numbers that are integers only up to rounding.
