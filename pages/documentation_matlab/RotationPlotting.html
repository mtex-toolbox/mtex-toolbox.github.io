A single rotation is best drawn by what it does, as the arrows on Definition do. A whole set of rotations is drawn by giving each of them a point in a three dimensional space - one point per rotation, one space per parametrisation.

{% highlight matlab %} plottingConvention.default('y↑→x'); % 500 uniformly distributed rotations rot = rotation.rand(500); {% endhighlight %}

Euler Angle Space

scatter puts each rotation at its three Bunge Euler angles. This is the default for rotations without a crystal symmetry, and the box is the range the angles run over: \(2\pi\) wide in \(\varphi_1\) and \(\varphi_2\), \(\pi\) deep in \(\Phi\).

{% highlight matlab %} scatter(rot) {% endhighlight %}
{% include inline_image.html file="RotationPlotting_01.png" %}

The points are not spread evenly, although the rotations are: they thin out towards the bottom of the box. Euler angle space distorts volume, by a factor \(\sin\Phi\) that vanishes at \(\Phi = 0\), so equal boxes there do not hold equal shares of rotations. This is why a texture that looks concentrated in an Euler angle plot need not be.

Axis Angle and Rodrigues Space

The same rotations placed by their axis and angle - the direction of the point is the rotation axis, the distance from the centre the rotation angle.

{% highlight matlab %} scatter(rot,'axisAngle') {% endhighlight %}
{% include inline_image.html file="RotationPlotting_02.png" %}

Now the cloud is a ball, and it is denser towards the rim: there are more rotations by a large angle than by a small one. Rodrigues space is the same construction with the distance scaled by \(\tan\omega/2\), which pushes the \(180^\circ\) rotations out to infinity.

{% highlight matlab %} scatter(rot,'Rodrigues') {% endhighlight %}
{% include inline_image.html file="RotationPlotting_03.png" %}

The trade-offs between the three, and the two constructions that preserve volume instead, are collected in Representations.

Colour and Markers

scatter takes the usual options, so a subset is highlighted by drawing it on top.

{% highlight matlab %} small = rot(rot.angle < 60*degree); scatter(rot,'axisAngle','MarkerFaceColor',[.7 .7 .7],'MarkerSize',4) hold on scatter(small,'axisAngle','MarkerFaceColor','r') hold off {% endhighlight %}
{% include inline_image.html file="RotationPlotting_04.png" %}

The red points sit in a small ball around the centre, and there are few of them.

{% highlight matlab %} length(small) {% endhighlight %} {% highlight plaintext %} ans = 24 {% endhighlight %}

Only \((\omega - \sin\omega)/\pi = 5.8\%\) of all rotations turn by less than \(\omega = 60^\circ\). What a texture calls nearly identical is a small minority among rotations in general.
