A rotation is applied to a direction, composed with another rotation, or inverted, and each of these is a single operator that works on whole lists at once.

{% highlight matlab %} plottingConvention.default('y↑→x'); {% endhighlight %}

Rotating a Direction

The product rot * v turns the direction v by the rotation rot.

{% highlight matlab %} rot = rotation.byEuler(90*degree,90*degree,0*degree) {% endhighlight %} {% highlight plaintext %} rot = rotation Bunge Euler angles in degree phi1 Phi phi2 90 90 0 {% endhighlight %} {% highlight matlab %} v = rot * vector3d.X {% endhighlight %} {% highlight plaintext %} v = vector3d (y↑→x) x y z 0 1 0 {% endhighlight %}

The grey arrows are the specimen axes, the black arrow the direction we started from and the red arrow where the rotation sent it.

{% highlight matlab %} arrow3d(1.2*[vector3d.X,vector3d.Y,vector3d.Z],'faceColor',[.75 .75 .75]) hold on arrow3d(1.05*vector3d.X,'faceColor','black') arrow3d(1.05*v,'faceColor','red') hold off axis off {% endhighlight %}
{% include inline_image.html file="RotationOperations_01.png" %}

X has landed on Y. Undoing a rotation is the backslash operator \\, which takes the direction back where it came from.

{% highlight matlab %} rot \ v {% endhighlight %} {% highlight plaintext %} ans = vector3d (y↑→x) x y z 1 0 0 {% endhighlight %}

Composing Rotations

Rotations are composed by multiplication, and the one applied first stands on the right - as with matrices.

{% highlight matlab %} rot1 = rotation.byEuler(90*degree,0,0); rot2 = rotation.byEuler(0,60*degree,0); rot = rot2 * rot1 {% endhighlight %} {% highlight plaintext %} rot = rotation Bunge Euler angles in degree phi1 Phi phi2 0 60 90 {% endhighlight %}

The order is not a detail. Swapping the two gives a different rotation,

{% highlight matlab %} rot2 * rot1 == rot1 * rot2 {% endhighlight %} {% highlight plaintext %} ans = logical 0 {% endhighlight %}

and the two results are this far apart.

{% highlight matlab %} angle(rot2*rot1, rot1*rot2) ./ degree {% endhighlight %} {% highlight plaintext %} ans = 82.8192 {% endhighlight %}

Axis and Angle

angle and axis read the axis-angle description off any rotation, however it was built.

{% highlight matlab %} rot.angle / degree {% endhighlight %} {% highlight plaintext %} ans = 104.4775 {% endhighlight %} {% highlight matlab %} rot.axis {% endhighlight %} {% highlight plaintext %} ans = vector3d (y↑→x) x y z 0.447 -0.447 0.775 {% endhighlight %}

The Angle Between Two Rotations

Given two rotations, angle measures how far apart they are - the angle of the rotation that turns one into the other. The composed rotation rot is rot1 followed by rot2, so it sits exactly the angle of rot2 away from rot1.

{% highlight matlab %} angle(rot,rot1) / degree {% endhighlight %} {% highlight plaintext %} ans = 60.0000 {% endhighlight %}

This number is the distance used throughout MTEX: how well a fit reproduces a measurement, how much orientation varies within a grain, how far a misorientation is from an ideal one. For orientations it additionally respects crystal symmetry, see Misorientations.

The Inverse Rotation

inv turns a rotation around: the axis stays, the angle changes sign.

{% highlight matlab %} inv(rot) {% endhighlight %} {% highlight plaintext %} ans = rotation Bunge Euler angles in degree phi1 Phi phi2 90 60 180 {% endhighlight %}

A rotation multiplied by its inverse is the identity, which is what makes rot \ v above the same as inv(rot) * v.

{% highlight matlab %} rot * inv(rot) {% endhighlight %} {% highlight plaintext %} ans = rotation Bunge Euler angles in degree phi1 Phi phi2 0 0 0 {% endhighlight %}

Reading off Other Parametrisations

Any parametrisation is available as a property or a command, whichever description the rotation was defined by.

Euler(rot)

the three Euler angles

Rodrigues(rot)

the Rodrigues Frank vector

matrix(rot)

the rotation matrix

homochoric(rot)

the homochoric vector

axis(rot), angle(rot)

axis and angle

Euler angles come in whichever convention is asked for, and the answer differs between conventions - the numbers below are not the ones the display shows, which uses Bunge.

{% highlight matlab %} [alpha,beta,gamma] = Euler(rot,'Matthies'); [alpha,beta,gamma] ./ degree {% endhighlight %} {% highlight plaintext %} ans = 270.0000 60.0000 180.0000 {% endhighlight %}
