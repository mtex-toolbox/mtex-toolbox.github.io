--- title: "Wave Velocities" sidebar: documentation_sidebar permalink: WaveVelocities.html folder: documentation toc: false --- Wave Velocities edit page

Elastic waves traveling through an anisotropic medium do not propagate with the same speed in every direction. In this section we explain how MTEX derives from an elastic stiffness tensor the direction dependent velocities of the P-wave and of the two S-waves, together with their polarization directions, how these quantities are visualized and which anisotropy measures are commonly derived from them.

Import an Elasticity Tensor

Let us start by importing the elastic stiffness tensor of an Olivine crystal in reference orientation from a file.

{% highlight matlab %} fname = fullfile(mtexDataPath,'tensor','Olivine1997PC.GPa'); cs = crystalSymmetry('mmm',[4.7646 10.2296 5.9942],'mineral','Olivin'); C = stiffnessTensor.load(fname,cs) {% endhighlight %} {% highlight plaintext %} C = stiffnessTensor (Olivin) unit: GPa rank: 4 (3 x 3 x 3 x 3) tensor in Voigt matrix representation: 320.5 68.2 71.6 0 0 0 68.2 196.5 76.8 0 0 0 71.6 76.8 233.5 0 0 0 0 0 0 64 0 0 0 0 0 0 77 0 0 0 0 0 0 78.7 {% endhighlight %}

The Density

Wave velocities do not only depend on the stiffness tensor but also on the density \(\rho\) of the material. For Olivine it is about 3.355 g/cm\(^3\). Since the density is required by almost every command in this section it is most convenient to store it directly within the stiffness tensor

{% highlight matlab %} rho = 3.355; C = addOption(C,'density',rho) {% endhighlight %} {% highlight plaintext %} C = stiffnessTensor (Olivin) unit : GPa density: 3.355 rank : 4 (3 x 3 x 3 x 3) tensor in Voigt matrix representation: 320.5 68.2 71.6 0 0 0 68.2 196.5 76.8 0 0 0 71.6 76.8 233.5 0 0 0 0 0 0 64 0 0 0 0 0 0 77 0 0 0 0 0 0 78.7 {% endhighlight %}

Alternatively, the density may be passed as the option 'density' when the tensor is defined, e.g. stiffnessTensor(M,cs,'density',rho), or as a trailing argument to the individual commands.

The Christoffel Equation

Consider a plane wave with propagation direction \(\vec n\), phase velocity \(v\) and polarization direction \(\vec p\), i.e., a displacement field of the form

\[ \vec u(\vec x,t) = \vec p \, f(\vec n \cdot \vec x - v t). \]

Substituting this ansatz into the equation of motion \(\rho \, \partial_t^2 u_i = \partial_j \sigma_{ij}\) together with Hooke's law \(\sigma_{ij} = C_{ijkl}\varepsilon_{kl}\) results in the Christoffel equation

\[ C_{ijkl} n_j n_l \, p_k = \rho v^2 p_i. \]

In other words, the admissible polarization directions \(\vec p\) are the eigenvectors of the symmetric rank two tensor

\[ E_{ik}(\vec n) = C_{ijkl} n_j n_l \]

and the corresponding eigenvalues are the wave moduli \(\rho v^2\).

The Christoffel Tensor

The tensor \(E(\vec n)\) is called the Christoffel tensor and is computed for a specific propagation direction \(\vec n\) by the command ChristoffelTensor

{% highlight matlab %} T = ChristoffelTensor(C,vector3d.X) {% endhighlight %} {% highlight plaintext %} T = ChristoffelTensor (Olivin) rank: 2 (3 x 3) 320.5 0 0 0 78.7 0 0 0 77 {% endhighlight %}

The Christoffel tensor is symmetric as a consequence of the symmetry \(C_{ijkl} = C_{klij}\) of the elastic constants. Hence, its three eigenvalues are real and the three eigenvectors are perpendicular to each other. Since the stiffness tensor is positive definite the eigenvalues are, moreover, positive and therefore correspond to three real wave speeds. Let us compute this eigenvalue decomposition

{% highlight matlab %} [p,lambda] = eig(T) {% endhighlight %} {% highlight plaintext %} p = vector3d (y↓→x) size: 3 x 1 antipodal: true x y z 0 0 1 0 1 0 1 0 0 lambda = 77.0000 78.7000 320.5000 {% endhighlight %}

MTEX returns the eigenvalues in ascending order. Dividing them by the density and taking the square root gives the three wave velocities in km/s

{% highlight matlab %} v = sqrt(lambda ./ rho) {% endhighlight %} {% highlight plaintext %} v = 4.7907 4.8433 9.7739 {% endhighlight %}

The largest of them belongs to the P-wave, i.e., the wave whose polarization direction is closest to the propagation direction, while the two smaller ones belong to the fast and the slow S-wave. Note that for the direction vector3d.X, which is a symmetry axis of our Olivine crystal, the polarization directions coincide with the coordinate axes and the P-wave is polarized exactly parallel to the propagation direction.

Elastic Wave Velocities

Instead of decomposing the Christoffel tensor by hand the command velocity performs all these steps at once and directly sorts the result into P-wave, fast S-wave and slow S-wave

{% highlight matlab %} [vp,vs1,vs2,pp,ps1,ps2] = velocity(C,vector3d.X) {% endhighlight %} {% highlight plaintext %} vp = 9.7739 vs1 = 4.8433 vs2 = 4.7907 pp = vector3d (y↓→x) antipodal: true x y z 1 0 0 ps1 = vector3d (y↓→x) antipodal: true x y z 0 1 0 ps2 = vector3d (y↓→x) antipodal: true x y z 0 0 1 {% endhighlight %}

Here vp, vs1, vs2 are the velocities of the P-wave, the fast S-wave and the slow S-wave, while pp, ps1, ps2 are the corresponding polarization directions, i.e., the directions the particles vibrate in. Since a polarization direction is only defined up to sign it is returned as an axis.

The command accepts arbitrary lists of propagation directions

{% highlight matlab %} x = [vector3d.X,vector3d.Y,vector3d.Z] vp = velocity(C,x) {% endhighlight %} {% highlight plaintext %} x = vector3d (y↓→x) size: 1 x 3 x y z 1 0 0 0 1 0 0 0 1 vp = 9.7739 7.6531 8.3425 {% endhighlight %}

Velocities as Spherical Functions

If the propagation direction is omitted altogether the wave velocities are computed for the entire sphere and returned as spherical functions

{% highlight matlab %} [vp,vs1,vs2,pp,ps1,ps2] = velocity(C) {% endhighlight %} {% highlight plaintext %} vp = S2FunTri (y↓→x) vertices: 18338 x 1 vs1 = S2FunTri (y↓→x) vertices: 18338 x 1 vs2 = S2FunTri (y↓→x) vertices: 18338 x 1 pp = S2AxisFieldTri vertices: 18338 x 1 ps1 = S2AxisFieldTri vertices: 18338 x 1 ps2 = S2AxisFieldTri vertices: 18338 x 1 {% endhighlight %}

As output we obtain three spherical functions vp, vs1 and vs2 representing the velocities of P, and fast and slow S-waves respectively in dependency of the propagation direction. The remaining three output variables pp, ps1, ps2 are spherical vector fields representing the polarization directions of these wave as functions of the propagation direction.

Being ordinary spherical functions they may be evaluated at any direction

{% highlight matlab %} vp.eval(vector3d.X) {% endhighlight %} {% highlight plaintext %} ans = 9.7735 {% endhighlight %}

By default the velocities are sampled on a triangulated grid and interpolated in between, which explains the small deviation from the exact value computed above. Passing the option 'harmonic' returns harmonic expansions instead. These are smooth, respect the crystal symmetry exactly and are the better choice for three dimensional plots

{% highlight matlab %} vpHarm = velocity(C,'harmonic') {% endhighlight %} {% highlight plaintext %} vpHarm = S2FunHarmonicSym (Olivin) bandwidth: 48 antipodal: true {% endhighlight %}

Visualizing the Wave Velocities

In order to visualize these quantities, there are several possibilities. Let us first plot the direction dependent wave speed of the p-wave

{% highlight matlab %} setMTEXpref('defaultColorMap',blue2redColorMap); plot(vp,'complete','upper') {% endhighlight %}
{% include inline_image.html file="WaveVelocities_01.png" %}

Next, we plot on the top of this plot the p-wave polarization direction.

{% highlight matlab %} hold on plot(pp) hold off {% endhighlight %}
{% include inline_image.html file="WaveVelocities_02.png" %}

Note how the polarization of the P-wave stays close to the propagation direction it is plotted at - the P-wave is almost, but not exactly, a longitudinal wave.

Shear Wave Splitting

We may even compute with these spherical functions as with ordinary values. E.g. to visualize the speed difference between the s1 and s2 waves we do.

{% highlight matlab %} plot(vs1-vs2,'complete','upper') hold on plot(ps1) hold off {% endhighlight %}
{% include inline_image.html file="WaveVelocities_03.png" %}

This difference is the reason for shear wave splitting: an S-wave entering an anisotropic medium is split into a fast and a slow component which are polarized perpendicular to each other and arrive with a delay. The line segments above show the polarization ps1 of the fast S-wave, which is the quantity a seismologist measures. Directions where the difference vanishes are the acoustic axes of the crystal - there both S-waves travel with the same speed and no splitting occurs.

Anisotropy Measures

The relative velocity variation of a wave is usually reported as a percentage of its mean velocity. For the P-wave this gives

{% highlight matlab %} [maxVp,maxPos] = max(vp); [minVp,minPos] = min(vp); AVp = 200*(maxVp-minVp)./(maxVp+minVp) {% endhighlight %} {% highlight plaintext %} AVp = 24.3329 {% endhighlight %}

Let us mark the corresponding fastest and slowest propagation directions in the plot

{% highlight matlab %} plot(vp,'complete','upper') hold on plot(maxPos(1),'Marker','s','MarkerSize',10,'MarkerFaceColor','k','MarkerEdgeColor','w') plot(minPos(1),'Marker','o','MarkerSize',10,'MarkerFaceColor','w','MarkerEdgeColor','k') hold off {% endhighlight %}
{% include inline_image.html file="WaveVelocities_04.png" %}

The S-wave anisotropy, in contrast, is a function of the propagation direction as it compares the two S-waves traveling in the same direction

{% highlight matlab %} AVs = 200*(vs1-vs2)./(vs1+vs2); plot(AVs,'complete','upper') mtexTitle('S-wave anisotropy (%)') mtexColorbar {% endhighlight %}
{% include inline_image.html file="WaveVelocities_05.png" %}

A third quantity of interest in seismology is the ratio between P- and S-wave velocity

{% highlight matlab %} plot(vp./vs1,'complete','upper') mtexTitle('Vp/Vs1') mtexColorbar {% endhighlight %}
{% include inline_image.html file="WaveVelocities_06.png" %}

Comparison with an Isotropic Medium

It is instructive to compare these velocities with those of an aggregate of randomly oriented Olivine crystals, which we obtain by averaging the stiffness tensor with respect to a uniform ODF. The first output of mean is the Voigt average, see isotropic theory for the Reuss and Hill averages.

{% highlight matlab %} C_iso = mean(C,uniformODF(cs)) {% endhighlight %} {% highlight plaintext %} C_iso = stiffnessTensor (y↓→x) unit : GPa density: 3.355 rank : 4 (3 x 3 x 3 x 3) tensor in Voigt matrix representation: 237.56 78.49 78.49 0 0 0 78.49 237.56 78.49 0 0 0 78.49 78.49 237.56 0 0 0 0 0 0 79.54 0 0 0 0 0 0 79.54 0 0 0 0 0 0 79.54 {% endhighlight %}

The resulting tensor is elastically isotropic. Hence its wave velocities are independent of the propagation direction and are entirely determined by the bulk modulus \(K\), the shear modulus \(G\) and the density

{% highlight matlab %} K = C_iso.bulkModulus; G = C_iso.shearModulus; vpIso = sqrt((K + 4/3*G)./rho) vsIso = sqrt(G./rho) {% endhighlight %} {% highlight plaintext %} vpIso = 8.4147 vsIso = 4.8690 {% endhighlight %}

which is exactly what the command velocity returns for this tensor

{% highlight matlab %} [vp_iso,vs1_iso,vs2_iso] = velocity(C_iso,vector3d.X) {% endhighlight %} {% highlight plaintext %} vp_iso = 8.4147 vs1_iso = 4.8690 vs2_iso = 4.8690 {% endhighlight %}

Note that both S-waves now travel with the same speed - there is no shear wave splitting in an isotropic medium. Comparing the isotropic P-wave velocity with the extremes of the single crystal

{% highlight matlab %} cprintf([minVp,vpIso,maxVp],'-Lc',{'min Vp' 'isotropic' 'max Vp'}) {% endhighlight %} {% highlight plaintext %} min Vp isotropic max Vp 7.65328 8.41473 9.7735 {% endhighlight %}

Group Velocity

The velocities computed so far are phase velocities, i.e., they describe how fast a wave front moves along its normal \(\vec n\). Energy, however, travels along the energy velocity vector \(\vec V_e\), which for a lossless medium is a good proxy for the group velocity and is computed by the command energyVector

{% highlight matlab %} % an arbitrary, non symmetric propagation direction x = vector3d.byPolar(45*degree,20*degree); [vp,vs1,vs2,pp,ps1,ps2] = velocity(C,x); Ve = energyVector(C,x,vp,pp) {% endhighlight %} {% highlight plaintext %} Ve = vector3d (y↓→x) x y z 6.92 1.57 5.11 {% endhighlight %}

In an anisotropic medium this vector is in general not parallel to the propagation direction - the energy of the wave is deflected sideways. The angle between both directions is

{% highlight matlab %} angle(Ve,x) ./ degree {% endhighlight %} {% highlight plaintext %} ans = 10.7498 {% endhighlight %}

Its magnitude is at least as large as the phase velocity, while its projection onto the propagation direction reproduces the phase velocity exactly

{% highlight matlab %} cprintf([norm(Ve),dot(Ve,x),vp],'-Lc',{'|Ve|' 'Ve.n' 'Vp'}) {% endhighlight %} {% highlight plaintext %} |Ve| Ve.n Vp 8.74413 8.59068 8.59068 {% endhighlight %}

As for velocity, passing an empty propagation direction together with the spherical velocity and polarization functions returns the energy velocity as a spherical vector field.

Phase Velocity Surfaces

When projected to a plane the different wave speeds
