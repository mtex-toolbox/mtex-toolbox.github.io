--- title: "Fundamental Sector" sidebar: documentation_sidebar permalink: FundamentalSector.html folder: documentation toc: false --- Fundamental Sector edit page

Crystal symmetry makes many directions equivalent. The fundamental sector is a choice of one representative for each class of symmetrically equivalent directions - a patch of the sphere that tiles the whole sphere when the symmetry elements are applied to it. It is what an inverse pole figure is plotted on, and it is the region in which directions are placed by project2FundamentalRegion.

For cubic symmetry it is the familiar triangle spanned by the \(\left<100\right>\), \(\left<110\right>\) and \(\left<111\right>\) poles.

{% highlight matlab %} cs = crystalSymmetry('432') plot(cs) hold on plot(cs.fundamentalSector,'color','Red') hold off {% endhighlight %} {% highlight plaintext %} cs = crystalSymmetry (⊙c→a) symmetry: 432 elements: 24 a, b, c : 1, 1, 1 {% endhighlight %}
{% include inline_image.html file="FundamentalSector_01.png" %}

The sector itself is a sphericalRegion

{% highlight matlab %} sR = cs.fundamentalSector {% endhighlight %} {% highlight plaintext %} sR = sphericalRegion edge normales: 5 {% endhighlight %}

It is stored as an intersection of half spaces - a direction belongs to the sector if it has a non negative inner product with each of the normal vectors sR.N. For the cubic group there are three of them, one per edge of the triangle.

{% highlight matlab %} sR.N {% endhighlight %} {% highlight plaintext %} ans = vector3d (crystal) size: 1 x 5 x y z 0 -0.707 0.707 -0.707 0 0.707 1 0 0 0 1 0 0 0 1 {% endhighlight %}

Testing and projecting

Let us take an arbitrary crystal direction

{% highlight matlab %} v = Miller(2,3,1,cs) {% endhighlight %} {% highlight plaintext %} v = Miller (432) h k l 2 3 1 {% endhighlight %}

We may check whether a direction is inside the fundamental region by the command checkInside

{% highlight matlab %} sR.checkInside(v) {% endhighlight %} {% highlight plaintext %} ans = logical 0 {% endhighlight %}

and its symmetrically equivalent representative inside the sector is found by project2FundamentalRegion

{% highlight matlab %} v.project2FundamentalRegion {% endhighlight %} {% highlight plaintext %} ans = Miller (432) h k l 1 2 3 {% endhighlight %} {% highlight matlab %} hold on plot(v) plot(v.project2FundamentalRegion,'MarkerFaceColor','Red') hold off {% endhighlight %}

Other symmetries

The shape of the sector depends on the point group, and it becomes larger the fewer symmetry elements there are. The triclinic group leaves the whole sphere.

{% highlight matlab %} newMtexFigure('layout',[2 5],'figSize','medium'); for lId = 2:11 nextAxis(lId-1); cs = crystalSymmetry('LaueId',lId); plot(cs,'doNotDraw') hold on plot(cs.fundamentalSector,'color','red','doNotDraw','LineWidth',3) hold off mtexTitle(cs.LaueName) end {% endhighlight %}
{% include inline_image.html file="FundamentalSector_03.png" %}

Note that a sector is a purely geometric object - it carries no orientation information. Its counterpart in orientation space is the fundamental region, represented by orientationRegion.
