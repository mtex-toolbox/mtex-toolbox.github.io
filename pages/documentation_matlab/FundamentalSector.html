--- title: "Fundamental Sector" sidebar: documentation_sidebar permalink: FundamentalSector.html folder: documentation toc: false --- Fundamental Sector edit page

Crystal symmetry makes many directions equivalent. The fundamental sector is a choice of one representative for each class of symmetrically equivalent directions - a patch of the sphere that tiles the whole sphere when the symmetry elements are applied to it. It is what an inverse pole figure is plotted on, and it is the region in which directions are placed by project2FundamentalRegion.

For cubic symmetry it is the familiar triangle spanned by the \(\left<100\right>\), \(\left<110\right>\) and \(\left<111\right>\) poles.

{% highlight matlab %} cs = crystalSymmetry('m-3m') plot(cs) hold on plot(cs.fundamentalSector,'color','Red') hold off {% endhighlight %} {% highlight plaintext %} cs = crystalSymmetry (⊙c→a) symmetry: m3̅m elements: 48 a, b, c : 1, 1, 1 {% endhighlight %}
{% include inline_image.html file="FundamentalSector_01.png" %}

The sector itself is a sphericalRegion

{% highlight matlab %} sR = cs.fundamentalSector {% endhighlight %} {% highlight plaintext %} sR = sphericalRegion edge normales: 3 {% endhighlight %}

It is stored as an intersection of half spaces - a direction belongs to the sector if it has a non negative inner product with each of the normal vectors sR.N. For the cubic group there are three of them, one per edge of the triangle.

{% highlight matlab %} sR.N {% endhighlight %} {% highlight plaintext %} ans = vector3d (crystal) size: 1 × 3 x y z 0.707 -0.707 0 -0.707 0 0.707 0 1 0 {% endhighlight %}

Testing and Projecting

Take an arbitrary crystal direction.

{% highlight matlab %} v = Miller(2,3,1,cs) {% endhighlight %} {% highlight plaintext %} v = Miller (m3̅m) h k l 2 3 1 {% endhighlight %}

checkInside answers whether it is inside the sector.

{% highlight matlab %} sR.checkInside(v) {% endhighlight %} {% highlight plaintext %} ans = logical 0 {% endhighlight %}

It is not.

The equivalent direction that is inside comes from project2FundamentalRegion.

{% highlight matlab %} v.project2FundamentalRegion {% endhighlight %} {% highlight plaintext %} ans = Miller (m3̅m) h k l 2 1 3 {% endhighlight %}

\((213)\) - a symmetry-equivalent permutation of the indices. For the cubic Laue group, both belong to the same \(\{123\}\) form; the sector selects one representative from that family.

{% highlight matlab %} hold on plot(v) plot(v.project2FundamentalRegion,'MarkerFaceColor','Red') hold off {% endhighlight %}
{% include inline_image.html file="FundamentalSector_02.png" %}

Other Symmetries

The shape of the sector follows from the point group, and the fewer elements the group has the larger the sector is. Only the point group 1 leaves the whole sphere; the triclinic Laue group \(\bar 1\) already halves it, since the inversion identifies every direction with its opposite. The remaining ten Laue groups are shown below:

{% highlight matlab %} newMtexFigure('layout',[2 5],'figSize','medium'); for lId = 2:11 nextAxis(lId-1); cs = crystalSymmetry('LaueId',lId); plot(cs,'doNotDraw') hold on plot(cs.fundamentalSector,'color','red','doNotDraw','LineWidth',3) hold off mtexTitle(cs.LaueName) end {% endhighlight %}
{% include inline_image.html file="FundamentalSector_03.png" %}

Each plot shows the symmetry elements of the group with its sector drawn in red. Going from 6/mmm to 2/m the red patch grows by exactly the factor by which the number of symmetry elements drops.
