A tensor of rank two or higher has too many components to be read off a list. What can be looked at instead is its directional magnitude - the scalar that the tensor produces when it is contracted with one and the same direction in all of its slots. For a tensor \(T\) of rank \(r\) this is

\[ Q(\vec x) = T_{i_1 \ldots i_r}\, x_{i_1} \cdots x_{i_r}, \qquad \vec x = 1, \]

a function on the sphere, i.e. an S2Fun, and plotting it is what the plot command of a tensor does by default.

{% highlight matlab %} setMTEXpref('defaultColorMap',blue2redColorMap); cs = crystalSymmetry('mmm',[4.7646 10.2296 5.9942],'mineral','Olivine'); C = stiffnessTensor.load(fullfile(mtexDataPath,'tensor','Olivine1997PC.GPa'),cs) {% endhighlight %} {% highlight plaintext %} C = stiffnessTensor (Olivine) unit: GPa rank: 4 (3 x 3 x 3 x 3) tensor in Voigt matrix representation: 320.5 68.2 71.6 0 0 0 68.2 196.5 76.8 0 0 0 71.6 76.8 233.5 0 0 0 0 0 0 64 0 0 0 0 0 0 77 0 0 0 0 0 0 78.7 {% endhighlight %} {% highlight matlab %} plot(C,'complete','upper') text(Miller({1,0,0},{0,1,0},{0,0,1},cs,'uvw'),'labeled','backgroundColor','White') mtexColorbar {% endhighlight %}

In particular, all of the spherical plotting options apply - filled contours, contour lines, 3d plots, as well as any spherical projection.

Furthermore, we can access this directional function directly by

{% highlight matlab %} sF = C.directionalMagnitude {% endhighlight %} {% highlight plaintext %} sF = S2FunHarmonicSym (Olivine) bandwidth: 4 antipodal: true {% endhighlight %}

and use it to derive e.g. the location of the maximum directional magnitude

{% highlight matlab %} [v,pos] = max(sF) {% endhighlight %} {% highlight plaintext %} v = 320.5000 pos = Miller (Olivine) antipodal: true h k l 4.7646 0.0013 0.0011 {% endhighlight %}

Rank two tensors and their principal axes

For a symmetric rank two tensor the directional magnitude is the quadratic form \(\vec x^T T \vec x\), and its extrema are attained along the eigenvectors. Hence the plot shows the principal axes directly.

{% highlight matlab %} T = tensor(diag([3 1 -1]),'rank',2,plottingConvention('y↑→x')) {% endhighlight %} {% highlight plaintext %} T = tensor (Y1↑→X1) rank: 2 (3 x 3) 3 0 0 0 1 0 0 0 -1 {% endhighlight %} {% highlight matlab %} plot(T,'complete','upper') mtexColorbar {% endhighlight %}
{% include inline_image.html file="TensorVisualisation_02.png" %}

the principle axes of a symmetric rank two tensor are computed by the command eig

{% highlight matlab %} [e,lambda] = eig(T); hold on plot(e,'plane','linewidth',2,'antipodal') hold off {% endhighlight %}

Sections

Some derived quantities are not functions of a single direction. The Poisson ratio and the shear modulus, for instance, depend on two directions, and it is only meaningful to evaluate them for directions perpendicular to the first one. Such functions are best drawn as a section along the corresponding great circle - see the elasticity chapter.

{% highlight matlab %} p = vector3d.Z; plotSection(C.PoissonRatio(p),p,'color','interp','linewidth',5) axis off mtexColorbar {% endhighlight %}
{% include inline_image.html file="TensorVisualisation_04.png" %}

Specialized plots

Beyond the directional magnitude there are visualizations that only make sense for one particular kind of tensor - wave velocities and their polarizations for the elasticity tensor, the birefringence of the refractive index tensor, or the piezoelectric modulus. Each is described in its own chapter.
