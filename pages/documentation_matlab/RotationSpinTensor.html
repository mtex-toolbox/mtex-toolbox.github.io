--- title: "Spin Tensors as Infinitesimal Changes of Rotations" sidebar: documentation_sidebar permalink: RotationSpinTensor.html folder: documentation toc: false --- Spin Tensors as Infinitesimal Changes of Rotations edit page

A spin tensor is a skew symmetric matrix, and it is how a rate of rotation is written: not where a body has turned to, but how fast and about which axis it is turning right now. This is the form in which rotation enters continuum mechanics - the antisymmetric part of a velocity gradient is a spin tensor - and it is the matrix side of the tangent space.

Start from a reference rotation.

{% highlight matlab %} rot_ref = rotation.byEuler(10*degree,20*degree,30*degree); {% endhighlight %}

Perturb it by a small rotation about the Cartesian direction \((1,2,3)\), by \(\delta = 0.01^\circ\). Rotations do not commute, so it matters whether the perturbation is applied before or after the reference rotation.

{% highlight matlab %} delta = 0.01*degree; rot_123 = rotation.byAxisAngle(vector3d(1,2,3),delta); rot_right = rot_123 * rot_ref; rot_left = rot_ref * rot_123; {% endhighlight %}

The first order Taylor coefficient of the perturbation, as \(\delta\) goes to zero, is

\[ T = \lim_{\delta \to 0} \frac{\tilde R - R}{\delta} \]

{% highlight matlab %} T_right = (rot_right.matrix - rot_ref.matrix) ./ delta T_left = (rot_left.matrix - rot_ref.matrix) ./ delta {% endhighlight %} {% highlight plaintext %} T_right = -0.4002 -0.4146 0.7724 0.5727 -0.5873 -0.2035 -0.2484 0.5297 -0.1218 T_left = -0.5399 -0.6025 0.5816 0.7530 -0.5816 0.1368 -0.2648 0.1140 0.0122 {% endhighlight %}

What such a derivative means is easier to see than to read. Turning a direction steadily about an axis sends it round a circle; the spin tensor is the velocity it sets off with. Below, the red arrow is the axis, the grey arrow a direction, the black circle the path it travels, and the blue arrow the velocity at the instant shown.

{% highlight matlab %} om = normalize(vector3d(1,2,3)); v0 = normalize(vector3d(1,0,0)); t = linspace(0,2*pi,300); tr = rotation.byAxisAngle(om,t) * v0; plot3(tr.x,tr.y,tr.z,'k','linewidth',1.5) hold on arrow3d(1.5*om,'faceColor','red') arrow3d(v0,'faceColor',[.45 .45 .45]) arrow3d(v0 + 0.6*normalize(cross(om,v0)),'faceColor','blue') hold off axis equal off {% endhighlight %}

T_right and T_left live in the tangent space at rot_ref. Neither is skew symmetric by itself - what makes them tangent vectors is that they become skew symmetric once the reference rotation is divided out, from the left or from the right.

{% highlight matlab %} S_right_L = matrix(inv(rot_ref)) * T_right S_right_R = T_right * matrix(inv(rot_ref)) S_left_L = matrix(inv(rot_ref)) * T_left S_left_R = T_left * matrix(inv(rot_ref)) {% endhighlight %} {% highlight plaintext %} S_right_L = -0.0000 -0.5892 0.4501 0.5893 -0.0001 -0.6709 -0.4501 0.6710 -0.0001 S_right_R = -0.0001 -0.8018 0.5345 0.8018 -0.0001 -0.2672 -0.5345 0.2673 -0.0000 S_left_L = -0.0001 -0.8018 0.5345 0.8018 -0.0001 -0.2672 -0.5345 0.2673 -0.0000 S_left_R = -0.0001 -0.9575 0.2758 0.9575 -0.0001 0.0850 -0.2758 -0.0850 -0.0000 {% endhighlight %}

Two of the four are skew symmetric, S_right_R and S_left_L.

A skew symmetric \(3 \times 3\) matrix has only three independent entries, \(S_{21}\), \(S_{31}\) and \(S_{32}\), and read as the vector \((S_{32},-S_{31},S_{21})\) they are the axis of the perturbation, scaled by its angle. Undoing the normalisation of the axis returns \((1,2,3)\).

{% highlight matlab %} vector3d(spinTensor(S_right_R)) * sqrt(14) vector3d(spinTensor(S_left_L)) * sqrt(14) {% endhighlight %} {% highlight plaintext %} ans = vector3d (y↓→x) x y z 1 2 3 ans = vector3d (y↓→x) x y z 1 2 3 {% endhighlight %}

The other two give the same axis seen in the other frame, i.e. turned by the reference rotation.

{% highlight matlab %} rot_ref * vector3d(spinTensor(S_right_L)) * sqrt(14) inv(rot_ref) * vector3d(spinTensor(S_left_R)) * sqrt(14) {% endhighlight %} {% highlight plaintext %} ans = vector3d (y↓→x) x y z 1 2 3 ans = vector3d (y↓→x) x y z 1 2 3 {% endhighlight %}

The Functions Exp and Log

Taking the difference of two rotation matrices is only meaningful while the perturbation is small. For a finite one the logarithm log maps the relative rotation to a skew-symmetric matrix without using a small-angle approximation. As with every rotation logarithm, the principal result is limited to angles up to \(180^\circ\).

{% highlight matlab %} % define a large perturbation with rotational angle 1 radian delta = 1; rot_123 = rotation.byAxisAngle(vector3d(1,2,3),1); S = log(rot_ref * rot_123,rot_ref, SO3TangentSpace.rightSpinTensor); S * sqrt(14) S = log(rot_123 * rot_ref,rot_ref, SO3TangentSpace.leftSpinTensor); S * sqrt(14) {% endhighlight %} {% highlight plaintext %} ans = spinTensor (y↓→x) rank: 2 (3 × 3) 0 -3 2 3 0 -1 -2 1 0 ans = spinTensor (y↓→x) rank: 2 (3 × 3) 0 -3 2 3 0 -1 -2 1 0 {% endhighlight %}

The three entries again give the axis times the angle, now for a perturbation of one radian rather than \(0.01^\circ\).

The same is obtained as a vector directly, with SO3TangentSpace.rightVector and SO3TangentSpace.leftVector.

{% highlight matlab %} v = log(rot_ref * rot_123,rot_ref,SO3TangentSpace.rightVector); v * sqrt(14) v = log(rot_123 * rot_ref,rot_ref,SO3TangentSpace.leftVector); v * sqrt(14) {% endhighlight %} {% highlight plaintext %} ans = SO3TangentVector (crystal) intern symmetries: 1 → y↓→x tangentSpace: rightVector x y z 1 2 3 ans = SO3TangentVector (y↓→x) intern symmetries: 1 → y↓→x tangentSpace: leftVector x y z 1 2 3 {% endhighlight %}

The Other Way Round

exp goes back: given a spin tensor S or a rotation vector v, it applies that perturbation to the reference rotation. The first line of each block below is the rotation the perturbation came from, so all three results in a block have to agree.

Under Crystal Symmetry

For orientations the side on which a perturbation is applied is not a formality: multiplying from the right acts in crystal coordinates, multiplying from the left in specimen coordinates, see Theory. The same calculation once more, now with trigonal crystal symmetry.

{% highlight matlab %} cs = crystalSymmetry('321'); % consider an arbitrary rotation ori_ref = orientation.byEuler(10*degree,20*degree,30*degree,cs); % next we disturb rot_ref by a rotation about the axis (123) mori_123 = orientation.byAxisAngle(Miller(1,2,-3,3,cs),1); % first we multiply from the right ori = ori_ref * mori_123 {% endhighlight %} {% highlight plaintext %} ori = orientation (321 → y↓→x) Bunge Euler angles in degree phi1 Phi phi2 79.3156 43.3785 9.9013 {% endhighlight %}

The right tangent vector is the perturbation written in crystal coordinates, so it comes back as a <Miller.Miller.html Miller> - and it is the axis \((1,2,\bar3,3)\) the perturbation was defined with.

{% highlight matlab %} v = Miller(log(ori,ori_ref,SO3TangentSpace.rightVector),ori.CS); round(v) exp(v,ori_ref,SO3TangentSpace.rightVector) {% endhighlight %} {% highlight plaintext %} ans = Miller (321) h k i l 1 2 -3 3 ans = orientation (321 → y↓→x) Bunge Euler angles in degree phi1 Phi phi2 79.3156 43.3785 9.9013 {% endhighlight %}
