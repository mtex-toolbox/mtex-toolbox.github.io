Numerical work on the rotation group needs orientations spread as evenly as possible over it - to integrate an ODF, to sample one, or to search for a best fit. As on the sphere, there is no perfectly even arrangement, and the constructions on offer differ in how close they come.

{% highlight matlab %} plottingConvention.default('y↑→x'); % define a crystal symmetry cs = crystalSymmetry('432') {% endhighlight %} {% highlight plaintext %} cs = crystalSymmetry (⊙c→a) symmetry: 432 elements: 24 a, b, c : 1, 1, 1 {% endhighlight %}

The Equispaced Grid

equispacedSO3Grid covers the fundamental region of the given symmetry with a nearly constant spacing.

{% highlight matlab %} ori = equispacedSO3Grid(cs,'resolution',5*degree) {% endhighlight %} {% highlight plaintext %} ori = SO3Grid (432 → y↑→x) grid: 4923 orientations, resolution: 5° {% endhighlight %}

Just under 5000 orientations at \(5^\circ\) for cubic symmetry. Seen in axis angle space they fill the fundamental region evenly.

{% highlight matlab %} plot(ori,'axisAngle') {% endhighlight %} {% highlight plaintext %} plot 2000 random orientations out of 4923 given orientations {% endhighlight %}
{% include inline_image.html file="OrientationGrid_01.png" %}

Checking for Equidistribution

Even spacing is easier to claim than to achieve, and the honest test is to treat the grid as a data set: an ODF built from it should be the uniform one, and the pole figures of a uniform ODF are flat at 1.

{% highlight matlab %} odf = unimodalODF(ori) plotPDF(odf,Miller({1,0,0},{1,1,0},{1,1,1},cs)) mtexColorbar {% endhighlight %} {% highlight plaintext %} odf = SO3FunRBF (432 → y↑→x) multimodal components kernel: de la Vallee Poussin, halfwidth 10° center: 4923 orientations, resolution: 5° weight: 1 {% endhighlight %}
{% include inline_image.html file="OrientationGrid_02.png" %}

Between 0.93 and 1.02 - flat to within a few percent, which is what a usable grid looks like.

The Regular Grid

regularSO3Grid instead steps through the three Euler angles regularly.

{% highlight matlab %} ori = regularSO3Grid(cs,'resolution',5*degree) {% endhighlight %} {% highlight plaintext %} ori = orientation (432 → y↑→x) size: 72 × 19 × 18 {% endhighlight %}

Five times as many orientations for the same nominal resolution, 24624 against 4923.

{% highlight matlab %} plot(ori,'axisAngle') {% endhighlight %} {% highlight plaintext %} plot 2000 random orientations out of 24624 given orientations {% endhighlight %}
{% include inline_image.html file="OrientationGrid_03.png" %}

And the extra points do not buy uniformity. The same test now runs from 0.79 to 2.62 - the grid piles up wherever Euler angle space is compressed, exactly as the regular grid on the sphere piles up at the poles, see Spherical Grids.

{% highlight matlab %} odf = unimodalODF(ori) plotPDF(odf,Miller({1,0,0},{1,1,0},{1,1,1},cs)) mtexColorbar {% endhighlight %} {% highlight plaintext %} odf = SO3FunRBF (432 → y↑→x) multimodal components kernel: de la Vallee Poussin, halfwidth 10° center: 24624 orientations {% endhighlight %}
{% include inline_image.html file="OrientationGrid_04.png" %}

Use the regular grid when the Euler angle raster itself is wanted, for instance to write an ODF to a file that expects one, and the equispaced grid for everything else.

Grids Around a Given Orientation

localOrientationGrid covers a ball around one orientation rather than the whole region, which is what a local search or a perturbation study needs.

{% highlight matlab %} center = orientation.byEuler(10*degree,20*degree,30*degree,cs); ori = localOrientationGrid(center,10*degree,'resolution',2.5*degree) {% endhighlight %} {% highlight plaintext %} ori = orientation (432 → y↑→x) size: 265 × 1 {% endhighlight %}

265 orientations arranged in shells about the centre. The outermost shell sits at 8.75 degree, half a resolution step inside the radius that was asked for.

{% highlight matlab %} max(angle(ori,center)) ./ degree {% endhighlight %} {% highlight plaintext %} ans = 8.7500 {% endhighlight %}
