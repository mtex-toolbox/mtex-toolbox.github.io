--- title: "The Index of EBSD data" sidebar: documentation_sidebar permalink: EBSDIndex.html folder: documentation toc: false --- The Index of EBSD data edit page

In previous chapters we have discussed how to select EBSD data by properties. In this chapter we discus the ordering of EBSD pixels within MTEX. Lets start by importing some sample data

{% highlight matlab %} mtexdata twins {% endhighlight %} {% highlight plaintext %} ebsd = EBSDsquare (y↑→x) Phase Orientations Mineral Color Symmetry Crystal reference frame 0 46 (0.2%) notIndexed none 1 22833 (100%) Magnesium LightSkyBlue 6/mmm X||a*, Y||b, Z||c Properties: bands, bc, bs, error, mad, oldId Scan unit : um X x Y x Z : [0, 50] x [0, 41] x [0, 0] Normal vector: (0,0,1) Square grid :137 x 167 {% endhighlight %}

The imported map is an EBSDsquare, i.e. it is already stored as a matrix - see Square and Hex Grids. Restricting it to a very small rectangular subset gives back a plain list of pixels, since the selection is in general not a rectangle

{% highlight matlab %} poly = [44 0 4 2]; ebsd = ebsd(inpolygon(ebsd,poly)) plot(ebsd,ebsd.orientations,'micronbar','off','edgecolor','k','backend','patch') {% endhighlight %} {% highlight plaintext %} ebsd = EBSD (y↑→x) Phase Orientations Mineral Color Symmetry Crystal reference frame 1 98 (100%) Magnesium LightSkyBlue 6/mmm X||a*, Y||b, Z||c Properties: bands, bc, bs, error, mad, oldId Scan unit : um X x Y x Z : [44, 48] x [0, 1.8] x [0, 0] Normal vector: (0,0,1) {% endhighlight %}
{% include inline_image.html file="EBSDIndex_01.png" %}

In the above plot each square corresponds to one entry in the variable ebsd which as an index from 1 to 98. Let us visualize this index

{% highlight matlab %} text(ebsd,1:length(ebsd)) {% endhighlight %}
{% include inline_image.html file="EBSDIndex_02.png" %}

We may easily select specific pixels by specifying their indices

{% highlight matlab %} hold on plot(ebsd(16:18),'edgeColor','red','facecolor','none','linewidth',4,'backend','patch') legend off hold off {% endhighlight %}
{% include inline_image.html file="EBSDIndex_03.png" %}

Whether lines or columns run first is inherited from the order of the data the subset was taken from. Here that is the gridded map, whose linear index runs down a matrix column, i.e. along y - which is why the numbers above count downwards rather than across. Had the map been imported as a plain list, they would follow the order of the lines in the file instead.

Since we have restricted our large EBSD map to the small subset, the indices of the restricted data do not coincide with the indices of the imported data anymore. However, the original indices are still stored in ebsd.id. Lets visualize those

{% highlight matlab %} plot(ebsd,ebsd.orientations,'micronbar','off','edgecolor','k','backend','patch') text(ebsd,ebsd.id) {% endhighlight %}
{% include inline_image.html file="EBSDIndex_04.png" %}

In order to select EBSD data according to their original id use the option 'id', i.e., the three pixels highlighted above are

{% highlight matlab %} hold on plot(ebsd('id',ebsd.id(16:18)),'edgeColor','red','facecolor','none','linewidth',4,'backend','patch') legend off hold off {% endhighlight %}
{% include inline_image.html file="EBSDIndex_05.png" %}

Square Grids

Our subset is a list, but the pixels in it do sit on a grid, so we may put it back into matrix form with gridify.

{% highlight matlab %} ebsd = ebsd.gridify; plot(ebsd,ebsd.orientations,'micronbar','off','edgeColor','black','backend','patch') [i,j] = ndgrid(1:size(ebsd,1),1:size(ebsd,2)); str = arrayfun(@(a,b) ['(' int2str(a) ',' int2str(b) ')'],i,j,'UniformOutput',false); text(ebsd,str) {% endhighlight %}
{% include inline_image.html file="EBSDIndex_06.png" %}

This allows to select EBSD data simply by their coordinates within the grid, e.g., by

{% highlight matlab %} hold on plot(ebsd(2,2:4),'edgeColor','red','facecolor','none','linewidth',4,'backend','patch') legend off hold off {% endhighlight %}
{% include inline_image.html file="EBSDIndex_07.png" %}

Note that the gridify command changes the order of measurements. They are now sorted such that rows run first and columns second, as this is the default convention how Matlab indexes matrices. This is unavoidable and the reason why an imported map is put on its grid right away - see Square and Hex Grids.

{% highlight matlab %} plot(ebsd,ebsd.orientations,'micronbar','off','edgeColor','black','backend','patch') text(ebsd,1:length(ebsd)) {% endhighlight %}
{% include inline_image.html file="EBSDIndex_08.png" %}

Hexagonal Grid

Everything above applies to EBSD data measured on a hexagonal grid as well. Such data is imported as an EBSDhex, i.e. it already is in matrix form

{% highlight matlab %} mtexdata titanium silent ebsd {% endhighlight %} {% highlight plaintext %} ebsd = EBSDhex (y↓→x) Phase Orientations Mineral Color Symmetry Crystal reference frame 0 8100 (99%) Titanium (Alpha) LightSkyBlue 622 X||a, Y||b*, Z||c Properties: ci, grainid, iq, sem_signal, oldId Scan unit : um X x Y x Z : [0, 1002] x [0, 998] x [0, 0] Normal vector: (0,0,1) Hex grid :97 x 84 {% endhighlight %}

and can be indexed similarly as in the square case.

{% highlight matlab %} ebsd = ebsd(10:16,68:79); {% endhighlight %}

Lets visualize the matrix coordinates for the hexagonal grid

{% highlight matlab %} plot(ebsd,ebsd.orientations,'edgeColor','k','micronbar','off','unitcell') axis off [i,j] = ndgrid(1:size(ebsd,1),1:size(ebsd,2)); str = arrayfun(@(a,b) ['(' int2str(a) ',' int2str(b) ')'],i,j,'UniformOutput',false); text(ebsd,str) {% endhighlight %}
{% include inline_image.html file="EBSDIndex_09.png" %}

Cube Coordinates

In hexagonal grids it is sometimes advantageous to use three digit cube coordinates to index the cell. This can be done using the commands hex2cube and cube2hex. Much more details on indexing hex grids can be found at here.

{% highlight matlab %} plot(ebsd,ebsd.orientations,'edgeColor','k','micronbar','off','unitcell') axis off [i,j] = ndgrid(1:size(ebsd,1),1:size(ebsd,2)); [x,y,z] = ebsd.hex2cube(i,j); str = arrayfun(@(a,b,c) ['(' int2str(a) ',' int2str(b) ',' int2str(c) ')'],x,y,z,'UniformOutput',false); text(ebsd,str) {% endhighlight %}
