--- title: "Fibres of Orientations" sidebar: documentation_sidebar permalink: OrientationFibre.html folder: documentation toc: false --- Fibres of Orientations edit page

A fibre is a curve through orientation space, stored as a single variable of type <fibre.fibre.html fibre>. Fibres matter because many real textures are not a point but a line: all orientations that put one crystal direction along one specimen direction, with the rotation about it left free. The rolling textures of cubic metals are described almost entirely in these terms.

To see how one is built, take the cube and the goss orientation

{% highlight matlab %} % define crystal and specimen symmetry cs = crystalSymmetry('432'); ss = specimenSymmetry('1'); % and two orientations ori1 = orientation.cube(cs,ss); ori2 = orientation.goss(cs,ss); {% endhighlight %}

and then the fibre connecting both orientations

{% highlight matlab %} f = fibre(ori1,ori2) {% endhighlight %} {% highlight plaintext %} f = fibre (432 → y↓→x) h || r: (100) || (1,0,0) o1 → o2: (0°,0°,0°) → (0°,45°,0°) {% endhighlight %}

Finally we plot everything into the Euler space

{% highlight matlab %} % plot the fibre plot(f,'DisplayName','Fibre','linewidth',4,'linecolor','green') % and on top of it the orientations hold on plot(ori1,'DisplayName','CUBE','MarkerSize',12,'MarkerFaceColor','darkred','MarkerEdgeColor','k') plot(ori2,'DisplayName','GOSS','MarkerSize',12,'MarkerFaceColor','blue','MarkerEdgeColor','k') hold off legend('Location','northwest') {% endhighlight %}
{% include inline_image.html file="OrientationFibre_01.png" %}

The green line runs from the one orientation to the other - it is the shortest path between them, the orientation space equivalent of a straight line. The same fibre in axis angle space:

{% highlight matlab %} % plot the fibre plot(f,'linecolor','green','linewidth',6,'axisAngle') % and on top of it the orientations hold on plot(ori1,'MarkerFaceColor','darkred','MarkerSize',15,'axisAngle') plot(ori2,'MarkerFaceColor','blue','MarkerSize',15) hold off {% endhighlight %}
{% include inline_image.html file="OrientationFibre_02.png" %}

What is drawn so far is only the segment between the two orientations. Orientation space has no boundary, so continuing along the curve brings it back to where it started: a full fibre is a circle through the two orientations. That is the option 'full'.

{% highlight matlab %} f = fibre(ori1,ori2,'full') hold on plot(f,'linecolor','gold','linewidth',3,'project2FundamentalRegion') hold off {% endhighlight %} {% highlight plaintext %} f = fibre (432 → y↓→x) h || r: (100) || (1,0,0) {% endhighlight %}
{% include inline_image.html file="OrientationFibre_03.png" %}

Fibres in Pole Figures and Inverse Pole Figures

Everything that can be plotted for orientations can be plotted for fibres, pole figures and inverse pole figures included, through plotPDF and plotIPDF. A fibre becomes a curve rather than a point in each of them.

{% highlight matlab %} plotPDF(f,Miller({1,1,0},{1,1,1},cs),'linewidth',3,'lineColor','orange') {% endhighlight %}
{% include inline_image.html file="OrientationFibre_04.png" %}

One difference to orientation plots matters: a fibre is not automatically symmetrised, so the plot above shows one curve where a symmetrised orientation would have shown all its equivalents. Asking for them is symmetrise.

{% highlight matlab %} plotPDF(f.symmetrise,Miller({1,1,0},{2,1,0},{1,1,1},cs),'linewidth',3,'lineColor','orange') {% endhighlight %}
{% include inline_image.html file="OrientationFibre_05.png" %}

Inverse pole figures are by default restricted to the fundamental sector. You may use the option 'complete' to plot the entire sphere.

{% highlight matlab %} % an inverse pole figure plot r = [vector3d(1,1,0),vector3d(2,1,0),vector3d(1,1,1)]; plotIPDF(f.symmetrise,r,'linewidth',3,'lineColor','orange') {% endhighlight %}
{% include inline_image.html file="OrientationFibre_06.png" %}

Defining a Fibre by Directions

Alternatively, a fibre can also be defined by a pair of a crystal and a specimen direction. In this case it consists of all orientations that align the crystal direction with the specimen direction. As an example, the following fibre contains all orientations for which the c-axis \([001]\) is parallel to the specimen Z axis.

{% highlight matlab %} f = fibre(Miller(0,0,1,cs,'uvw'),vector3d.Z) plot(f,'linecolor','gold','linewidth',4,'project2FundamentalRegion','axisAngle') {% endhighlight %} {% highlight plaintext %} f = fibre (432 → y↓→x) h || r: [001] || (0,0,1) {% endhighlight %}
{% include inline_image.html file="OrientationFibre_07.png" %}

If both directions are Miller variables, the fibre contains all misorientations that bring the two crystal directions into alignment.

Finally, a fibre can be defined by an initial orientation ori1 and a direction h, i.e., all orientations ori of this fibre satisfy

{% highlight matlab %} ori * h = ori1 * h {% endhighlight %}

The following code defines a fibre that passes through the cube orientation and rotates about the \([111]\) axis.

{% highlight matlab %} f = fibre(ori1,Miller(1,1,1,cs,'uvw')) plot(f,'linecolor','darkred','linewidth',4,'project2FundamentalRegion','axisAngle') {% endhighlight %} {% highlight plaintext %} f = fibre (432 → y↓→x) h || r: [111] || (1,1,1) {% endhighlight %}
{% include inline_image.html file="OrientationFibre_08.png" %}

Predefined Fibres

The fibres of rolling texture have names, as the components do - alpha, beta, gamma, epsilon, eta, tau and theta - and MTEX has them built in.

{% highlight matlab %} ss = specimenSymmetry('orthorhombic'); beta = fibre.beta(cs,ss,'full') {% endhighlight %} {% highlight plaintext %} beta = fibre (432 → y↓→x (mmm)) h || r: (12 6 11) || (-1,-1,4) {% endhighlight %}

An overview of all of them, for cubic crystal and orthorhombic specimen symmetry:

{% highlight matlab %} plot(fibre.alpha(cs,ss,'full'),'linewidth',3,'lineColor',ind2color(1),'DisplayName','alpha') hold on plot(fibre.beta(cs,ss,'full'),'linewidth',3,'lineColor',ind2color(2),'DisplayName','beta') plot(fibre.gamma(cs,ss,'full'),'linewidth',3,'lineColor',ind2color(3),'DisplayName','gamma') plot(fibre.epsilon(cs,ss,'full'),'linewidth',3,'lineColor',ind2color(4),'DisplayName','epsilon') plot(fibre.eta(cs,ss,'full'),'linewidth',3,'lineColor',ind2color(5),'DisplayName','eta') plot(fibre.tau(cs,ss,'full'),'linewidth',3,'lineColor',ind2color(6),'DisplayName','tau') plot(fibre.theta(cs,ss,'full'),'linewidth',3,'lineColor',ind2color(7),'DisplayName','theta') hold off legend('Location','best') {% endhighlight %}
{% include inline_image.html file="OrientationFibre_09.png" %}

Fibre ODFs

A fibre is a curve of zero volume, and a real texture is a spread around one. fibreODF turns the curve into a density with a given halfwidth, which is what a measurement is fitted against.

{% highlight matlab %} odf = fibreODF(beta,'halfwidth',10*degree) % and plot it in 3d plot3d(odf) % this adds the fibre to the plots hold on plot(beta.symmetrise,'lineColor','b','linewidth',4) hold off {% endhighlight %} {% highlight plaintext %} odf = SO3FunCBF (432 → y↓→x (mmm)) kernel: de la Vallee Poussin, halfwidth 10° fibre : (12 6 11) || -1,-1,4 weight: 1 {% endhighlight %}
{% include inline_image.html file="OrientationFibre_10.png" %}

An ODF Along a Fibre

An ODF can also be evaluated along a fibre and plotted as a curve, here the beta fibre ODF read along the eta fibre.

{% highlight matlab %} plot(odf,fibre.eta(cs,ss),'linewidth',2) {% endhighlight %}
{% include inline_image.html file="OrientationFibre_11.png" %}

The Volume Around a Fibre

volume measures how much of an ODF lies within a tube of given radius about a fibre - the number quoted when a texture is reported as "so many percent beta fibre".

{% highlight matlab %} 100 * volume(odf,beta,5*degree) {% endhighlight %} {% highlight plaintext %} ans = 58.0557 {% endhighlight %}

58 percent of this ODF lies within 5 degree of the fibre it was built on, and within 10 degree it is the whole of it, to the precision printed.

{% highlight matlab %} 100 * volume(odf,beta,10*degree) {% endhighlight %} {% highlight plaintext %} ans = 100 {% endhighlight %}
