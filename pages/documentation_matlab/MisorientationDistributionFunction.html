--- title: 'Misorientation Distribution Function' sidebar: documentation_sidebar permalink: MisorientationDistributionFunction.html folder: documentation toc: false --- Misorientation Distribution Function edit page

A single misorientation describes one pair of crystals. A map contains thousands of such pairs. Their density in misorientation space is the misorientation distribution function, or MDF.

There are two MDFs, and confusing them changes the physical question:

  1. The boundary or correlated MDF uses misorientations between grains that actually touch.
  2. The uncorrelated MDF uses independently drawn orientations, whether or not their measurement points are neighbours.

The uncorrelated MDF is what the two textures alone imply. It is not a uniform distribution unless both textures are uniform. The boundary MDF also contains the effect of which orientations became neighbours. Comparing the two separates a preferred orientation relationship from an accidental consequence of texture.

This page assumes familiarity with misorientation theory, grain reconstruction, and kernel density estimation. The plotting frame below matches the specimen frame stored with this data set.

{% highlight matlab %} plottingConvention.default('y↑→x'); mtexdata forsterite silent grains = calcGrains(ebsd); {% endhighlight %}

The Boundary Misorientation Distribution Function

First take the misorientation of every forsterite--enstatite boundary segment. The displayed summary identifies the mapping from the forsterite crystal frame to the enstatite crystal frame and reports 11,751 samples.

{% highlight matlab %} mori_boundary = grains.boundary('Fo','En').misorientation {% endhighlight %} {% highlight plaintext %} mori_boundary = misorientation (Forsterite → Enstatite) size: 11751 × 1 {% endhighlight %}

This is one sample per boundary segment, not one vote per neighbouring grain pair. A long boundary therefore contributes more samples than a short one. The result also depends on how finely the boundary was sampled.

calcDensity estimates the density, just as it does for a list of orientations. The halfwidth is the angular smoothing scale. A smaller value resolves sharper peaks but also more sampling noise.

{% highlight matlab %} mdf_boundary = calcDensity(mori_boundary,'halfwidth',5*degree) {% endhighlight %} {% highlight plaintext %} mdf_boundary = SO3FunHarmonic (Forsterite → Enstatite) bandwidth: 48 weight: 1 {% endhighlight %}

The result is an SO(3) function and supports everything such a function does. MTEX normalizes its mean density to one, so values are commonly read as multiples of a random distribution (mrd). Its maximum gives the preferred misorientation.

{% highlight matlab %} [peakMRD,preferredMori] = max(mdf_boundary); peakMRD {% endhighlight %} {% highlight plaintext %} peakMRD = 118.3380 {% endhighlight %} {% highlight matlab %} preferredAxis = round(axis(preferredMori)) {% endhighlight %} {% highlight plaintext %} preferredAxis = Miller (222) h k l 0 0 1 {% endhighlight %} {% highlight matlab %} preferredAngle = angle(preferredMori) ./ degree {% endhighlight %} {% highlight plaintext %} preferredAngle = 89.9817 {% endhighlight %}

The peak is 118.34 mrd at \(89.98^\circ\) about \((001)\) in the forsterite crystal frame. Forsterite and enstatite share lattice planes in this relationship, and it dominates the phase boundaries of this map.

An axis--angle section at \(90^\circ\) cuts through this maximum.

{% highlight matlab %} plotSection(mdf_boundary,'axisAngle',90*degree) mtexColorbar {% endhighlight %}
{% include inline_image.html file="MisorientationDistributionFunction_01.png" %}

The narrow red spot at the middle of the lower edge is the \((001)\) peak. Most other axes in this section have density close to zero.

The Uncorrelated Misorientation Distribution Function

calcMisorientation draws random pairs of EBSD pixels without requiring them to be neighbours. By default it draws 100,000 pairs and rejects points closer than one percent of the map diagonal. Fixing the random seed makes the published example reproducible.

{% highlight matlab %} rng default; mori_uncorrelated = calcMisorientation(ebsd('En'),ebsd('Fo')) {% endhighlight %} {% highlight plaintext %} mori_uncorrelated = misorientation (Forsterite → Enstatite) size: 99978 × 1 {% endhighlight %}

The summary reports 99,978 accepted pairs. These are pixel orientations, not grain mean orientations, so large phases and densely sampled regions contribute more strongly than small ones.

{% highlight matlab %} mdf_uncorrelated = calcDensity(mori_uncorrelated) {% endhighlight %} {% highlight plaintext %} mdf_uncorrelated = SO3FunHarmonic (Forsterite → Enstatite) bandwidth: 25 weight: 1 {% endhighlight %} {% highlight matlab %} uncorrelatedPeakMRD = max(mdf_uncorrelated) {% endhighlight %} {% highlight plaintext %} uncorrelatedPeakMRD = 2.0566 {% endhighlight %}

Its maximum is 2.06 mrd, not 118.34 mrd. The preferred boundary relationship is absent from independently paired pixels. The boundary peak is therefore a property of the boundary network, not something the two textures produce by themselves.

{% highlight matlab %} plotSection(mdf_uncorrelated,'axisAngle',90*degree) mtexColorbar {% endhighlight %}
{% include inline_image.html file="MisorientationDistributionFunction_02.png" %}

The maximum is now a broad lobe rather than the narrow \((001)\) spot. The colorbar also shows that its scale is about two orders of magnitude lower.

The Uncorrelated MDF from Two ODFs

The uncorrelated MDF needs no individual orientations at all. It is completely determined by the two orientation distribution functions (ODFs). The ODFs below use the same pixel weighting as the direct sample.

{% highlight matlab %} odf_fo = calcDensity(ebsd('fo').orientations,'halfwidth',10*degree); odf_en = calcDensity(ebsd('en').orientations,'halfwidth',10*degree); {% endhighlight %}

calcMDF computes their convolution. The argument order below gives the same forsterite-to-enstatite mapping as the boundary misorientations.

{% highlight matlab %} mdf_from_odfs = calcMDF(odf_en,odf_fo) {% endhighlight %} {% highlight plaintext %} mdf_from_odfs = SO3FunHarmonic (Forsterite → Enstatite) bandwidth: 25 weight: 1 {% endhighlight %}

This and the direct estimate describe the same uncorrelated population. Their relative difference is

{% highlight matlab %} relativeDifferencePercent = 100 * ... norm(mdf_from_odfs - mdf_uncorrelated) ./ norm(mdf_uncorrelated) {% endhighlight %} {% highlight plaintext %} relativeDifferencePercent = 4.9397 {% endhighlight %}

The difference is 4.94 percent in the \(L^2\) norm. The ODF route smooths each texture before convolution, whereas the direct route smooths the sampled pair differences once. Finite random sampling contributes as well; the difference does not indicate different physical content.

{% highlight matlab %} plotSection(mdf_from_odfs,'axisAngle',90*degree) mtexColorbar {% endhighlight %}
{% include inline_image.html file="MisorientationDistributionFunction_03.png" %}

The broad maximum and the low-density patch on the right match the direct estimate above. The agreement is visible in both location and scale.

With one ODF, calcMDF gives the uncorrelated misorientations within one phase. The displayed antipodal: true records that a same-phase pair has grain exchange symmetry.

{% highlight matlab %} mdf_fo = calcMDF(odf_fo) {% endhighlight %} {% highlight plaintext %} mdf_fo = SO3FunHarmonic (Forsterite → Forsterite) antipodal: true bandwidth: 25 weight: 1 {% endhighlight %}

Angle Distribution

An MDF is a function on a three-dimensional space. Integrating out the misorientation axis leaves the one-dimensional angle distribution.

{% highlight matlab %} close all plotAngleDistribution(mori_boundary,'figSize','small') hold on plotAngleDistribution(mdf_from_odfs) hold off legend('boundary','uncorrelated') {% endhighlight %}
{% include inline_image.html file="MisorientationDistributionFunction_04.png" %}

The boundary histogram has an extra peak near \(90^\circ\). The uncorrelated curve has no matching spike, although it follows the broader trend of the histogram. An angle peak alone does not identify the complete orientation relationship because the axis has been integrated out.

Uniform orientations provide a third reference. Their angle distribution is not flat: large rotation angles occupy more of rotation space than small ones, and crystal symmetry limits the largest distinct angle. This geometry is illustrated in Plotting Rotations.

{% highlight matlab %} close all plotAngleDistribution(mdf_from_odfs,'figSize','small') hold on plotAngleDistribution(ebsd('fo').CS,ebsd('en').CS) hold off legend('uncorrelated texture','uniform orientations','Location','best') {% endhighlight %}
{% include inline_image.html file="MisorientationDistributionFunction_05.png" %}

The orange curve is the texture-free baseline, not a horizontal line. The numbers behind the curves come from calcAngleDistribution(mdf) and calcAngleDistribution(ori). See Angle Distribution for their use.

Axis Distribution

The other marginal integrates out the angle and retains the misorientation axis. First consider the boundary misorientations.

{% highlight matlab %} plotAxisDistribution(mori_boundary,'smooth') mtexColorbar {% endhighlight %}
{% include inline_image.html file="MisorientationDistributionFunction_06.png" %}

Their axes form a narrow maximum at \((001)\), consistent with the full MDF. The uncorrelated MDF gives a much broader distribution.

{% highlight matlab %} plotAxisDistribution(mdf_from_odfs) mtexColorbar {% endhighlight %}
{% include inline_image.html file="MisorientationDistributionFunction_07.png" %}

The broad lobe covers much of the symmetry sector rather than collapsing onto the boundary relationship. The marginal is itself a spherical function, returned by calcAxisDistribution.

{% highlight matlab %} axisDistribution = calcAxisDistribution(mdf_boundary) {% endhighlight %} {% highlight plaintext %} axisDistribution = S2FunHarmonicSym (222) bandwidth: 64 {% endhighlight %}

References

  • J. Pospiech, K. Sztwiertnia, and F. Haessner, The Misorientation Distribution Function, Texture, Stress, and Microstructure 6 (1983), 201--215, introduces the MDF as a three-dimensional distribution.
  • J. K. Mackenzie, Second Paper on Statistics Associated with the Random Disorientation of Cubes, Biometrika 45 (1958), 229--240, derives the cubic random-disorientation baseline.
  • A. Morawiec, Orientations and Rotations: Computations in Crystallographic Textures, Springer, 2004, develops rotation-space geometry and misorientation statistics.
