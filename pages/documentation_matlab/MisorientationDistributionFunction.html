When speaking about the misorientation distribution function (MDF) one has to distinguish two cases

  1. the boundary (correlated) misorientation distribution function
  2. the uncorrelated misorientation distribution function

While the first one considers only misorientations at grain boundaries the second one considers misorientations between arbitrary crystal orientations. To illustrate the difference lets consider the following EBSD data set and reconstruct its grains.

{% highlight matlab %} plottingConvention.default('y↑→x'); mtexdata forsterite silent grains = calcGrains(ebsd) {% endhighlight %} {% highlight plaintext %} grains = grain2d (y↑→x) Phase Grains Pixels Mineral Symmetry Color 0 6 621 notIndexed none 1 1089 152345 Forsterite mmm LightSkyBlue 2 515 26058 Enstatite mmm DarkSeaGreen 3 1496 9064 Diopside 12/m1 Goldenrod boundary segments: 44425 (2.1e+06 µm) inner boundary segments: 265 (12008 µm) triple points: 3416 Properties: meanRotation, GOS {% endhighlight %}

The Boundary Misorientation Distribution Function

In order to compute the boundary misorientation distribution function for the phase transition from Forsterite to Enstatite we first extract the misorientations along all Forsterite to Enstatite boundary segments

{% highlight matlab %} mori_boundary = grains.boundary('Fo','En').misorientation {% endhighlight %} {% highlight plaintext %} mori_boundary = misorientation (Forsterite → Enstatite) size: 11751 x 1 {% endhighlight %}

and second compute the corresponding density function using the command calcDensity

{% highlight matlab %} mdf_boundary = calcDensity(mori_boundary,'halfwidth',5*degree) {% endhighlight %} {% highlight plaintext %} mdf_boundary = SO3FunHarmonic (Forsterite → Enstatite) bandwidth: 48 weight: 1 {% endhighlight %}

The misorientation distribution function can be processed as any other orientation valued function. E.g. we may compute the preferred misorientation

{% highlight matlab %} [v,mori] = max(mdf_boundary) {% endhighlight %} {% highlight plaintext %} v = 118.3380 mori = misorientation (Forsterite → Enstatite) Bunge Euler angles in degree phi1 Phi phi2 134.616 0.0669012 135.402 {% endhighlight %}

or plot it in an axis angle section

{% highlight matlab %} plotSection(mdf_boundary,'axisAngle',90*degree) mtexColorbar {% endhighlight %}
{% include inline_image.html file="MisorientationDistributionFunction_01.png" %}

The Uncorrelated Misorientation Distribution Function

The uncorrelated misorientation distribution function is computed from misorientations between arbitrary orientations, which are extracted by calcMisorientation

{% highlight matlab %} mori = calcMisorientation(ebsd('En'),ebsd('Fo')) mdf_uncor = calcDensity(mori) {% endhighlight %} {% highlight plaintext %} mori = misorientation (Forsterite → Enstatite) size: 99969 x 1 mdf_uncor = SO3FunHarmonic (Forsterite → Enstatite) bandwidth: 25 weight: 1 {% endhighlight %}

Obviously it is different from the boundary misorientation distribution function.

{% highlight matlab %} plotSection(mdf_uncor,'axisAngle',90*degree) mtexColorbar {% endhighlight %}
{% include inline_image.html file="MisorientationDistributionFunction_02.png" %}

Computing the Uncorrelated MDF from two ODFs

The uncorrelated MDF does not require the individual orientations at all - it is fully determined by the two ODFs involved. Let us estimate them from the same data set

{% highlight matlab %} odf_fo = calcDensity(ebsd('fo').orientations,'halfwidth',10*degree) odf_en = calcDensity(ebsd('en').orientations,'halfwidth',10*degree) {% endhighlight %} {% highlight plaintext %} odf_fo = SO3FunHarmonic (Forsterite → y↑→x) bandwidth: 25 weight: 1 odf_en = SO3FunHarmonic (Enstatite → y↑→x) bandwidth: 25 weight: 1 {% endhighlight %}

Then the uncorrelated misorientation function between these two ODFs is computed by calcMDF

{% highlight matlab %} mdf = calcMDF(odf_en,odf_fo) {% endhighlight %} {% highlight plaintext %} mdf = SO3FunHarmonic (Forsterite → Enstatite) bandwidth: 25 weight: 1 {% endhighlight %}

This misorientation distribution function should be similar to the uncorrelated misorientation function computed directly from the EBSD data

{% highlight matlab %} plotSection(mdf,'axisAngle',90*degree) mtexColorbar {% endhighlight %}
{% include inline_image.html file="MisorientationDistributionFunction_03.png" %}

Passing a single ODF to calcMDF gives the uncorrelated misorientations within one phase

{% highlight matlab %} mdf_fo = calcMDF(odf_fo) {% endhighlight %} {% highlight plaintext %} mdf_fo = SO3FunHarmonic (Forsterite → Forsterite) antipodal: true bandwidth: 25 weight: 1 {% endhighlight %}

Angle Distribution

Let us compare the actual angle distribution of the boundary misorientations with the theoretical angle distribution of the uncorrelated MDF.

{% highlight matlab %} close all plotAngleDistribution(grains.boundary('fo','en').misorientation) hold on plotAngleDistribution(mdf) hold off legend('boundary','uncorrelated') {% endhighlight %}
{% include inline_image.html file="MisorientationDistributionFunction_04.png" %}

It is often instructive to add the angle distribution of a uniform texture as a reference

{% highlight matlab %} close all plotAngleDistribution(mdf) hold on plotAngleDistribution(ebsd('fo').CS,ebsd('en').CS) hold off legend('uncorrelated MDF','uniform ODF','Location','best') {% endhighlight %}
{% include inline_image.html file="MisorientationDistributionFunction_05.png" %}

For computing the exact values see the commands calcAngleDistribution(mdf) and calcAngleDistribution(ori).
