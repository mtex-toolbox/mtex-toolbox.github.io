--- title: "Operations on Crystal Directions" sidebar: documentation_sidebar permalink: CrystalOperations.html folder: documentation toc: false --- Operations on Crystal Directions edit page

Crystal directions support the same calculations as specimen directions - angles, cross products and means - with one addition that can change the answer: crystal symmetry. A direction stands for all the directions that symmetry makes equivalent, and MTEX takes those equivalents into account unless told not to.

{% highlight matlab %} plottingConvention.default('y↑→x'); {% endhighlight %}

A Kikuchi Pattern to Read Them In

A simulated Kikuchi pattern of quartz makes the geometry visible. The left plot is the pattern itself, the right one its Radon transform, in which every band of the pattern becomes a spot.

{% highlight matlab %} data = load([mtexDataPath filesep 'quartzPattern.mat']); pattern = data.pattern; [~,ax1] = plot(pattern,'resolution',0.25*degree,'complete','upper',"UVTW",'noLabel'); mtexColorMap black2white nextAxis [~,ax2] = plot(pattern.radon,'resolution',0.25*degree,'complete','upper','hkil','noLabel'); mtexColorMap black2white {% endhighlight %}
{% include inline_image.html file="CrystalOperations_01.png" %}

The brightest bands belong to the most reflective lattice planes of quartz: the hexagonal prism and the two rhombohedra.

{% highlight matlab %} % extract the crystal symmetry cs = pattern.CS; m = Miller(-1,0,1,0,cs,'hkil'); % hexagonal prism r = Miller(0,-1,1,1,cs,'hkil'); % positive rhombohedron z = Miller(0,1,-1,1,cs,'hkil'); % negative rhombohedron {% endhighlight %}

Drawn into both plots, a plane is a great circle on the left - the band it produces - and a single point on the right.

{% highlight matlab %} hold on circle(m,'parent',ax1,'color','lightBlue') circle(r,'parent',ax1,'color','red') circle(z,'parent',ax1,'color','yellow') opt = {'marker','s','MarkerFaceColor','none','parent',ax2,... 'labeled','backgroundColor','w','linewidth',2}; plot(m,opt{:},'markerEdgeColor','lightBlue') plot(r,opt{:},'markerEdgeColor','red') plot(z,opt{:},'markerEdgeColor','yellow') {% endhighlight %}
{% include inline_image.html file="CrystalOperations_02.png" %}

Symmetrically Equivalent Planes and Directions

Only three planes are marked, but the pattern clearly has more bands of each kind. The missing ones are the symmetrically equivalent planes - those the symmetry operations of the crystal map the marked one onto. The class of all directions equivalent to \([uvw]\) is written \(uvw\), the class of all planes equivalent to \((hkl)\) is written \(\{hkl\}\), and symmetrise lists them.

{% highlight matlab %} symmetrise(r) {% endhighlight %} {% highlight plaintext %} ans = Miller (alpha-quartz low) size: 6 × 1 h k i l 0 -1 1 1 0 1 -1 -1 1 0 -1 1 1 -1 0 -1 -1 1 0 1 -1 0 1 -1 {% endhighlight %}

Six planes for quartz, whose point group 321 has six operations. Adding them to both plots covers the remaining bands.

{% highlight matlab %} hold on circle(m.symmetrise,'parent',ax1,'color','lightBlue') circle(r.symmetrise,'parent',ax1,'color','red') circle(z.symmetrise,'parent',ax1,'color','yellow') plot(m,opt{:},'markerEdgeColor','lightBlue','symmetrised') plot(r,opt{:},'markerEdgeColor','red','symmetrised') plot(z,opt{:},'markerEdgeColor','yellow','symmetrised') {% endhighlight %}
{% include inline_image.html file="CrystalOperations_03.png" %}

The option 'symmetrised' on plot does the same in one step. Treating the planes as axes doubles the count, since 321 contains no inversion and each plane normal then stands for its opposite as well.

{% highlight matlab %} length(symmetrise(r,'antipodal')) {% endhighlight %} {% highlight plaintext %} ans = 12 {% endhighlight %}

Multiplicity

The multiplicity is the number of distinct directions in a symmetry family. It is the size of the family returned by symmetrise(...,'unique'), and in powder diffraction it is the number of equivalent reflections contributing to one peak.

{% highlight matlab %} csCubic = crystalSymmetry('m-3m'); hCubic = Miller({1,0,0},{1,1,0},{1,1,1},csCubic); multiplicity(hCubic) {% endhighlight %} {% highlight plaintext %} ans = 6 12 8 {% endhighlight %}

The cubic \(\{100\}\), \(\{110\}\) and \(\{111\}\) forms have multiplicities 6, 12 and 8. A low-index direction is not necessarily the most numerous; multiplicity is set by how much symmetry leaves that direction fixed.

Are Two Directions the Same?

Under symmetry the question has two answers, and == gives the one that respects the crystal.

{% highlight matlab %} Miller(1,1,-2,0,cs) == Miller(-1,-1,2,0,cs) {% endhighlight %} {% highlight plaintext %} ans = logical 0 {% endhighlight %}

Not equivalent - no operation of 321 maps one onto the other. As axes they are, because then the sign no longer matters.

{% highlight matlab %} eq(Miller(1,1,-2,0,cs),Miller(-1,-1,2,0,cs),'antipodal') {% endhighlight %} {% highlight plaintext %} ans = logical 1 {% endhighlight %}

Does a Direction Lie in a Plane?

A direction \([uvw]\) lies in a plane \((hkl)\) when their scalar product is zero. In three-index notation this is the zone law

\[hu+kv+lw=0.\]

Use 'noSymmetry' for this test: incidence concerns the two indices that were written, not the closest pair from their symmetry families.

{% highlight matlab %} csOrtho = crystalSymmetry('mmm',[4 5 6]); plane = Miller(1,1,0,csOrtho); directionInPlane = Miller(1,-1,0,csOrtho,'uvw'); dot(plane,directionInPlane,'noSymmetry') {% endhighlight %} {% highlight plaintext %} ans = 0 {% endhighlight %}

Zero confirms that \([1\bar{1}0]\) lies in \((110)\). In contrast, \([100]\) does not.

{% highlight matlab %} dot(plane,Miller(1,0,0,csOrtho,'uvw'),'noSymmetry') {% endhighlight %} {% highlight plaintext %} ans = 1 {% endhighlight %}

The Cartesian dot-product test also works with four-index trigonal and hexagonal notation, without manually translating the zone law.

Zone Axes

Two lattice planes intersect in a lattice direction, the zone axis, which is the cross product of their normals.

{% highlight matlab %} d1 = round(cross(m,r)) plot(d1,'marker','s','parent',ax1,'MarkerFaceColor','lightgreen','labeled','backgroundColor','w') circle(d1,'parent',ax2,'linecolor','lightgreen') {% endhighlight %} {% highlight plaintext %} d1 = Miller (alpha-quartz low) U V T W -1 2 -1 3 {% endhighlight %}
{% include inline_image.html file="CrystalOperations_04.png" %}

MTEX switched from hkil to UVTW in the display, because the cross product of two plane normals is a direction and not a normal. round is what turns the result into small integer indices. In the pattern the zone axis sits where the two bands cross; in the Radon plot it is the great circle through the two spots.

Taking a second direction,

{% highlight matlab %} d2 = Miller(-2,0,1,cs,'uvw') plot(d2,'marker','s','parent',ax1,'MarkerFaceColor','Orange','labeled','backgroundColor','w') circle(d2,'parent',ax2,'linecolor','orange') {% endhighlight %} {% highlight plaintext %} d2 = Miller (alpha-quartz low) u v w -2 0 1 {% endhighlight %}
{% include inline_image.html file="CrystalOperations_05.png" %}

the same cross product gives the plane the two directions span.

{% highlight matlab %} n = round(cross(d1,d2)) circle(n,'parent',ax1,'linecolor','white') plot(n,opt{:},'MarkerEdgeColor','white') {% endhighlight %} {% highlight plaintext %} n = Miller (alpha-quartz low) h k i l 1 -2 1 2 {% endhighlight %}
{% include inline_image.html file="CrystalOperations_06.png" %}

The white band connects d1 and d2 in the pattern, and in the Radon plot the white spot is where the two great circles of d1 and d2 meet.

Angles

The angle between two crystal directions is the smallest angle between the first and any direction equivalent to the second - anything else would depend on which of the equivalent descriptions happened to be written down.

{% highlight matlab %} angle(Miller(1,1,-2,0,cs),Miller(-1,-1,2,0,cs)) / degree {% endhighlight %} {% highlight plaintext %} ans = 60.0000 {% endhighlight %}

Read as axes, the two are the same direction, and the angle is zero up to rounding.

{% highlight matlab %} angle(Miller(1,1,-2,0,cs),Miller(-1,-1,2,0,cs),'antipodal') / degree {% endhighlight %} {% highlight plaintext %} ans = 1.2074e-06 {% endhighlight %}

The plain geometric angle, symmetry ignored, is what 'noSymmetry' returns - the two vectors do point exactly opposite ways.

{% highlight matlab %} angle(Miller(1,1,-2,0,cs),Miller(-1,-1,2,0,cs),'noSymmetry') / degree {% endhighlight %} {% highlight plaintext %} ans = 180.0000 {% endhighlight %}

\(60^\circ\), \(0^\circ\) and \(180^\circ\) for one and the same pair of index triples. 'noSymmetry' is available for most commands that take crystal directions or orientations, and it is the option to reach for when a number looks smaller than it should.

From the Crystal into the Specimen

An orientation says how the lattice sits in the specimen, so it converts a crystal direction into a specimen direction.

{% highlight matlab %} ori = orientation.byEuler(10*degree,20*degree,30*degree,cs) close all plot(ori * pattern,'resolution',0.25*degree,'complete','upper') mtexColorMap black2white {% endhighlight %} {% highlight plaintext %} ori = orientation (alpha-quartz low → y↑→x) Bunge Euler angles in degree phi1 Phi phi2 10 20 30 {% endhighlight %}
{% include inline_image.html file="CrystalOperations_07.png" %}

The pattern above is the same one as before, turned by ori. The zone axis moves with it.

{% highlight matlab %} ori * d1 hold on plot(ori*d1,'marker','s','MarkerFaceColor','lightgreen','label',char(d1,'latex'),'backgroundColor','w') hold off {% endhighlight %} {% highlight plaintext %} ans = vector3d (y↑→x) x y z -0.427 -0.0286 0.592 {% endhighlight %}
{% include inline_image.html file="CrystalOperations_08.png" %}

Applying the orientation to all equivalent directions instead marks every place in the specimen where that crystal direction points.

{% highlight matlab %} hold on plot(ori*d1.symmetrise,'marker','s','MarkerFaceColor','lightgreen','label',char(d1,'latex'),'backgroundColor','w') hold off {% endhighlight %}
{% include inline_image.html file="CrystalOperations_09.png" %}

That set of points is precisely a pole figure of the orientation, see Pole Figures.

Dropping the Crystal Frame

A Miller is a <vector3d.vector3d.html vector3d> underneath, and the conversion returns the same direction without the lattice attached, in Cartesian coordinates.

{% highlight matlab %} vector3d(d1) {% endhighlight %} {% highlight plaintext %} ans = vector3d (y↑→x) x y z -0.246 0.426 0.541 {% endhighlight %}

From there the spherical angles are available as usual.

{% highlight matlab %} [theta,rho] = polar(d1) {% endhighlight %} {% highlight plaintext %} theta = 0.7378 rho = 2.0944 {% endhighlight %}
