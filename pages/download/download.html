mtex-{{ cur.version }}.zip
  1. Unzip the file into any folder.
  2. Start MATLAB and change to that folder.
  3. Run startup_mtex in the command window.
  4. Try mtexdata titanium and plot(ebsd), then follow the EBSD tutorial.

If it does not start

macOS may block the precompiled binaries, and some systems need the mex files compiled anew. Installation problems covers both, and how to build a standalone application with the MATLAB Compiler.

MATLAB versions

Use a MATLAB version as recent as possible. MTEX works with the student version; only GND and Taylor computations need the Optimization Toolbox. Each release stays compatible with MATLAB versions a few years older, not ten.

Development version

The newest code is on the develop branch on GitHub. Clone it with git to follow the development and to contribute.
